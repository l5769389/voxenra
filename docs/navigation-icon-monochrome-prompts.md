# Monochrome navigation icons

> 历史设计记录：运行时现已使用 SVG，下文描述的 PNG 资源已清理。

Generated using built-in ImageGen. These replace the earlier 3D orange icons in `src/voxplane/qml/assets/icons/nav-*.png`.

## Shared prompt

Use case: logo-brand. Generate ONE small flat monochrome professional medical software toolbar glyph. Square raster PNG with actual transparent alpha background. Pure soft white #eeeeee only. Draw like crisp technical UI iconography: uniform medium-thin strokes about 1.5px on a 24px logical grid, tiny corner radius, precise geometric proportions, balanced centered silhouette occupying 76% canvas. Flat front-facing or simple isometric geometry as required by subject. Subtle anti-aliasing only. This belongs alongside classic white folder and wireframe cube toolbar symbols on charcoal #222222. It is NOT an app icon or illustration. NO 3D render, NO extrusion, NO thickness, NO bevel, NO glossy materials, NO shading, NO shadows, NO gradients, NO orange, NO colors, NO lighting, NO texture, NO background tile, NO container around the symbol, NO words or numerals, NO watermark. GENUINE transparent background, never painted checkerboard. Exactly one simple glyph.
