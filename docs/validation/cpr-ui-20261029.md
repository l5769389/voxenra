# CPR 原生界面验收 · 2026-10-29

本次在 `codex/cpr-reconstruction` 分支完成 CPR 工作区，并使用 macOS 原生界面操作验证。操作通过真实鼠标、键盘和系统文件对话框完成；测试程序仅生成合成 DICOM、启动应用及读取状态，不调用控制器代替用户操作。

## 环境与复现

- macOS / Apple Silicon，Qt Cocoa 平台，PySide6，Python 3.13.14，NumPy 2.5.2。
- 原生窗口分别为 1440×950、1280×720 逻辑像素，设备比例为 2。Qt Quick 使用 software 后端。
- 96 张 160×160 合成 CT，体素间距 0.8×0.8×1 mm，含两条弯曲高密度管状结构。标识为 `CPR^PHANTOM / SYNTHETIC-CPR`，没有真实患者数据。
- 使用独立的设置、PACS 配置与导入目录。自动化运行使用本地开发用 Mach-O Python 启动器；没有制作或发布安装包。

```sh
PYTHONPATH=src QT_QUICK_BACKEND=software \
VOXENRA_CPR_UI=build/native-cpr VOXENRA_CPR_WINDOW=1280x720 \
.venv/bin/python tests/manual/native_cpr_workspace.py
```

在界面打开 `build/native-cpr/synthetic-ct`，导入后通过序列右键菜单进入 CPR。`state.json` 是定时读取的状态证据，不是输入通道。

## 验收中修正的问题

- 草稿开始、加点、删点和取消现在会标记工作区已修改。
- 拖动未提交时关闭页签，保留最后一次提交的路径，不把拖动预览写入工作区。
- 曲面文字标注按路径、版本、实际点集和重建参数隔离；只移动沿路径位置时仍保留。
- 面板由 Loader 延迟赋予 controller 时同步名称与数值，修复切换设置页后出现空名称、默认数值的问题。
- 影像画布的标题、位置提示采用独立于界面主题的文字色；路径覆盖层改用主题语义颜色。
- 无效路径直接在面板显示错误；曲面普通测量和不支持的掩膜转换不再显示误导性操作。
- 曲面文字标注模式的点击进入标注选择逻辑，不再被沿路径位置联动拦截。
- CPR 页面及共享标注面板释放 controller 时安全清理绑定，CPR 导出入口也处理释放状态。

独立审核者复核了上述生命周期、标注、面板同步及空值处理，全部反馈已解决。关键缺陷均有先失败、再通过的定向回归。
