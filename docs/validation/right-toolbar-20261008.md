# 右侧操作栏整理验证

## 本轮范围

- 新配置默认宽 300 逻辑像素，拖动范围 240–420；保留已有有效宽度，旧的 220–239 收敛至 240。
- 顶部保留常用阅片操作，下一行显示带名称的主要功能与“更多”。其余工具在“更多”内分组显示，导入、导出、重置单列一组。
- 切换工具不改变宽度；播放时保持停止入口可见。沿用侧栏收起和中央视口最小尺寸约束。
- 更新中英文操作手册。不引入独立工具窗口。

## 按视图调整优先级

后续审核发现，固定名单加截取数量不能表达不同视图的任务优先级。改由 `model/toolbar_priorities.py` 定义顺序，控制器以公开 `toolbarGroups` 属性提供给 QML；切换序列能力会刷新分组。常驻项仅从实际可用工具中选取，其余入口仍在“更多”。

- 2D：调窗／翻页／平移／缩放；测量、布局。
- MPR：基础导航；测量、分割、投影。对照视图不提供不支持的分割。
- 4D：播放常驻第一排；参考 3D 也保留时相播放。
- PET：伪彩常驻；PET/CT：CT 和 PET 显示调节常驻，主要功能为伪彩、融合、测量。
- 3D：旋转／平移／缩放；模板、方向、裁剪。MPR 参考 3D 的裁剪位置改为布局。
- 彩色影像：保留实际支持的导航、测量与标注，不显示灰度调窗。

新增用例验证顺序不受工具目录顺序影响、序列能力切换刷新，以及中英文 240 / 300 宽度的 QML 实际渲染。已修复英文标签截断，完整名称保留在悬停提示中。截图位于 `build/toolbar-context-ui/`。此次界面复核为 Qt 渲染与自动交互，没有新增原生手动复核结论。
