# QA 圆形 ROI 兜底与编辑验证

日期：2026-10-26。验证对象为本次工作区代码修改。

## 原因复核

用户提供的四张 CT 为 512 × 512，像素间距 0.3906 mm。
圆形拟合有完整角度覆盖，拟合直径约 199 mm，几乎占满约 200 mm 视野。
拟合圆在左侧或上侧略超出像素中心范围，触发检测器的边界完整性检查。
拒绝发生在边界检查阶段，并非水样灰度检查阶段。
原始数据和桌面截图仅在本地验证，没有加入仓库。

## 最终行为

- 未识别到唯一可用水模时，自动在图像中心及四周创建五个物理圆形 ROI。
- 直接显示“圆形 ROI”与取样统计，不显示黄色未识别提示；模式说明收在信息按钮内。
- 自动水模 ROI、兜底 ROI 和副本均支持拖动、复制、删除。普通 ROI 移动受图像边界限制。
- 重新计算、切片切换和工作区保存保留 ROI 的位置与删除状态；“重新生成五个 ROI”恢复布局。
- 没有水模或五个初始区域不完整时不展示水模五点汇总；删除中心后 Δ中心 为“—”。
- 无效像素、缺少间距、空间或采样不足、检测器执行异常仍返回实际错误，不冒充有效测量。
- 兼容旧工作区中的 QA 记录；本地手册及中、英、葡语文案已同步。
