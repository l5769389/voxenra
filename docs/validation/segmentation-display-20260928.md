# 分割显示第一版验证

## 范围

- 当前页签的二维分割叠加：填充、轮廓、填充＋轮廓，默认组合显示、30% 填充不透明度。
- 0–100% 滑块；仅轮廓时禁用并保留填充值。4D 各时相共用该页签设置，VOI 不受影响。
- 使用当前采样平面掩膜的内侧四邻域像素边界，包含孔洞、独立小区域、单像素及图像边界，不平滑实际掩膜。
- 填充和轮廓合成一张 RGBA 图，沿用现有双缓冲叠加；显示参数变化复用平面掩膜，不重新统计或重采样。
- 使用工作区已有可选工具偏好字段保存，旧文件使用默认值。显示修改标记未保存；恢复不产生虚假修改。
- 本版不增加三维分割表面、逐区域不透明度或轮廓宽度设置。

## 验证

8 个相关测试文件共 76 项通过（重复运行的文件不重复计数）。日志位于本地 `build/segmentation-display/tests`、`final-tests`、`ui-final`。

- 独立逐像素边界判定，空掩膜、孔洞、独立像素、边界及 0/30/100% 不透明度。
- 显示修改不改变原掩膜或统计对象，不再次调用平面采样；隐藏项仍隐藏。
- 绘制／擦除预览、撤销／重做及显示切换保持 QML 叠加对象和就绪纹理，检查无空帧或双重混合。
- 保存恢复和独立进程重启保留显示设置、掩膜和编辑状态；SEG／NRRD 交换回归通过。
- 中英文、深色／深灰／浅色、1280×720 窗口与 240 宽操作栏；通过实际组合框键盘选择和滑块操作验证绑定。截图在 `build/segmentation-display/ui`。
- 视觉检查发现语言切换重建下拉模型后选中项可能回到第一项，已修复分割模式、画笔范围／单位及显示模式的索引同步，并增加断言。

## 原生界面

通过 CUA 在隔离的 Voxenra Spatial QA 中打开已有 MR 分割工作区的副本。默认组合模式显示 30%；切换仅轮廓后区域内部恢复原始灰度、滑块禁用。回到组合模式后滑块恢复，点击滑块得到 50%。界面统计保持均值 157.86、标准差 27.42、体素数 947、体积 0.95 cm³。

通过原生快捷键保存副本，读取文件确认 `displayMode=fill-outline`、`fillOpacity=50`，两个分割掩膜与原始工作区完全一致。原生截图见本轮 CUA 记录。连续鼠标绘制的无闪烁检查本轮依靠 Qt 渲染回归，不将静态原生截图当作连续帧证据。
