# Voxenra 2.1.5 发布检查

## 范围

自 v2.1.4 后的阅片界面精简、收藏目录、四角信息直接拖拽编辑，以及收藏切换抖动和相关状态修复。CPR 仍是设计方案，不包含在本次发布中。

版本号、应用版本、锁文件和中英文发布摘要已更新。README 和图集补充中英文收藏目录及四角编辑的实际界面素材；本地及在线手册更新相应示例与取消收藏说明。新素材来自原生应用窗口，临时目录与内置示例不含私有患者信息，切换及跨角移动已核对状态。GIF 的两帧分别展示移动前后。

## 预检

发布摘要格式、Qt 资源清单、README/图集本地链接和静态网站构建通过。收藏与界面回归在原生 Cocoa 和 offscreen 各 15 项通过。部分 Qt 样式会为隐藏的水平滚动条保留非零范围，但实际卡片均在视口内；回归改为检查隐藏状态与每张卡片的左右边界，不依赖样式内部的滚动范围。

全量测试与产物验收结果将在候选提交固定后追加。日志与截图保存于本地忽略目录 `build/release-2.1.5/`。

## 分发限制

本机无 Developer ID 分发证书，本次 macOS 包继续使用 ad-hoc 签名，未经过 Apple 公证；Windows 未配置 Authenticode 签名。Windows/Linux 外部 AI 实际推理、真实崩溃恢复和旧版 Windows 客户端完整点击自动更新流程未完成实机验收。
