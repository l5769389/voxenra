# Voxenra 2.1.1 发布检查

## 范围

本版集中优化界面样式、主题、文案和操作流程，并修复影像导入、测量与分割、跨时相报告、工作区数据保护和异常恢复问题。发布说明按用户可见的大类概括。

## 发布候选验证

- macOS 完整隔离回归：211 个文件、2838 项；2767 通过、71 跳过，0 失败、0 错误。
- 已执行原生界面和文件验证：导入、报告 CSV/PDF、工作区保存恢复、关闭保护、AI 失败重试、VOI 内存异常、历史记录重试及三种主题。
- 真实强制终止测试验证旧恢复文件完整；AI 进程清理覆盖所属多级子进程。内存不足使用故障注入，未人为耗尽物理内存或显存。
- 中英文发布摘要通过格式检查；项目、应用和锁文件版本一致。
- 更新外观设置、首页、导出完成和自动分割流程图；素材仅捕获应用窗口，无私有患者信息。AI 流程图使用合成 CT 与受控推理输出，明确标注为流程演示。
- 新增的资源包含在源码包、wheel 和冻结打包资源清单中。

## 平台说明

macOS 为 Apple Silicon、ad-hoc 签名，未配置 Developer ID 或 Apple 公证；Windows x64 包未配置 Authenticode 签名。Windows/Linux 真实 AI 推理及崩溃恢复仍未完成实机验收，不以 CI 或 macOS 检查替代。

## 构建与发布

安装包以版本标签对应的提交构建。构建、安装包启动、自动更新、六个附件及 SHA-256 的实际核验结果在发布完成后补充；未完成的项目不计为通过。主页只在附件可下载后切换为本版。
