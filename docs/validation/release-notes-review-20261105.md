# 发布说明审核（2026-11-05）

## 范围与结论

审核对象为当前正式版 [Voxenra 2.3.0](https://github.com/l5769389/voxenra/releases/tag/v2.3.0)、仓库 `docs/releases/v2.3.0.md`、发布模板，以及应用内摘要解析规则。GitHub 当前 Latest 为 v2.3.0，发布于 2026-11-03；线上正文与仓库文件逐字一致。中英文摘要格式校验通过。

内容有事实基础，也明确披露了平台限制；主要问题是升级信息优先级、摘要密度和正文组织。适合调整成“升级须知 + 简短亮点 + 分类变更 + 已知限制”的结构，不宜继续扩写成另一份操作手册。

本次仅审核并提供建议稿，未修改正式说明或线上 Release，未构建或发布版本。

## 推荐结构

1. 版本与发布日期，并用一句话说明本版重点。
2. `## 更新摘要`：4–6 条用户可见变化，必须包含用户需要采取行动的升级事项。
3. `## Update summary`：与中文对应，保持解析契约。
4. 完整中文说明：升级须知、主要改进、问题修复、兼容性与已知限制、手册与验证链接。
5. 完整英文说明：相同事实和限制，单独成块。

应用内解析器依赖两个固定标题，不能为了排版随意更名。现有限制为每种语言 1–6 条单行普通列表、中文每条不超过 80 字符、英文不超过 180 字符。截图、链接、粗体只放完整说明。

## 2.3.0 摘要改写示例

以下只概括已发布的 2.3.0，不包含当前工作区后续修改。

- Windows 2.2.0 用户需手动下载安装本版；修复 Windows 更新程序未启动安装的问题。
- 改进 CPR 路径绘制，支持采样示意、沿线区间标记和结果视图大小调整。
- CPR 页签关闭后，从序列打开会新建空白路径；通过「重新打开页签」恢复原结果。
- 新增菜单数字快捷键、色表收藏和「跟随系统」主题。
- 修复曲线与自由手绘 ROI 完成时的交互问题，保留已有控制点和分屏布局。
- 完善对话框 Enter / Esc 操作；首次本地导入自动选中首个序列。

中英文可校验建议稿保存在 `build/release-notes-review-20261105/summary-proposal.md`。这是一份文案建议，不是新版发布声明。

## 版本边界

- v2.3.0 标签中的界面确实使用“重新打开页签”。不能因为开发版改为“撤销关闭页签”，就把旧版本说明判为用词错误。
- 最近的四图青色取样标记、初始切片对齐、全类型页签规则等改动尚不属于 v2.3.0 标签。应在下次发布中根据实际提交说明，不能补写成 2.3.0 已提供的能力。
- 本次没有完成新一轮平台验收。已有 2.3.0 验证证据来自 [发布验收记录](release-2.3.0.md)，本审核不扩大其结论。
