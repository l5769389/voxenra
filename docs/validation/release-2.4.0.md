## 内容与界面

发布说明统一为简短中英文摘要，以及按语言分块的升级须知、主要改进、行为变化与修复、安装兼容性及相关资料。2.3.0 只修订说明文字，原标签与六个附件保持不变。摘要格式检查通过；真实 2.4.0 内容的弹窗检查覆盖中英文、三种主题、长摘要滚动、关闭后重开及链接。

使用匿名示例影像更新中英文工作区、窗模板、CPR 四视图和结果、测量列表、主题及线条样式截图，共 14 张；逐张检查无桌面或其他窗口叠加。README、离线手册及网站引用同步更新；147 个本地图片和文档链接逐一检查存在。

保留已确认的交互：绘制 CPR 时不自动翻层；完成或选中路径时参考切片对齐起点；从序列打开视图仍每次新建独立页签。独立全量改动审查未发现需修改的问题，审查中的 40 项专项检查通过。

## 平台包与升级

macOS DMG 的完整性、arm64 架构、2.4.0 版本及 ad-hoc 签名检查通过。挂载后直接启动成功，包内应用与本地构建的 2,049 个条目逐一比对文件内容、符号链接和权限一致。RLE、JPEG-LS、JPEG 2000 与 JPEG Baseline 四类真实压缩像素解码通过。

在隔离目录中安装实际发布的 2.3.0 客户端；测试更新源只重定向该进程读取的发布信息、校验文件和安装包地址，未修改生产更新器。最终 DMG 通过旧版界面的更新按钮安装，替换后版本与健康启动令牌正确，设置保留，旧工作区在主动保存前逐字节不变；安装后的应用与最终构建的 2,049 个条目再次完全一致。

旧工作区加载后，实际界面恢复第 39/91 层、窗宽 600、窗位 180，以及 CPR 位置 124.753011 mm 和结果模式。新版保存、新建、重新打开工作区后，界面与文件再次确认一致。校验错误拒绝安装、取消下载、取消退出、保存退出、关闭自动更新后重启不请求更新及手动检查更新，使用本轮第一候选和同一旧客户端完成；最终候选的更新器代码未改变，最终包重新执行成功升级及工作区往返。

Windows x64 安装版与单文件便携版由同一提交的 GitHub Actions 构建，两种形式的四类压缩像素解码及嵌入图标检查通过。默认安装目录、覆盖安装、旧运行库清理、用户文件保留及安装后启动通过。实际下载已发布的 2.3.0 安装版和便携版，各自启动后由更新助手升级到 2.4.0；新旧版本均确认启动，主题及关闭自动检查设置保留，中文路径下的测试工作区文件逐字节不变。Windows 包级测试使用空序列工作区夹具；含真实影像及 CPR 的保存／重开往返在上述 macOS 界面验收中完成。

## 修复与未覆盖范围

发布验证复现了异步手册加载期间立即切换页签导致文本选择菜单警告的问题，已将手册界面作为整体创建，并保留影像后台加载；补充 0、1、8、25 ms 切换时序回归。另修正旧箭头测试的拖放预期，使其符合已经确认的固定端点按下定点规则。早期系统磁盘挂载忙与原生悬停等待超时已分别复核，未作为通过结果计入最终验收。

前一 Windows 全量运行在后台 PDF 首次导入 Qt 类型时出现一次原生堆异常（0xc0000374）。随后在原始提交上，对原生／离屏、主线程提前导入／原样按需导入四种组合，共执行 100 个独立测试进程、2,800 项用例，未重现崩溃；4 次首轮原生运行只遇到上述 3 秒等待超时。没有证据支持把类型导入方式视为根因，因此未改动生产导出代码，也不声称已修复此单次异常。新增原生后台报告验收和前置工作区回归，最终完整运行结果见上表。[首次失败](https://github.com/l5769389/voxenra/actions/runs/41982937940) · [五轮对照](https://github.com/l5769389/voxenra/actions/runs/41988976971) · [二十轮对照](https://github.com/l5769389/voxenra/actions/runs/41989426317)

macOS 使用 ad-hoc 签名，未经 Apple 公证；未在另一台干净 Mac 上进行 Gatekeeper 安装验收。Windows 未配置 Authenticode 签名；原生自动化及真实包升级不等于物理 Windows 电脑上的人工阅片和旧版界面点击更新全流程。未声称通过这些未执行的检查。
