## Slicer 5.12.4 交叉核对

隔离 Slicer 用户目录与 DICOM 数据库，未使用用户现有场景。使用同一数据并明确网格/单位；完整路径、影像身份和原始数据仅保留在本地 build 目录。

### 影像与几何

- 真实 MR、CT：Slicer 环境独立通过 SimpleITK/GDCM 读取原始 DICOM，再与 Voxenra 导出的体数组和空间矩阵核对，像素、几何一致。MR 因文件元信息组织方式采用明确文件列表导入，记录在适配器输出。
- PET/CT 另走 Slicer 原始 DICOM 数据库导入路径：CT 59,899,904 个有效体素、PET 1,019,200 个有效体素，强度最大误差均为 **0**；空间矩阵最大误差分别为 `7.11e-15 mm`、`1.11e-15 mm`，小于 `0.001 mm`。
- 复合斜位解析数据通过 NRRD 同网格交换核对；它不是本轮原始 DICOM 导入证据。
- PET Slicer 标量导入器提供源强度，本轮 **没有完成 Slicer SUVbw 数值复核**。不能将源像素一致表述为 SUV 一致。

### 分割及统计

| 案例 | Voxenra→Slicer 三区域体素数 | Slicer 编辑后返回 Voxenra | 同网格掩膜/名称/颜色 |
|---|---|---|---|
| MR | 1198 / 1198 / 0 | 1199 / 1198 / 0 | 完全一致 |
| CT | 410 / 410 / 0 | 411 / 410 / 0 | 完全一致 |
| 复合斜位 | 846 / 846 / 0 | 847 / 846 / 0 | 完全一致 |

包含重叠区域与空区域。Slicer 对第一区域添加一个体素并重命名，返回后新增体素、名称、颜色及空区域均保留。Segment Statistics 的体素数、体积、均值、最小/最大值核对通过；标准差按总体/样本定义转换后比较，不能直接比较两个不同定义的 SD。

### 可见 MR 定位

两款软件使用相同窗宽/窗位 `204 / 102`，患者 RAS 坐标约 `(3.652027, 25.923729, -9.185633) mm`。Slicer 默认曾沿斜位采集网格显示，先显式切为 Axial/Coronal/Sagittal 再设平面位置，随后核对方向与脑部标志点。仅相同坐标数值或切片编号不足以保证输出平面一致。

本地对应证据：`slicer-visible.png`、`slicer-visible.json`、`exchange/*/slicer-result.json`、`exchange/return-summary.json`、`pet/comparison.json`。
