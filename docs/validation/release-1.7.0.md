## 验收发现及修复

- 彩色标记经通用文本转换后将 `false` 视为真，影响普通灰度/PET 窗值叠加；改为严格布尔判断。
- 原生导入目录列表使用平面模型，避免切换树根触发 macOS 辅助功能崩溃；统一 Windows 路径格式，恢复文件选择与进入目录。
- 目录枚举移出主线程，等待系统授权、网络或磁盘时仍可取消、改路径；旧请求不能覆盖新目录，关闭窗口不等待目录线程。
- Windows 更新辅助程序使用 .NET SHA-256，避免继承其他 PowerShell 的模块环境后找不到 Get-FileHash；反馈 GUI 回归隔离原生邮件客户端并等待异步任务结束。
- 修复设置页、链接及其他提示框在锚点断开时读取空父对象的错误，补充主动断开锚点的回归。
- 快速切换页签时测量控制器暂时不可用，提示与光标绑定增加空值回退。
- PDF 选项改为“附测量参考图”，与按测量来源生成图片的实际行为一致。
- 语言包窗模板示例与重名提示修正；版本相关测试固定测试基线，路径比较按平台语义处理。
