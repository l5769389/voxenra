# 工作区关闭结果保留、QA 撤销重做（2026-10-26）

用户确认关闭页签保留结果，退出时统一确认是否保存。

## 最终行为

- 移除原有逐页签破坏性关闭提示。关闭包含完成结果的页签前序列化快照，成功后释放页签及其渲染资源；批量关闭在所有快照准备完成后才执行。快照失败保留原页签并显示原因。
- 已关闭的结果参与手动保存、自动恢复和未保存内容判断。即使侧栏和全部页签均为空，只要保留结果存在，退出仍执行工作区保存确认。
- 打开相同页签、首页/工作区窗口的“重新打开页签”、Ctrl+Shift+T / ⇧⌘T 均可重开。保存文件重开后已收起的结果保持收起状态，按需恢复。新建工作区清除本次保留快照。
- 退出文案统一为“是否保存对当前工作区的修改？”，沿用已有保存、不保存、取消及用户明确设置的记住选择。保存失败不退出。
- QA 移动、复制、删除、重新生成、成功的参数变更及重置接入页签编辑历史；初始自动圆形和兜底圆形的编辑均支持。一次拖动提交一步，单击不移动不增加历史。切片导航、调窗及后台自动分析不增加历史。
- QA 面板提供撤销/重做按钮，沿用软件快捷键。与测量编辑按时间顺序回退。撤销使过期的显式重算任务失效；不涉及 QA 的测量撤销不会中断自动切片分析。重新生成失败保留上次成功记录。
- 工作区保存结果，不保存撤销历史；关闭重开后从保留结果继续编辑。
