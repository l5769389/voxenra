# Voxenra 2.3.0 发布验收

正式标签 `v2.3.0` 指向 `ff8d01e1f4b462493b229eabe6b0a465d8580b5c`。本次更新包含 CPR 交互与采样示意、视口分隔、菜单与弹窗快捷键、色表收藏、导入默认选择和跟随系统主题。中英文 README、截图与操作手册同步更新。[发布页](https://github.com/l5769389/voxenra/releases/tag/v2.3.0) · [截图记录](release-2.3.0-media.md)

## 测试与升级

| 平台 | 最终提交上的结果 |

| Windows x64 | 266 个文件，共 3,495 项，3,398 通过，97 条件跳过。原生弹窗键盘、更新器成功及回滚、三轮异步界面切换、安装版与便携版解码、覆盖安装和真实旧包升级均通过。[构建与测试](https://github.com/l5769389/voxenra/actions/runs/41618225992) |

Slicer 5.12.4 对原始与斜位数据共 13 组 CPR 重建完成几何及像素对照，全部符合既定误差范围。

macOS 使用真实发布的 2.2.0 客户端，在隔离设置下保存已修改的 CTA 工作区并安装最终 DMG。进程内测试更新源仅重定向发布信息及包地址。替换后启动令牌、版本与设置一致，下载文件及备份清理完成。新应用保存、新建并重新打开工作区后，实际界面与文件均恢复第 37/91 层、窗宽 600、窗位 180，以及 CPR 横截面位置 124.753011 mm 和结果模式。

Windows 在 Actions 上启动真实 2.2.0 安装版和便携版，由本版生产更新辅助程序执行升级。两版应用均确认启动，既有工作区文件与设置保持一致。此次修复了 Windows PowerShell 辅助进程提前退出的问题，Windows 2.2.0 用户需要手动下载安装新版。旧客户端界面点击更新的全流程与人工阅片尚未在物理 Windows 电脑验收。

## 限制与复测记录

macOS 使用 ad-hoc 签名，未经 Apple 公证，未执行另一台干净 Mac 的 Gatekeeper 安装测试。Windows 包无 Authenticode 签名。macOS 校验失败、取消下载及关闭自动检查等故障场景复用了同一真实 2.2.0 客户端的前期记录，最终包重新执行了成功升级与工作区往返。

前期候选暴露的加载提示与拼图悬停提示销毁错误、控制器接口生命周期问题以及 Windows 更新器启动问题已修复。相关回归包含可稳定复现的失败用例。测试等待条件也补充了实际视口呈现、窗口尺寸、设置分类可见范围、后台 PDF 完成和卸载器临时文件解锁。

最终提交首次本地全量测试遇到系统磁盘工具创建测试 DMG 超时。清理该测试设备后，更新器专项及整套测试重新通过。

标签触发的额外重复构建曾在原生 Windows 测试中等待设置页反馈按钮出现时超过 3 秒，当时尚未开始反馈弹窗交互。后续专项离屏复测 115 项通过，原生 macOS 反馈用例也通过。原始 Windows 运行未保存加载器现场，超时原因仍未确认。发布附件采用上述同提交的完整成功构建。[重复运行记录](https://github.com/l5769389/voxenra/actions/runs/41628001013)
