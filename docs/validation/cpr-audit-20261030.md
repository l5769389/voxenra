# CPR 交互、持久化与 Slicer 验证（2026-10-30）

审核基于 CPR 实现 `6d02343`，合入 main 的 2.1.5 后完成修复。当前功能采用手动三维折线路径；本记录不将其描述为自动中心线提取或平滑样条。

## 已修复的问题

| 问题 | 修复及验证 |
| --- | --- |
| 切换参考平面、定位控制点没有标记工作区变更 | 补发持久化通知；验证修改、保存、读取和恢复后的状态一致。原生界面保存后切换平面再次变为未保存。 |
| 渲染失败后重试成功仍留有错误 | 新请求接受后清除旧计算错误；源序列不一致的错误持续保留。 |
| 删除最后一条路径后文字标注残留 | 空结果解除当前标注平面，撤销后重新出现，标注记录不被删除。 |
| 空结果显示大量无值四角信息 | 仅在 CPR 图像存在时显示四角信息，保留原参考图的显示。 |
| 小幅拖动控制点被当作点击并插入新点 | 按下时识别可拖动控制点，立即响应位移；普通点击和新建路径仍遵循原有交互。原生界面确认三个点数量不变、只移动选中点、一次撤销精确恢复。 |
| 源序列不一致提示被其他操作清除 | 参数变化、取消操作后仍保持来源不匹配状态，避免无提示的不可用页面。 |
| CPR 操作提示和历史测量说明未随语言切换 | 使用现有语言属性通知机制；实际中英文切换及历史平面说明测试通过。 |
| 斜向横截面方向字母与角落信息重叠 | 根据方向文字实际宽度预留中间间距；实际 QML 三字母方向和原生截图确认不重叠。 |

另修复 Slicer 验证脚本对合法两点路径的空内部顶点集合处理。补充 CPR 面板、图标及帮助图片的 Qt 资源清单，更新中英文 README、本地手册及网站首页。

## 回归和原生界面

最终相关回归共 17 个文件、325 项通过，零失败、错误或跳过。覆盖 CPR 控制器、几何、重采样、测量、工作区、异步任务、导出及实际 QML 指针/键盘交互，以及语言、公共视口、文本标注、工具与四角信息。完整发布候选测试和安装包验收另记于本次发布检查。

使用隔离偏好与合成 CT 在原生 Cocoa 窗口验证：导入、创建两条路径、完成与编辑状态、细微拖动及撤销、MIP 8 mm / 30° 参数、参考平面切换、保存、重启打开与异常退出副本恢复。中性深灰、浅色和深色界面及中英文切换均已检查。新 README / 手册图片来自最终源码的应用窗口内容，不含桌面覆盖或私人患者资料。

原生细微拖动和参考平面变化的状态记录见 [拖动记录](cpr-audit-20261030/fine-drag-state.json)、[平面变化记录](cpr-audit-20261030/plane-change-state.json)。[中文界面](../screenshots/59-cpr-2.2.0.png)和 [English 界面](../screenshots/en/59-cpr-2.2.0.png)显示最终文字避让效果。

## 独立 Slicer 校验

使用本机 Slicer 5.12.4、revision 4e21c19、VTK 9.6.2，重新生成并检查输入清单与散列。Slicer 阶段不导入 Voxenra 包，使用独立 DICOM 读取、Markups 和 VTK 插值；同时运行 Slicer 的 GeneralizedReformat 模块。

| 输入 | 数值核验范围 | 最大像素差 | 最大采样位置差 | 最大路径长度差 |
| --- | --- | ---: | ---: | ---: |
| 保存的回归工作区及历史测量 | 3 组数据、17 次重建、51 个横截面 | 0.007782 HU | 0.000003266 mm | 0.000001869 mm |
| 本轮实际界面保存的工作区 | 3 组数据、17 次重建、51 个横截面 | 0.008240 HU | 0.000003266 mm | 0.000001306 mm |

两轮掩码、坐标、切向、正交标架、投影和采样检查均通过。历史长度差约 4.44e-16 mm，历史面积差约 0.0000433 mm²；历史平面及统计仍能恢复。第二轮包含合法两点路径和实际界面编辑的三点路径；该新工作区没有历史测量，历史测量验证由第一轮覆盖。

完整数值结果见 [回归工作区报告](cpr-audit-20261030/slicer-fixtures.json)和 [当前界面工作区报告](cpr-audit-20261030/slicer-current-ui.json)。新生成的 `native-1-saved-slicer-cpr.nrrd` 还通过 Slicer 的 Add Data 界面加载并显示，见 [Slicer 界面记录](cpr-audit-20261030/slicer-ui.png)。

像素差比较采用明确匹配的采样网格。Slicer 自带重建可能采用不同的曲线、平滑和标架默认值，不能据此声称其默认输出与 Voxenra 逐像素相同。折线拐点的切向变化属于当前手动折线模型；本次数值及合成数据验证也不等同于临床用途认证。

## 复验入口

`tests/manual/validate_cpr_slicer.py` 依次执行准备、Slicer 和 check 阶段；`CPR_VALIDATION_ROOT` 指定隔离输出目录，`CPR_VALIDATION_STAGE=slicer` 或 `check` 选择阶段。复验需提供说明中的输入数据，本记录只提交数值报告和合成图像，不提交原始影像数据。
