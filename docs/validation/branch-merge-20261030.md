## 复核后修复

1. **异步完成抢占输入焦点。** CPR 后台完成时保留仍可见的文本框与控件焦点；原视口或完成按钮被隐藏时，焦点交给可见结果视口。普通根 Item 的 `Qt.NoFocus` 不被误判成输入控件。
2. **部分面板控件中完成／取消快捷键失效。** CPR 命令按面板作用域分发，不再仅依赖按钮的 `checkable` 属性。保留文本输入、弹窗和快捷键录制的屏蔽条件。
3. **原生紧凑面板构建期间被同步卸载。** Cocoa 窗口中复现了后台接受结果、切换活动视口、关闭弹窗后出现的 `Object or context destroyed during incubation`。打开时同步装载面板，关闭后在当前事件结束时按最终可见状态卸载，避免销毁正在创建的控件。关闭后立即重开及引擎销毁场景也经过独立复核。

另外将本次新增的 `DelayedActivity.qml` 和 `CprActions.qml` 补入资源清单。PyInstaller 原本递归收集 QML 目录，此处不宣称存在已证实的安装包漏文件故障。
