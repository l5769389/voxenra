# 鼠标、快捷键、界面大小与隐私设置验证

日期：2026-10-09。基于本地未提交工作区，保留此前修改。本轮不打包、发布、提交或推送。

## 实现范围

- 设置新增“鼠标与快捷键”：滚轮翻层反向、右键／中键拖动动作、调窗与缩放灵敏度；默认保持原操作习惯。
- 工具快捷键集中定义，支持录入、清除、恢复默认；标准文件和编辑快捷键独立列出，不允许覆盖。冲突校验失败保留原绑定。
- 工具键仅作用于当前窗口支持的视口功能；输入框、弹层、录入过程、鼠标按住及失焦时不执行阅片工具。无 OS 全局快捷键注册。
- 设置“外观与语言”新增 100%／115%／130% 界面大小，重启生效，保留系统缩放。继承环境的更新重启不重复叠加应用缩放。
- 设置“隐私”新增新视图隐藏身份信息和清除最近工作区入口；已打开的视图不被静默修改，工作区保存状态优先。清除历史不删除文件。
- 隐藏身份仅针对视口叠加和平铺身份信息，不隐藏左侧患者列表、不改变 DICOM／烧录像素，也不替代匿名导出。
- 中英文操作手册新增上述入口、适用范围和冲突处理说明。

## 本轮发现并修复

1. 全应用事件过滤器长期挂载，在 Python／Qt 对象销毁边界仍被回调；改为仅录入期间安装，取消／失焦／应用关闭时移除，并防护销毁期间事件。
2. 2D 调窗／缩放灵敏度原先在构造拖动事件之后才缩放偏移；调整到事件构造之前，实际控制器回归核对倍率差异。
3. 新设置分类增加导航高度，旧测试点击了滚动区之外的 ROI 项；测试先滚动到真实控件，再点击并校验页面结果。
4. 原生 MPR 数据就绪早于 QML 挂载，固定延时测试可能找不到视口；改为等待可见交互层，不把数据状态当作界面已就绪。
5. 平铺视图恢复隐私显示状态时缺少身份文字通知；补齐信号并验证先失败、修复后通过。
6. 更新器继承进程环境时，界面缩放可能重复相乘；保存原始 Qt 缩放基准，验证重复启动和恢复 100% 不累乘。

- 设置页真实点击录入；重复 W 显示错误且保持录入；合法绑定成功；隐私设置对已有／新建视图的区别；界面大小提交成功。

截图和状态：`build/input-settings/scale/`。使用隔离设置和模拟影像，未改用户正式配置。

## 限制

- Windows 的系统按键、第三方全局热键、不同键盘／输入法和多显示器 DPI 切换未在 Windows 机器实测；不宣称完全无冲突。
- OS／输入法／第三方常驻工具先截获的按键，应用无法可靠枚举或夺回。已拒绝已知保留键；其余可清除或重新绑定。
- 离屏环境跳过的原生窗口／OpenGL 项不算通过；原生快捷键检查不等价于完整 GPU 或全部应用回归。
- 本轮仅调整交互、显示及偏好，不修改 MTF／FWHM 等定量公式。
