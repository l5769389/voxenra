# 页面样式与操作习惯复核 · 2026-10-29

## 结论与范围

基于 `1c73351` 加当前尚未提交的 UI 调整进行审核。本轮不修改业务实现。整体配色、字号层级、按钮风格已较一致；主要问题集中在空间不足时的页签布局、操作反馈、旧文案，以及重复说明。

检查方法：macOS 原生 Qt 窗口截图、实际点击与状态断言，以及对应 QML/Python 实现审查。使用合成影像、隔离的测试设置，未操作患者数据。主要窗口为 1280×820；较矮窗口实际为 1280×720，受应用最小尺寸约束，不能当作 1000×600 验证。截图为高分屏物理像素尺寸。

以下 P2 表示建议修复的常规缺陷或明显交互问题；P3 表示可排期的呈现优化。本轮未确认新的 P1 问题，但不代表所有流程均无 P1。

## 呈现与操作习惯优化

| 页面 | 现状 | 建议 |
| --- | --- | --- |
| 调窗、数值编辑面板 | “点击应用或按 Enter 一起提交所有数值；Esc 取消本次编辑。”常驻占用两行，与“应用”按钮重复。 | 简化为“Enter 应用 · Esc 取消”；详细编辑规则放手册。 |
| 外观设置 | 界面大小说明、左右按钮说明文字包含重复解释。 | 保留影响使用的“重启后生效”等内容；独立开关的默认值无需再用整段描述。 |
| 工具栏设置 | 多处重复介绍拖动、排序和保存。 | 留一处简短指导，保存/取消状态明确；键盘替代方式放辅助说明。 |
| 设置导航 | 标题“工作区设置”下实际包含全局外观、输入、AI、更新等。 | 使用“设置”更符合范围，避免理解成仅影响当前工作区。 |
| MIP | 投影开关关闭时，模式和厚度仍呈可操作样式。修改参数不会自动启用投影，画面不变。 | 关闭时禁用参数，或明确表现为待启用参数。代码与 `mpr-mip.png` 确认，属于操作反馈问题。 |
| 伪彩列表 | BWInverse / BW Inverse、BlackBody / Black Body、HotIron / Hot Iron 很难区分。 | 改善显示名称并增加色条预览。必须保留底层标识和工作区兼容性：两组同名近似项的 LUT 实际不同，不能直接合并。 |
| 4D 播放 | 面板称“相位”，滑块悬浮文字硬编码 `Phase N`，与其他位置“时相”不一致。 | 统一为“时相”，并纳入翻译；FPS 可显示为“帧率”并保留单位。 |
| PACS 查询 | 查询字段未绑定 Enter 执行查询。 | 在满足查询条件且未忙碌时支持 Enter；保留查询按钮。此项来自代码审查，本轮未连接真实 PACS。 |
| 标签页 | 每条标签同时展示英文名称和极相近的关键字，占据三行。 | 专业字段需保留，但可提供紧凑显示，把关键字放详情或可选列；不是必须删除的信息。 |
| 手册·窗模板 | 首屏优先讲 JSON、内置清单、迁移等，常用操作被挤到下面。 | 先展示“选择、收藏、编辑、应用”，文件结构与迁移移到高级部分。 |
| 手册·PACS/导出等 | 整窗截图展示中央小弹窗，目标区域过小，且图片把步骤推到下方。 | 改用目标弹窗或操作区域裁切图；总体概览才使用整窗图，保留点击放大。 |

必要的错误原因、隐私保护、删除/恢复边界应保留，不能与冗余操作说明一起删除。

伪彩核对：`grayscale-inverted` 与 `bwInverse` 的 256 项颜色一致；`blackbody` 与 `blackBody`、`hot-iron` 与 `hotIron` 各有 254/256 项不同。只能调整呈现，不能以名称相近为由更改映射结果。

## 复核产物与建议次序

截图、状态 JSON 和临时原生审核脚本位于 `build/style-audit-20261029/`，为本地忽略产物，不随版本发布。

- `test_audit.py`：17 个设置分类、31 手册首屏、2D/MPR/分析入口及折叠/搜索状态检查。
- `test_findings.py`：导入按钮派发、工具栏草稿丢失、当前页签裁切、2D 播放面板。
- `test_extra_views.py`：标签、平铺、对比、融合和 4D 播放面板，以及补充主题抽查。
- `verified-findings.json`：按钮派发、草稿前后顺序、页签可视几何。

建议先修复页签可见性/重叠、按钮名称与行为、草稿与折叠状态；然后修正文案与搜索/编辑反馈；最后精简说明、调整手册截图及信息顺序。无需为了此次审核再重排整个右侧工具栏分类。

验证记录：上述三个脚本最终分别为 1 passed、1 passed、2 passed；未收集到 QML 警告。存在第三方 SWIG 的弃用警告。临时脚本调试期间修正过定位器与中文键盘输入方式，不将这些脚本问题计作应用缺陷。`git diff --check` 通过。浅色和石墨主题补查了窗模板与工具栏布局，未见新增的对比度或文字溢出问题；页签第二行重叠在两个主题中均可见。

页签几何补证：`tab-text-geometry.json` 中平铺与对比的患者字段均为 `patientWidth: 0`、`patientVisible: true`，日期字段从 `contextX: 0` 开始，结合截图确认文本重叠并非短暂加载状态。

## 后续修复与验收（2026-10-29）
