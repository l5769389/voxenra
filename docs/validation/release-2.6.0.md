## 审核修复

独立整体代码复核发现：空气 ROI 参数输入的最大直径仅受图像边界约束，未计入水模外净空。已补入外部净空约束，并以实际参数编辑路径回归：超过 30 mm 的输入被限制，合法 28 mm 输入计算完成。修复前用例失败，修复后 QA 尺寸/分组 15 项通过。控制点缩放原已有相应约束。

复核范围不扩展临床合格阈值或自动识别算法；不变更工作区容器格式。Windows 增加原生 Direct3D 标量渲染测试，不能以软件回退通过代替 GPU shader 验证。

补充原生复核修复：子按钮框延迟 LanguageChange 会在父对话框翻译后恢复系统标准文案。现监听子控件事件并重新应用 Enter/Esc 提示；测试等待真实呈现稳定，不依赖固定 30 ms 初始化时长。补齐 6 个教程图片资源清单条目。正方形视口测试兼顾当前屏幕无法容纳大主视口时的显式失败及可容纳小视口的成功路径。

真实 2.5.0→2.6.0 升级中发现旧工作区读取回归：旧 QA 设置、圆形结果及汇总缺少本版新增字段，通用数据校验因此拒绝恢复；即使未使用 QA 的旧视口也受影响。已仅为这些已知新增字段补入兼容默认值，保持旧尺寸、指标和协议含义，不放宽未知字段/错误类型校验。新增旧版序列化格式回归，并用实际 2.5.0 保存的五页签工作区复验；失败候选不用于发布，全部平台测试与安装包重新生成。

完整回归另发现工作区重建时，旧视口销毁过程可能读取已经释放的设置对象。比例尺绑定现对完整属性链检查可用性。Windows 原生测试补齐小屏幕前提：输入测试先确保搜索框可见并获得焦点；图片比较使用无边框窗口保证实际画布尺寸；教程检查控件不重叠、不越界；屏幕只有应用最小尺寸时，正方形视口必须明确报告无法调整。保留像素误差、GPU 路径及实际焦点断言。

高分屏软件回退复核发现 `Image.sourceSize` 被再次乘以屏幕倍率，2 倍屏幕实际向提供器请求了 4 倍逻辑尺寸，既增加内存，也引入二次映射误差。改为向 Qt 提供逻辑尺寸，由 Qt 统一应用倍率，仍限制物理分配上限。修复前渲染回归最大差异为 2/255，修复后软件与 Metal 均通过 1/255 逐像素容差，并断言软件提供器收到的尺寸与实际画布一致；原始采样数组不变。

Windows 全量测试另发现验收环境问题：离屏 FreeType 缺少原生中文字体回退，5 项 QA PDF 文字断言失败，而同一提交的原生 Windows QA PDF 测试全部通过。报告测试现分别覆盖英文和中文，离屏 Windows 保留全部英文内容断言，中文项仅在原生 Windows 阶段核验，不把跳过计作通过。主题测试在临时小屏幕及英文截图之后完整恢复桌面约束、语言和窗口尺寸，再比较原影像状态。原生流水线补入 QA 控制器及主题测试，产品源码未因这些环境差异而调整。
