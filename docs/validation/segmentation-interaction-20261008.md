## 修改范围

- 画笔和橡皮只在体素实际改变时分配新掩膜、刷新预览；以 16 ms 单次定时器合并密集预览请求。松开时仍处理最终坐标，取消不写入历史结果。
- 移除大号“新建分割并绘制”按钮；分割管理旁的加号立即创建并选中空分割。无分割时首次绘制自动创建，切换工具不创建分割。加载未就绪或时相切换期间不绑定旧来源。
- 教程入口移到切面范围旁；工具、范围按当前语言文字的实际宽度优先同排，仅空间不足时分行。单位框按文字宽度收紧，避免直径标签过早换行。撤销、重做移至数量行，保留独立按钮及快捷键提示。
- 新增、撤销、重做采用统一 SVG 线条图标；显隐和删除复用现有图标。
- 整理测量、标注、导入导出、播放、布局、显示映射及设置的重复说明，详情收进帮助入口。错误、单位、状态及 SEG/SR 非匿名导出提示保留。上下文帮助随模式或退出设置变化。
- 导出面板的长标题和选项可换行；窄侧栏按钮单列，宽侧栏双列。修复英文长标题将手册入口挤出窗口的问题。

桌面工具的坐标拖动未能可靠路由到目标视口，本轮没有据此宣称人工画笔手感或 GPU 帧率验证通过；绘制路径及预览连续性由实际 QML 指针回归覆盖。

## 性能证据与边界

`tests/manual/benchmark_brush_preview.py` 使用合成体数据，对三平面预览测量 CPU 时间。40 个指针样本中，逐变化刷新产生 20 次预览；同一事件循环突发输入合并为 1 次预览。预览计时包含最终渲染成本。

本地一次采样中，突发输入处理的中位耗时约 0.48 ms，最终三平面渲染约 21 ms。数据保存在 `build/segmentation-interaction-20261008/after.json`。这不是实际刷新率，也不代表持续拖动永远只渲染一次；不同体数据、GPU 和窗口尺寸仍影响手感。较早的 before 基准与当前掩膜裁剪条件不同，不据此计算速度提升倍数。
