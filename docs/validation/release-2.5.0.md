# Voxenra 2.5.0 发布验收

2026-11-10。依据 [发布清单](../release-checklist.md) 核验。本文件在发布完成后补入最终提交、平台测试、附件校验及网站结果。

## 发布内容

从 2.4.0 升级，包含双指缩放、视图与操作快捷键、有效像素统计、绘制与边框修复，以及 MTF 自适应取样和矩形选区、页签复用、最近路径和影像来源弹窗重构。

中英文发布摘要已按固定格式更新。旧 MTF 结果保留原值，主动重算才使用当前算法；110% 表示内部积分范围的比例，不是准确度承诺。未继续发布已经移除的敏感性提示和 90% / 100% 日常对照功能。

README、图集、操作手册、网站取图来源及资源清单已更新。原生应用使用匿名演示序列或合成点源重新捕获中英文测量、快捷键、工作区、影像来源与 MTF 页面；工作区对话框从其自身窗口读取，未使用桌面区域截屏。新文件名避免沿用旧图缓存。

## 签名与未覆盖范围

本机只有 Apple Development 身份，没有 Developer ID Application 分发证书。本版 macOS 沿用 ad-hoc 签名，未经 Apple 公证；Windows 未配置 Authenticode 签名。不会将签名完整性检查表述为 Gatekeeper 或 Apple 信任认证通过。

未在另一台干净 Mac 或物理 Windows 电脑上完成人工安装与全部阅片流程；实体触屏及触控板型号覆盖不完整。MTF 在曲面背景、弱尾部及噪声下仍有局限，不自动判定合格。

## 发布步骤状态

- 版本：项目、应用内版本与锁文件均为 2.5.0，远程最新正式版为 2.4.0，无现有 2.5.0 标签或 Release。
- 发布前的功能回归与原生 UI 验证已有记录；本次将对固定的发布提交重新执行完整测试及相关原生回归。
- macOS 本地打包与包内验证、Windows 同提交 Actions 构建、旧包更新链路、六附件及公开链接核对尚待本次执行结果。
- 下载配置暂时保持 2.4.0，六个附件可下载后才切换主页与 README。
