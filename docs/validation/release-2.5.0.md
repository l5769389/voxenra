# Voxenra 2.5.0 发布验收

2026-11-10。发布提交 `94672e137e9087943b30f5f3084d407bae96923a`。依据[发布清单](../release-checklist.md)核验。[发布说明](../releases/v2.5.0.md)。已于 12:38（UTC+8）公开发布，三个安装包及其 SHA-256 文件齐全；macOS 与 Windows 的 2.4.0→2.5.0 升级验收完成。

## 内容、文档与界面

从 2.4.0 升级，包含双指缩放、视图与操作快捷键、有效像素统计、绘制与边框修复，以及 MTF 自适应取样和矩形选区、页签复用、最近路径和影像来源弹窗重构。

中英文发布摘要已按固定格式更新。旧 MTF 结果保留原值，主动重算才使用当前算法；110% 表示内部积分范围的比例，不是准确度承诺。未继续宣传已经移除的敏感性提示和 90% / 100% 日常对照功能。实际发布摘要的 3 项参数化回归通过，涵盖中英文、三种主题、长摘要滚动、关闭重开及链接。

README、图集、操作手册、网站取图来源及资源清单同步更新。原生应用使用匿名演示序列或合成点源重新捕获中英文测量、快捷键、工作区、影像来源与 MTF 页面；工作区对话框从其自身窗口读取，未使用桌面区域截屏。新文件名避免沿用旧图缓存。图片已逐张检查；本地文档、图片及 405 个资源引用均存在。发布后文档同步修正 README 中旧页签章节地址，使其指向 `workspace.html#step-6`。

## 测试与候选修复

macOS arm64 的最终完整回归：287 个文件，3,928 项，3,835 通过、93 条件跳过、0 失败。条件跳过涉及外部影像样例、PACS / Docker 环境和原生窗口，不计作通过。

原生 Cocoa 专项中，导入、收藏、最近记录、页签复用、MTF、草稿指标、有效像素统计、工作区、更新弹窗和快捷键隔离共 11 个文件、170 项全部通过。另行执行原生缩放锚点验证，按实际系统鼠标坐标校验平移、旋转、镜像及双接触点事件，4 项通过。

原始 13 文件原生测试共 212 项：199 通过、2 跳过、11 失败。11 项均假设 `QCursor.setPos()` 能移动系统鼠标，而当前 Cocoa 自动化环境未执行该移动。诊断中请求位置为 (995, 466)，实际鼠标仍为 (554, 370)，应用使用实际鼠标位置符合既定规则。未为满足错误模拟位置而修改生产锚点逻辑；上述 4 项补充验证使用实际鼠标位置。原始 11 项失败不计作通过，实体设备手势仍未完整覆盖。

首次离屏全量运行的 MTF 文件有 2 项缺失 QML 成员的警告断言失败；单独重跑 25 项及原生运行 25 项均通过，构建结束后完整重跑结果见上文。保留首次失败证据，没有据此修改生产弹窗代码，也不声称已修复一个未能稳定复现的问题。

发布前独立执行最近路径测试曾复现 Qt 定时器崩溃，合并执行时因其他模块预先导入 QtQuick 而被掩盖。将图标渲染模块的加载移到导入弹窗模块初始化阶段，避免窗口已启动后再加载；独立 20 项、原生 20 项及最终完整回归均通过。修复包含在发布提交中。

Windows x64 同提交完整回归：287 个文件，3,928 项，3,824 通过、104 条件跳过、0 失败。原生标题栏、导入、弹窗快捷键、中文 PDF 和工作区回归共 80 项通过。异步界面切换三轮各 98 项通过；控制器生命周期 96 项通过、1 跳过；异步呈现 11 项通过、3 跳过；CPR／更新弹窗专项 32 项、报告／关闭专项 49 项通过。专项与完整回归有重叠，不相加宣称覆盖数量。

本地生成最终 arm64 DMG，应用与包名均为 2.5.0。严格深度签名完整性检查及 DMG 完整性校验通过；只读挂载后的应用与构建目录的全部 2,058 个条目按文件摘要、链接及权限比较一致。包内程序的 RLE、JPEG-LS、JPEG 2000 与 JPEG Baseline 四类真实压缩像素解码均通过。

实际发布的 2.4.0 包复制到仓库内独立安装目录，使用进程级隔离配置和只重定向更新请求的本地测试源；未修改旧版更新器及新包内容。旧包健康启动确认通过。关闭自动检查时，在手动点击检查更新前无测试源请求。旧工作区恢复第 39/91 层、窗宽 600、窗位 180，CPR 位置 124.753011 mm；主动保存前工作区逐字节未变。

旧版界面正确展示 2.5.0 摘要；取消后保留版本提示，并记录取消版本；可重新打开。错误校验值拒绝安装；慢速下载可取消，未留下下载包；正常下载与最终 DMG 的 SHA-256 一致。取消退出后仍运行 2.4.0，并保留待安装状态。

用户明确批准隔离安装并运行后，从旧版界面重新下载并执行更新。更新助手返回 success，新版 2.5.0 启动令牌确认成功；安装后的全部 2,058 个应用条目仍与最终构建一致。原工作区文件逐字节不变，外观设置和关闭自动检查的选项保留。

在新版界面打开旧 CTA 工作区，2D 恢复第 39/91 层和 WW 600 / WL 180，CPR 恢复 124.753011 mm 及重建影像。MPR 三平面和 3D 体绘制正常呈现，再次执行 MPR 打开快捷键复用既有页签。另存为 2.5.0 工作区后，新建空工作区并重新打开，五个页签及上述 2D / CPR 状态恢复正常。文件对比中来源序列、原有 2D 状态和 CPR 路径、位置及显示参数一致；仅两个隐藏参考视口的布局高度从 398 变为 195，不计作影像或路径内容变化。

## 签名与未覆盖范围

本机只有 Apple Development 身份，没有 Developer ID Application 分发证书。本版 macOS 沿用 ad-hoc 签名，未经 Apple 公证；Windows 未配置 Authenticode 签名。签名完整性检查不等于 Gatekeeper 或 Apple 信任认证通过。

未在另一台干净 Mac 或物理 Windows 电脑上完成人工安装与全部阅片流程；实体触屏及触控板型号覆盖不完整。MTF 在曲面背景、弱尾部及噪声下仍有局限，不自动判定合格。
