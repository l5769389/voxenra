# Voxenra 2.0.0 发布检查

## 发布内容

以 v1.8.0 为基线，版本入口统一为 2.0.0。主要改动见 [发布说明](../releases/v2.0.0.md)。本地 macOS 构建与 Windows Actions 使用同一发布提交；最终产物和测试记录在本地 `build/release-2.0.0/`，发布后补充结果。

## 文档与素材

- 更新中英文 README 的整体功能概述，补充界面大小、鼠标／快捷键、隐私偏好。
- 主页保留按功能组织的展示，更新外观与操作偏好说明；下载入口在六个发布附件齐备后切换到 2.0.0。
- 重新采集匿名 MR 工作流、导入动画、工作区、导出、深浅及中性深灰主题、外观与窗模板设置、鼠标与快捷键、隐私及空白工作区。
- 重新采集指定螺旋 MTF 第 11 张金属点，展示当前真实 ROI 与结果；未改计算公式。
- 重新生成中英文分割精修、绘制／擦除／撤销动画。截图来自真实 QML 及当前控制器状态，未拼接模拟功能。
- 新增中英文内置手册设置截图并登记打包资源。网站仍由内置手册资源生成。
- 浏览器检查中英文主页、英文设置手册；真实图片显示正常，语言链接正确。

## 发布前检查记录

- 代码独立评审未发现具体发布阻断项。修正发布说明中“画笔／橡皮独立直径”的误述，实际为共用直径、对应名称切换。
- 初次全量回归中，旧外观默认值测试未包含新增 interfaceScale，已修正；本机 PACS 端口与临时 DMG 测试在沙箱中受限，最终回归使用允许这些本地测试能力的环境。
- 文档编辑期间中间测试读到了尚未补齐的翻译键；最终键、双语图片和资源清单已同步，单独手册／语言回归通过。
- 不将缺少依赖或目标系统的跳过项计为通过。源码验证不替代最终安装包验证。

## 限制

本机无有效 Developer ID 签名身份，macOS 包仅 ad-hoc 签名，不宣称 Apple 公证通过。Windows Authenticode、弱 GPU 及多显示器 DPI 实机检查未完成。既往 Slicer 比对见专项报告，不将历史比对标注为本次重新执行。
