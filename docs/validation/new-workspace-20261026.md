# 新建工作区验证记录（2026-10-26）

用户选择在当前应用中开始空白工作区，切换前处理未保存内容。

## 实现

- 主页、工作区窗口提供“新建工作区”，支持 Ctrl+N / ⌘N。
- 当前有未保存影像工作时提供“保存并新建、不保存并新建、取消”。保存失败、取消文件选择或保存期间发生新编辑时保留当前工作。
- 保存、恢复、本地导入或 PACS 任务进行时禁止新建。
- 新建清空全部旧页签（包括独立窗口）、序列索引、搜索、选择及导入重试状态，返回主窗口空白首页。保留个人设置、最近记录、已保存文件和原始影像。
- 清除本会话拥有的恢复副本；清除失败时保留原工作。先前异常退出留下的未处理恢复副本保持保留。
- 同步本地手册和中文、英文、葡萄牙文资源。

## 验证

- 测试先行：初始控制器测试 10 项失败，原因是缺少新建接口；实现后通过。
- 15 个相关回归文件：219 项通过、2 项跳过、0 失败。覆盖保存/恢复边界、退出确认、恢复副本、首页、对话框、近期工作区、快捷键、语言、手册和独立窗口。
- 最终控制器/退出确认/语言检查：72 项通过，包含新增的未完成恢复清理检查。
- macOS Cocoa 原生窗口最终验收：9 项通过。实际点击新建、取消、不保存并新建、保存并新建；实际快捷键；独立窗口清理；三种语言及深浅主题布局。
- 人工检查原生截图：新建按钮、确认框、空白首页可见，文本可读、操作区无重叠。操作后同时断言空白序列/页签/文档状态，并读取已保存文件确认测量保留。
- `git diff --check` 通过。
