# Voxenra 2.0.1 发布检查

## 范围与原发布

以原 2.0.0 为基线，保留原标签 `130b669583cbb202b52212e1aceec1161b32667a` 及其六个公开附件。此前按同版本修订准备的 2.0.0 构建未发布；用户改为 2.0.1 后取消其 Windows 运行，并为最终 2.0.1 提交重新运行完整回归及双平台构建。

## 修复与验证设计

- `QNetworkReply.redirectAllowed` 是 Qt 信号，必须调用 `.emit()`；原测试替身将其实现为普通方法，漏掉了真实重定向问题。增加原生信号测试与真实本地 HTTP 跳转测试，模拟替身同步使用 `.emit()` 接口。
- 用真实更新控制器从 GitHub 下载原 2.0.0 完整 DMG，经历查询、校验文件、附件跳转、下载和 SHA-256 校验；在调用安装器前拦截，未改动用户安装。最终 2.0.1 公开后重新验证新包下载。
- 摘要支持中英文即时切换、英文回退，最多六条；固定模板与发布格式校验脚本已加入清单。
- 覆盖三种主题、窗口布局、滚动复位、完整发布说明链接、取消和退出保护。QML 退出测试与摘要测试采用独立进程，避免同进程旧引擎的 Quit 事件干扰新引擎创建。
- 更新中英文操作手册及截图，保留现有主页功能布局。网站与 README 下载版本在正式附件齐备后更新。

## 限制

旧 1.7–2.0.0 客户端需手动下载安装新包；不能宣称更新服务器可修复旧客户端自身的代码。macOS 仅 ad-hoc 签名，未 Apple 公证；Windows 未 Authenticode 签名。Windows 真机完整升级、弱 GPU 和多显示器检查不由 CI 回归代替。
