# 收藏影像目录

用户最新选择：收藏目录直接显示在“打开影像”对话框上方，不使用下拉菜单。点击收藏进入目录，再通过原有“打开当前文件夹”或“打开所选”确认导入。

收藏区域横向排列、自动换行，最多两行，其余纵向滚动。旁边提供管理入口；空收藏时隐藏该区域，保留“收藏此目录”。管理支持名称、顺序、取消收藏、重新指定路径。原侧栏收藏箭头与菜单已移除，普通导入入口保留。

收藏数据独立保存在应用配置旁的 `favorite-directories.json`，最多 32 项。复用已有数据，不迁移或重置收藏。目录切换复用异步导航，失效目录保留收藏及原有有效路径；启动不探测收藏目录。
