# 工作区、撤销重做与测量导出

## 保存与继续工作

启动即进入「临时工作区」，可以直接导入影像，不必先新建文件。保存后显示工作区文件名。快速浏览时无需专门管理工作区；需要分次完成多序列对照、MPR 定位、测量或裁剪时，再命名保存，之后打开文件继续操作。自动恢复副本用于意外退出后的恢复，不替代用户主动保存的工作区文件。

点击左侧底部的工作区图标，窗口上方显示当前工作区，侧栏收起后仍可使用。首次使用时，底部左侧「打开工作区…」继续已有进度，右侧「保存工作区…」选择名称和位置。保存后，右侧变为「保存更改」，旁边提供「另存为…」。点击「使用说明」可查看手册。保存快捷键为 Ctrl+S（macOS：⌘+S）；另存为使用系统标准快捷键；打开工作区为 Ctrl+Shift+O（macOS：⇧+⌘+O）。Ctrl/⌘+O 仍用于导入影像。

`.voxworkspace` 保存影像引用和操作状态，不复制 DICOM 像素。包括左侧序列、勾选、搜索及分组折叠，页签及其顺序、活动视口、单视口放大、侧栏布局，以及切片／时相、CT 窗值、反色、缩放、平移、翻转、旋转、MPR 平面与 PET 显示参数。已完成的测量、文字箭头、VOI／分割和 3D 裁剪／去床板掩膜也会保存；融合 3D 可独立恢复已保存的配准画面。

开始保存后，在后台生成文件并通过临时文件原子替换；不会覆盖原始影像。恢复会先读取来源并核对序列 UID、实例 UID、尺寸、位置和像素间距，再替换当前页签并依次加载。加载进度显示在工作区面板，可取消后续恢复；失败页签保留错误原因，只提供关闭页签操作。

- **普通文件／文件夹**：记录每个已载入文件的位置；文件在工作区文件所在目录内时同时记录相对路径。
- **压缩包**：记录原始压缩包，包括嵌套压缩包的最外层来源；恢复时重新解压，不引用上次运行的临时目录。
- **PACS**：引用已下载至本机的影像，不保存账户密码，也不会在恢复时自动登录或重新查询服务器。需保留下载文件。
- **文件移动或不一致**：使用「重新定位」一次选择新的文件、文件夹或压缩包，重新核对 UID 和几何信息。也可仅恢复可用序列；缺失项会明确提示，建议另存为以保留原工作区。

工作区包含路径、影像标识和原始标注文字，不等同于匿名测量报告。恢复需要可用的原始影像。未完成的绘制草稿、撤销历史、正在播放的计时器、临时分析任务与拖动预览和 PACS 查询结果不保存；4D 恢复到保存的时相并保持暂停。

工作区窗口使用系统标题栏的唯一关闭控件。窗口与底部打开、另存为、保存按钮位置固定；长反馈在内容区滚动，保存及恢复期间阻止关闭，恢复可通过左下角「取消恢复」停止。

## 新建空白工作区

点击首页或左下角 **工作区 → 新建工作区**，也可按 Ctrl+N（macOS：⌘+N）。有未保存修改时，可选择保存并新建、不保存并新建或取消；只有保存成功后才切换，取消或保存失败保留当前内容。正在导入、保存或恢复时，新建入口不可用。

新建会关闭所有窗口的旧页签、清空当前序列列表和已关闭页签的保留结果，并回到主窗口空白首页。已保存的工作区文件和原始影像不会删除；需要之后继续旧工作时，应先保存工作区。

## 意外退出恢复

自动恢复默认启用。有更改时每 30 秒在本机保存恢复副本；在工作区窗口取消勾选「自动恢复」，可停止自动保存。该开关重启后保留，不影响手动保存、另存为和打开工作区，也不会因为关闭开关而删除已有副本。关闭自动恢复后不再在启动时弹出恢复窗口，仍可从工作区入口处理之前的副本。

工作区窗口与左侧底部工作区按钮显示相同的状态图标，侧栏折叠时仍然可见：灰色时钟表示等待内容，黄色时钟表示有更改待保存，旋转箭头表示正在保存，绿色勾表示恢复副本已更新，红色叉表示保存失败，灰色暂停表示已关闭自动恢复。黄色恢复箭头表示有上次意外退出的副本待处理。悬停查看具体状态、保存时间或失败原因；绿色勾仅表示自动恢复副本已更新，不代表已经另存为工作区文件。保存过程中继续修改时，完成后仍会显示待保存。

恢复副本的文件名固定为 `workspace-recovery.voxworkspace`，位于系统本地应用数据目录。macOS 默认路径为 `~/Library/Application Support/Voxenra/Voxenra/workspace-recovery.voxworkspace`；Windows 使用当前用户的本地应用数据目录。悬停或点击工作区窗口中的「副本位置」会显示完整路径和「打开位置」「复制路径」按钮；点击「打开位置」关闭卡片并打开所在文件夹。悬停状态图标可查看恢复状态及路径。手动保存的 `.voxworkspace` 位于用户选择的位置，与恢复副本分开。

正常退出可选择保存、放弃或取消；选择保存后须成功才能退出，正常关闭会清理本次会话创建或接管的恢复副本。意外退出后，下次启动会提供恢复入口。存在上次尚未处理的副本时先恢复或丢弃旧副本，避免用新会话覆盖它。点击“恢复”或“丢弃”后工作区窗口立即关闭；恢复失败或需要重新定位来源时会重新打开提示。尚未处理的旧副本不会被正常退出清理。恢复副本同样只包含影像引用和状态，因此也需要原始文件或压缩包。

退出提示中的「记住本次选择，下次不再询问」默认不勾选。勾选后，选择「不保存」会立即记住；选择「保存」只在成功写入且没有新更改时记住。取消退出、取消保存或保存失败均不记录本次选择。在「设置 → 工作区 → 退出确认」可随时切换「询问是否保存」「保存工作区后退出」「不保存，直接退出」；选择保存时，临时工作区仍需先指定保存位置。该偏好重启后保留，恢复默认会重新启用询问；打开另一个工作区时的替换确认不受影响。

## 撤销与重做

每个影像页签独立维护最多 100 步、合计约 64 MiB 的历史。Ctrl+Z 撤销，Ctrl+Y 重做；macOS 为 ⌘+Z 和 ⇧+⌘+Z。工作区保存窗口不提供撤销／重做按钮；在目标影像页签中使用快捷键。文本输入框保持自身的文本撤销行为。

记录测量／标注的新增、修改、删除、粘贴，VOI／分割编辑，3D 裁剪／去床板、融合配准及 QA 圆形 ROI 编辑。QA 的移动、复制、删除、重新生成、成功参数修改与重置均可撤销，与同页签测量按操作顺序回退。一次完成的绘制或几何拖动算一步，正在绘制的草稿和 ROI 后台统计刷新不进入历史。翻页、切换工具和查看图像不挤占编辑历史。撤销后进行新的编辑会清空重做分支；关闭页签或打开工作区后重新开始记录。

因内存不足等原因无法记录历史时，窗口底部显示原因和“重试记录”。当前编辑及此前的历史保持保留，撤销和重做暂时不可用，避免跳过未记录的编辑。释放资源后点击“重试记录”；成功后恢复历史操作。多个尚未记录的编辑会合并为一次记录。

## 测量结果导出

在右侧「导出」面板选择「测量 CSV」或「测量 PDF」。默认导出当前页签，勾选「包含所有页签」可汇总当前工作区。正在绘制、修改或计算的对象须先完成或取消，避免输出未提交或过期结果。

- **CSV**：UTF-8 BOM，方便 Excel 打开中文；每项测量／标注／VOI 一行。包含类型、视图、切片（从 1 开始）、可判定的时相、平面原点和方向，以及适用的长度 mm、角度、面积 mm²、体积 cm³、像素／体素数、均值、SD、最小／最大值、单位和有效分割阈值。不适用或未知的数值留空，不以零代替。文本字段防止被电子表格误作公式。
- **PDF**：按结果编号分页排版，可附按测量来源采样平面独立渲染的参考图及测量轮廓；同一平面合并配图，并标注对应编号。参考图不包含三维截图；需要导出当前三维画面时使用「导出 PNG」。统计来自提交的像素／体素计算结果，不根据窗宽、伪彩或截图重新计算。
- **匿名**：沿用面板上方「匿名导出」，默认勾选。患者和序列名称替换为报告内编号，省略真实 ID、DICOM UID、路径及自由标注文字。参考图使用没有四角文字的影像层；源数据明确声明像素内含身份内容时拒绝附带匿名参考图。像素内的身份文字不会自动擦除。

CSV 适合进一步统计，PDF 适合查看与分享；两者不会修改影像或测量对象。

面板中的「查看导出说明」打开操作手册。完成后点击高亮文件路径，macOS 在 Finder 中选中文件，Windows 在文件资源管理器中选中文件；长路径会省略中间部分，悬停可查看完整路径。文件被移动或删除时会提示无法定位。

## 自由形状与 DICOM 结果

在「测量」中选择「自由形状 ROI」，逐次单击添加至少三个控制点，生成经过各点的平滑闭合轮廓；移动鼠标只预览，点击起点、双击或按 Enter 完成，Esc 取消。拖动控制点调整形状，拖动内部整体移动；会造成交叉的落点和拖动不改变已有轮廓。面积、周长和灰度统计均以平滑边界及实际像素间距计算；CSV/PDF 同样使用这些结果。支持复制粘贴、撤销重做和工作区保存恢复；旧工作区中的折线 ROI 保留原有轮廓。

在「导出 → DICOM 分割与结构化报告」选择：

- **导出 SEG**：导出当前页签、当前时相的已完成分割，同一源网格的区域保存为多区域二值 SEG，重叠部分保留；大数据分批输出。
- **导出 SR 报告**：导出当前页签的数值测量，并同时生成当前时相分割／VOI 的关联 SEG。报告采用 TID 1500，每个 SEG 对应分割统计 SR，平面测量另存 SR，保留位置、单位、体积及区域引用。

SEG/SR 保留患者信息与原影像关联，不应用上方的匿名或全部页签选项。需要可用且几何信息一致的原始 DICOM；空区域、未完成计算、无法定位的多帧来源和投影视图测量会明确报错。导出写入新建结果目录，不覆盖源影像；完成后点击路径打开目录。

实现范围、Slicer/dcmqi 读回结果和合成数据截图见[验证说明](validation/segmentation-export-20260916/README.md)。

## 页签与多窗口

右键页签可在独立窗口打开、关闭、关闭其他页签、关闭右侧或关闭全部；批量关闭仅作用于所在窗口。独立窗口额外提供“移回主窗口”。中键关闭目标页签，Ctrl/⌘+W 关闭当前页签，Ctrl+Tab / Ctrl+Shift+Tab 切换当前窗口的页签。

关闭页签会释放视图，并将已完成的测量、标注、VOI、分割、分析结果和三维编辑保留在当前工作区，无需逐个确认。保留结果进入后续保存和自动恢复副本；即使所有页签都已关闭，退出仍会按工作区的未保存修改状态询问保存。尚在编辑中的内容须先完成或取消；无法创建结果快照时保留原页签并显示原因，批量关闭在所有快照准备完成后才执行。

重新打开相同序列和视图类型即可继续编辑；也可从首页或 **工作区 → 重新打开页签**，或按 Ctrl+Shift+T（macOS：⇧⌘T），依次恢复最近关闭的结果页签。工作区文件重新打开后，已收起的结果仍保持收起，按需恢复。保留的是完成结果，不包含撤销历史；重开后开始新的编辑历史。新建工作区或打开其他工作区会替换当前内容，先统一处理未保存更改。

按住左键拖动排序；拖出应用窗口范围后松开，可在独立窗口阅片。拖到其他窗口的页签栏合并，按 Esc 取消。独立窗口保留影像和右侧工具，测量、裁剪及撤销历史不会因为移动而丢失。

关闭独立窗口会关闭其中的页签，其他窗口继续运行；关闭最后一个窗口时执行退出保存确认。独立窗口右上角“显示主窗口”可重新打开序列管理。

保存及自动恢复副本包含所有窗口中的页签与已关闭页签的保留结果。打开中的页签按主窗口优先、其他窗口创建顺序和窗口内页签顺序保存；再次打开工作区时回到主窗口，不恢复窗口位置与分组。已关闭的结果继续收起，可从重新打开入口恢复。

## 测量与量化记录

测量名称、显隐、锁定和来源采样条件随工作区保存。服务工具的正式 MTF、FWHM、QA 结果与临时缓存分离，保存曲线、参数、ROI、版本和计算时间。重新打开保留原值，用户点击“重新计算”才按当前设置更新；源数据不匹配时禁止复用结果。PDF 参考图按测量来源独立渲染，同一采样平面合并配图，并标注对应编号。

测量列表的局部定位保存为视口独立的采样来源（含时相、平面及投影条件），不改写页签公共导航状态。工作区重开恢复该独立状态；主动切换公共时相或联动平面后恢复正常联动。
