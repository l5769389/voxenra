# 显示设置

左侧栏底部 **设置** 打开工作区设置 Tab。数据源之外，现在提供伪彩、窗模板、十字线、
四角信息、比例尺、测量与标注、ROI 指标七个分类。界面沿用项目的 Theme、按钮和输入控件。
分类可搜索，低对比分组默认展开，可点击标题折叠；本次会话保留分类和折叠状态。
同一参数的数值输入与滑块双向同步，合法输入即时生效；未完成输入暂不提交，无效值在回车或失焦时恢复。

在 **设置 → 外观与语言 → 主题** 选择 **跟随系统**，界面会随操作系统切换深色或浅色。新安装默认使用深色，也可手动选择中性深灰或浅色。影像的窗宽窗位、色表和测量颜色独立于界面主题。

设置修改即时生效并自动保存到 Qt `AppConfigLocation/display-settings.json`，重启后继续使用。
macOS 上通常为 `~/Library/Preferences/Voxenra/Voxenra/display-settings.json`。
首次使用新应用标识时，自动从旧配置目录复制窗模板、布局偏好与 PACS 配置；不覆盖已有 Voxenra 配置，也不移动原始影像。
保存失败会显示错误并保留此前状态；非法或损坏的配置值使用默认值。
每页 **恢复默认** 仅重置当前分类。恢复窗模板默认值会删除该分类的自定义模板。

## 拖拽布局

右侧工具栏拖动左边缘，默认 250 px，限制 220–420 px；设置页导航拖动右边缘，默认 180 px，限制 156–300 px。两处拖动结束后分别保存到 `layout.rightPanelWidth` 和 `layout.settingsNavigationWidth`，重启和切换页签继续沿用。中央工作区和设置内容至少保留 360 px；小窗口临时压缩侧栏，窗口恢复时沿用保存宽度。

应用 logo 与 Voxenra 名称集中显示在 32 px 同色顶部栏，左侧不再重复显示品牌。左侧序列栏收起后保留 52 px 窄栏，显示 40 px 序列缩略图；底部展开按钮恢复此前宽度。窄栏独占布局空间，不与原生 3D 画面重叠。缩略图支持单击选择、Ctrl／⌘ 多选、双击打开 2D，以及完整序列右键菜单。窄栏顶部按数据源设置保留文件夹与 PACS 入口，底部保留手册、设置和展开按钮。窄栏沿用患者搜索范围，显示已折叠分组内的序列；展开后保留原有搜索、分组与滚动位置。顶部空白处拖动窗口、双击切换最大化，窗口边缘可调整大小。

显示范围和影像能力适配见 [显示映射](display-mapping.md)。补充彩色图优先使用源色表，单独提供数值范围与灰度背景调节。

## 伪彩

分别设置普通灰阶与 PET（DICOM Modality 为 `PT` / `PET`）影像的默认伪彩：
BW、BW Inverse、Black Body、Hot Iron、Hot Metal、PET、Rainbow。
预览色带与实际渲染共用同一组颜色控制点。

选择后更新所有已打开的对应 2D、MPR、4D 视图，新打开的视图同样使用该配置。
伪彩作用于调窗后的显示像素，原始模态像素、光标数值和 ROI 计算保持原有数据。
CT 3D 使用独立体绘制模板；独立 PET 3D 打开时采用 PET 默认色表，之后由该页签的三维显示设置独立调整。

## 窗模板

保留现有脑组织、肺窗、骨窗、软组织四个系统预设，可分别启停。
支持新增、编辑、启停、删除最多 20 个自定义模板，每项包含名称、窗宽 WW 和窗位 WL。
模板名称不允许为空或重复，窗宽必须为正值。

CT 调窗二级面板可直接填写窗宽 WW、窗位 WL，点击「应用」或按回车一次性提交；编辑过程中不更新图像。
「保存为模板」将填写值保存为新模板，自定义模板行的删除按钮移除模板而保留当前窗值。
MPR 与 4D 同一页签的三个方向同步预设、输入、鼠标调窗及调窗重置；4D 切换时相后继续沿用窗值，其他页签保持独立。

启用的模板即时同步到所有二维视图的右侧调窗面板。保存模板后，点击调窗面板中的模板
才会应用到当前视口；改变模板列表不会主动修改当前图像的窗值。
视口“重置调窗”继续恢复该序列的初始窗值。

## 十字线

分别设置 AX / COR / SAG 切面的颜色与 1–6 px 线宽。
颜色和线宽表示该切面在其他两个视图中的交线，例如 AX 的设置影响 COR 与 SAG 中的
轴位参考线。三幅预览遵循相同映射。MPR 厚层投影的边界辅助线跟随对应切面颜色。
修改只改变样式，不改变十字线位置、方向或重建几何。

## 四角信息

可整体开关四角信息，调整文字大小、行间距，并选择自动对比背景或统一自定义颜色。
自动模式在 BW Inverse 的浅色画布上使用深色文字，其余深色画布使用浅色文字。

按钮与布局预览同步选择唯一的角，鼠标焦点不会再产生第二个选中样式。
四个角分别选择显示内容，支持添加、移除与上下排序，每角最多 8 项。
提供患者姓名、患者 ID、制造商、模态、检查/序列描述、切面位置、切片号、kV/mA、层厚、
窗宽/窗位、坐标/像素值、缩放、旋转/镜像、实例号、矩阵、像素间距和序列 UID。
筛选框可按中文名称或字段名查找要添加的内容；不存在的元数据不显示伪造值。

多视口布局或小于 640 × 480 px 的视口（任一边低于阈值）按设置字号的 85% 显示，最低 10 px。每条信息独占一行，超宽显示省略号，姓名、ID、坐标和像素值仍按原有字段分行；不会因长 ID 自动换行挤占其他内容。方向字母和测量字号不受影响。

## 比例尺

可开关比例尺并自定义颜色。比例尺显示在 2D、MPR、4D 视口底部中央。
默认最大长度 100 mm（10 cm），可选 1、10、20、50、100 mm；长度保存在 `scale.lengthMm`，旧配置缺少该值时采用 100 mm。
按真实像素间距、适配比例与缩放计算屏幕长度，限制在视口宽度的 25%、160 px 和可用边距内。从 `1、2、5 × 10ⁿ mm` 选择不超过设定上限且能容纳的最大长度，支持亚毫米刻度，标注实际物理长度。
旋转、镜像或平移不会改变长度含义。无可靠标定或没有可用空间时隐藏。

## 测量与标注

**测量精度** 默认保留 **2 位小数**，可选整数（0 位）、1 位、2 位或 3 位。例如 `12.3456` 分别显示为 `12`、`12.3`、`12.35`、`12.346`。该设置自动保存，旧配置补用 2 位；本分类“恢复默认”也恢复为 2 位。

长度、角度、ROI 的尺寸/面积/强度统计、VOI 的体积/统计以及 MTF 和水模 QA 的结果立即使用所选精度。像素/体素数量仍显示整数，无有效结果继续显示缺失标记。小负数舍入到零时不会显示 `-0.00`。CSV / PDF 测量报告锁定开始导出时的精度，后续修改设置不影响正在导出的文件。仅改变结果文本，计算、测量几何、图表数据、阈值输入与工作区保存值保留原精度。


测量、箭头标注和 CPR 路径共用绘制/编辑色、线型与线宽，默认绘制时为浅蓝色虚线。完成后，测量和 CPR 显示金黄色实线，箭头标注显示淡紫色实线。可单独修改标注完成色，也可勾选「跟随通用完成色」统一显示。旧设置中不同于通用完成色的箭头颜色会作为自定义色保留。其他 CPR 路径使用较淡的完成色作参照，选中的控制点通过大小和中心标记区分。
样式作用于已完成的对象和之后绘制的对象，屏幕线宽与字号不随图像缩放改变。
这些设置不改变几何、命中优先级或统计计算。

右侧 **标注** 提供箭头与文字箭头：拖动绘制，释放处为箭头尖端。
选中后可调整端点、移动整条箭头，`Delete` / `Backspace` 删除，`Esc` 取消。
纯箭头模式隐藏文字输入和字号；文字箭头模式显示这些控件。面板不再列出当前切片的标注，仅保留「删除所选」，按当前模式删除选中的箭头或文字箭头。
两种模式均可在标注面板调整线宽（1–6 px）和箭头大小（8–28 px），七种颜色保持单行显示。线宽与箭头大小复用全局「测量与标注」设置并持久保存；纯箭头颜色修改默认样式，文字箭头颜色作用于选中标注及后续新建标注。设置页仍提供样式预览。
“清除标注”只清除当前视口的箭头，“清除测量”只清除测量；全部重置清除二者。
标注与测量仍按切片/采样几何隔离，只保留在当前会话，不写回 DICOM；可导出 PNG 记录可见叠加内容，尚无 DICOM SR 导出。

## ROI 指标

分别开关 Mean、StdDev、Min、Max、Area、宽高和有效像素数；宽度与高度统一开关。
宽高与面积在信息卡尺寸标签右侧上下两行显示，设置仅过滤显示项，不改变已计算的值。
椭圆的 Width/Height 显示横轴与纵轴直径。全部关闭时保留 ROI 标题与轮廓。
MTF 使用自己的分析卡，不受 ROI 指标设置影响。

## 验证

```bash
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software uv run --group dev pytest -q
```

`tests/test_display_settings.py` 验证配置校验、原子保存与恢复、窗模板管理、四角项顺序、
LUT 与颜色图像提供器，以及设置到视口渲染请求的同步。
`tests/test_display_settings_qml.py` 用真实 QML 控件验证七页在 1400×760 和 1000×600 下
加载、恢复默认、保存设置；用合成 DICOM 验证实际伪彩像素、窗模板、MPR，
并通过鼠标事件验证 ROI 指标过滤、比例尺缩放、四角文字和箭头绘制/编辑/删除。


窗口控制使用操作系统原生装饰，macOS 保留系统信号灯，Windows 保留系统最小化、最大化/还原、关闭按钮。Windows 标题栏与当前主题同步。macOS 绿色按钮或 Control+Command+F 进入/退出真正全屏；Windows 使用 F11。系统安全区域（如刘海）由平台保留。实现使用 Qt 6.9+ 的 ExpandedClientAreaHint 和 NoTitleBarBackgroundHint，依据 [Qt 官方窗口说明](https://www.qt.io/blog/expanded-client-areas-and-safe-areas-in-qt-6.9)。

测量和两种箭头标注在有效拖动后松开即完成并选中；在空白处直接拖动可新建下一项，无需“继续绘制”按钮。长度、矩形、椭圆和纯箭头仍支持选中后拖动编辑；角度在第三点完成后提交。所有影像操作使用统一箭头指针，右侧带 18 px 当前操作图标。2D、MPR、4D、平铺、PET 和原生 3D 共用 SVG，逻辑画布 40 × 32 px，箭头尖端 (2, 2) 为落点；按住拖动时不切换为手形或其他布局。

右侧主工具按钮高 36 px、间距 2 px、上下留白 4 px，按可用宽度排列最多六列；采用整数宽度避免最后一项意外换行。折叠按钮使用居中的矢量箭头，不依赖字体基线。

macOS 通过 Cocoa 的 `NSWindow.titleVisibility` 隐藏原生标题文字，保留窗口标题属性与原生信号灯，避免和顶部的 Voxenra 品牌重复。仅在 Cocoa 平台应用，并在窗口状态改变后重新应用；Windows 继续由系统管理标题按钮。


翻页二级面板提供第一页、最后一页、向前和向后 10 页。使用当前视口的切片索引，越界截断；MPR 沿当前切面法线导航，4D 不改变相位，MIP 等不可逐页浏览的视图禁用快捷按钮。缩放二级面板提供 0.1× 至 20× 的滑杆，数字快捷键可直选 1× 至 10× 的整数倍率，1× 表示默认适配大小；保留平移、旋转、窗值和已完成裁剪。

「旋转 / 水平与垂直翻转」字段默认在 2D、MPR、4D 和融合切片的右下角，显示 Rot 角度与 Flip H/V 状态，精简模式也保留。字段可添加到任一角、移除，遵循四角整体开关、字体和颜色设置。平铺宫格只显示切片序号；所有 3D 视图不显示四角文字，保留方向立方体，PNG 同样不包含四角文字。旧版默认右下角布局会补入此项，自定义布局保留；明确移除后重启不会重新添加。


## CT 反白与平铺显示

CT 2D、MPR、4D、平铺及融合切片的调窗面板提供「反白」按钮；高亮表示开启，再次点击恢复。切换不改窗值、源文件或定量数据，在伪彩映射前执行；融合切片只反转 CT 层。重置调窗/全部重置关闭反白；普通 CT MPR/4D 延续同页签的联动和过期渲染拒绝机制。3D 不提供反白，使用体绘制模板和透明度控制显示，CT/融合 3D 保留独立的窗宽窗位输入与模板。

平铺增加伪彩色表选择，使用设置中的默认普通/PET 色表。色表和反白变化只重新映射缓存的模态像素，后续滚动加载的切片使用最新参数。过期渲染不会覆盖当前显示。点击宫格进入 2D 会携带当前窗值和反白状态。

平铺顶部箭头收起/展开患者及扫描详情，保留切片摘要与 2～6 列选择；当前页签记住展开状态。窄窗口顶部操作自动分行，详情以两列排布。收起不会改变列数、显示参数或正常范围内的浏览位置。

## 原生顶部与图标细节

原生窗口使用当前主题的明暗模式。macOS 同时将 NSWindow 背景设为应用颜色，启用透明标题栏，保留系统信号灯、全屏与原生边框。外观更新延续原有窗口状态变化处理。实现依据：[Qt 窗口提示](https://doc.qt.io/qt-6/qt.html#WindowType-enum)、[Qt 颜色方案](https://doc.qt.io/qt-6/qstylehints.html#colorScheme-prop)、[AppKit 透明标题栏](https://developer.apple.com/documentation/appkit/nswindow/titlebarappearstransparent)。

统一图标、设置/关闭/折叠等小图形以及伪彩图标使用 SVG 管线；先以目标物理尺寸的 2 倍抗锯齿渲染，再平滑缩到对应 DPR。标题 logo 随屏幕 DPR 请求纹理，按钮图文垂直对齐；伪彩列表收紧并在调整宽度后重绘渐变预览。


## 0.3.0 交互细节

调窗 WW/WL 输入框使用等宽列与 32 px 固定高度；只有工具栏宽度变化会改变可用宽度，输入负数、小数、长数值或鼠标调窗不会改变输入框尺寸。

测量、纯箭头和文字箭头在提交后立即使用完成线型；选中只保留控制点和删除能力，实际拖动编辑时才使用编辑线型。线条与曲线使用 Qt Quick Shape CurveRenderer 和圆形端点/连接，在 GPU 上按边缘覆盖率抗锯齿；软件渲染继续使用 Qt 的抗锯齿路径。设置导航的「工作区设置」下显示 Voxenra 版本号，与程序和构建包一致。
