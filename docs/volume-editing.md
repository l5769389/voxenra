# 3D 去床板与自由裁剪

去床板是每个 3D viewport 的独立布尔状态，工具入口不改变当前 interaction、active tool 或面板。3D 不再显示 VOI 入口；选择「分割」直接进入左键自由圈选，默认选中「内部裁剪」，也可在绘制前切换「外部裁剪」。松开鼠标后立即应用，不再有选区确认或取消选区步骤。内部裁剪表示删除圈内，外部裁剪表示删除圈外，均贯穿当前视线方向的全部深度。

模式按钮互斥选中，修改模式只影响下一次圈选，不重新裁剪已有范围。离开分割工具后重新进入，恢复默认内部裁剪。裁剪处理中禁用模式切换和再次绘制。底部「清除裁剪」恢复全部裁剪结果并保留去床板状态。

## 数据与状态

`VolumeViewportController` 保存人体保留遮罩、累积裁剪保留遮罩、当前裁剪模式及绘制中的屏幕轨迹。最终可见区域是两个启用遮罩的交集。遮罩不会修改 `DicomVolume.modality_pixels`。关闭去床板只移除人体遮罩；清除裁剪只移除累积裁剪遮罩；全局重置同时清除两项显示效果并恢复内部裁剪模式。

遮罩计算使用 `QThreadPool`，不在工作线程创建 QWidget、渲染器或 OpenGL 上下文。每项任务携带递增 token，重置、换载和销毁使旧 token 失效。计算错误保留当前显示，并在工具栏下显示错误原因。去床板结果缓存于当前 viewport，再次开关无需重新计算。

## 自由选区与空间定位

左键轨迹按逻辑像素采集并限制于视口范围；松开后以 1 像素容差简化轮廓，小于 9 平方像素的选区不执行。黄色预览轮廓由 VTK 2D actor 绘制，使用归一化视口坐标，在原生 WindowContainer 中可见且支持高 DPI。有效轮廓在松开时提交一次，并立即清除预览；不存在等待按钮确认的选区状态。

选区记录当时的相机姿态及视口尺寸。每层体素经 voxel-to-patient 仿射、相机横纵基向量、平移及平行投影缩放映射回逻辑屏幕像素。凹多边形用奇偶填充规则判定并包含边界；内裁剪取补集，外裁剪取交集。按层计算，避免分配整卷浮点坐标网格。再次裁剪与上一遮罩求交，已移除的体素不会因另一角度的裁剪而恢复。

绘制途中若相机、视口尺寸或交互发生变化，或视图隐藏、失去焦点，会丢弃尚未完成的轨迹，不自动提交。裁剪已在松开时提交后，焦点变化或相机移动不影响计算时保存的空间范围。独立的取消选区按钮、Esc 取消选区及等待确认接口已移除；需要恢复结果时使用清除裁剪。

## 去床板范围

仅对 CT 启用。选择最接近患者头脚方向的数据轴逐层处理，支持倒序与轴置换。先以 -500 HU 阈值提取组织并填充封闭孔洞，再用约 5 mm 半径的矩形腐蚀分离薄支撑物及窄接触，按连通区域的物理面积和长宽比筛选人体核心，膨胀恢复轮廓并填孔。保留多个足够大的区域以支持分离的双腿、手臂。扫描端部没有有效核心的层使用最近有效轮廓。

这是显示用的启发式轮廓估计。它不提供精确解剖分割，宽接触、厚床垫、极端倾斜、扫描边缘的小结构或非人体模体可能表现不佳；关闭开关即可恢复。没有可识别的人体区域时返回错误并保持未启用，不输出全空遮罩。

## 渲染与验证

使用 VTK GPU volume mapper 的二值遮罩（0 删除、255 保留），继承原体数据的尺寸、间距、原点和方向。遮罩不通过替换 HU 值实现，因此切换窗值、Composite、MIP、Additive 模式时删除区域不会重新显现。体数据及遮罩只在变化时上传，交互和静止均保持固定采样设置。

`tests/test_volume_edit.py` 验证 CT 模拟床板、窄接触、肺内空气、分离双腿、轴置换、凹选区、边界、斜位各向异性体数据的 VTK 投影一致性、默认模式、松开自动提交一次、处理中锁定、累积裁剪、状态组合与过期结果。`tests/test_volume_panel_qml.py` 验证实际模式按钮、默认选中、没有 3D VOI/取消入口、禁用状态和底部重置。`tests/manual/smoke_3d.py` 在真实桌面/OpenGL 下验证自由轨迹、绘制时可见轮廓、松开自动应用内外裁剪，以及全空遮罩在六种模板下均不显示影像。
