# PET MPR 与 PET/CT 融合

## 使用

- 选择经典静态/全身 PT 序列，点击 MPR：轴位、冠状位、矢状位三视图，布局与 CT MPR 一致；不需要配对 CT，也不额外计算 MIP。
- 点击序列左侧复选框多选一个 CT 和一个 PT，再点击「融合」或右键「融合浏览」，直接进入工作区。也支持 Cmd/Ctrl + 单击；普通单击选中单个序列，右键保留已选组合。选择顺序不影响固定/移动层。
- 只选一个 CT 或 PT 时，「融合」打开配对对话框：固定展示已选序列，只列出同患者的另一种模态，按同检查、共享空间坐标优先排序，预选首个可用候选。不可构建体数据的序列显示原因，不能确认。
- 患者匹配使用 PatientID + Issuer，不以姓名相似或目录位置猜测。跨检查需要核对确认；其他患者或身份缺失的序列默认隐藏，主动展开「人工配对」后才能选择，且仍须确认身份。
- 融合四格为 CT、PET、融合、PET MIP。前三格固定联动，顶部左侧依次为「轴位、冠状位、矢状位、融合 3D」。不再显示重复的每格标题、方向下拉或联动开关，模态和方向由四角信息标识。前三格同步定位和画面变换，MIP 保持投影方向。
- 默认使用固定屏幕尺寸的小十字：彩色短臂至少 2 个逻辑像素宽，增加 1 个逻辑像素的深色描边，并提亮默认轴向颜色；保留用户自定义颜色及更大的线宽。普通阅片工具下点击切片定位；按住十字中心或短臂始终优先移动定位点，包括调窗、测量、标注和配准工具。操作在鼠标按下时锁定，抓住短臂不会跳到中心，回图不改变拖动参考系。可切换完整参考线；小十字模式没有不可见的长线旋转命中区。
- 点击 MIP 的有效像素，或抓住 MIP 十字拖动，定位到该射线上最大值所在的物理位置；拖动同样优先于当前工具。配准中的低分辨率 MIP 预览不提供峰值定位。MIP 是投影值，不提供二维 ROI/距离测量。

## 显示与定量

PET 使用「0–当前显示上限」，不使用 CT 的 WL/WW 交互。控制上限可输入或点击快捷项；当前上限始终约束在最小值与控制上限之间。快捷项含自定义控制值。

界面将控制上限标为「滑杆上限」，明确它控制滑杆范围；输入在回车或离开输入框时提交，避免输入中间数字反复压低当前显示上限。体积初始化时取最终定量域中各切片预设上限的最大值，避免只用首张低摄取切片的窄窗。之后浏览切片保持整卷统一的显示范围，SUV 不可用时在源活度域重新确定范围。

同一标签页共享 PET 单位、两个上限和重置基线，不同标签页相互独立。切换单位时，上限及快捷项按首次成功加载时的参考比例一起换算；新图像完成前保留旧单位和图像。更新失败仍可查看上一帧，并显示错误提示。

体积逐切片应用 padding、Modality LUT/rescale 和 SUV 计算后再插值。BQML 保存源活度；仅当全部切片可靠时开放 SUVbw，否则整卷降级为 Bq/ml 或 kBq/ml。原生 GML 保留 SUV 类型，不伪造可逆的源活度域。如果切片间转换比例不同，像素仍使用各切片真实比例；显示上限的参考换算不保证所有位置亮度不变。

CT 使用独立 WL/WW 和 HU；融合工作区的 PET 单独视图和 MIP 默认反灰（白底黑高值），可切换灰阶或其他色表，PET MPR 仍采用全局 PET 色表设置。融合 PET 层为 Hot Iron、叠加比例 50%，默认显示定量色条。PET 零值、无效值和覆盖范围之外不遮挡 CT。融合光标分别显示 CT/PET 值；矩形、椭圆 ROI 的两套统计来自最终浮点采样，不来自 RGB 图像。单位或配准变化后按 ROI 几何重新统计，隐藏切面的 ROI 回到该切面时重算。

融合工具栏按「CT 调窗 / PET 调窗 / 伪彩 / 融合比例 / 配准」排列，默认选中 CT 调窗：

- CT 调窗：并排 WL/WW 输入，复用 2D 调窗的预设表格（名称、WL、WW），共享启用的内置及自定义预设，当前匹配项高亮；选中后仅 CT/融合格响应调窗拖动。
- PET 调窗：直接复用 2D 的 PET 强度面板，保留强度范围、滑杆上限和单位，去掉重复的外层标题与说明；选中后仅 PET/融合/MIP 格响应调窗拖动。图标为矢量强度曲线和上限标记，与 CT 半明半暗圆形及伪彩图标区分。
- 鼠标按下时锁定目标，其他模态格忽略当前调窗操作；十字命中始终优先。切换工具结束旧手势。数值输入即时生效，异步回图不覆盖正在编辑的数字。
- 伪彩：显式选择「PET / MIP」或「融合层」；切换目标后用带渐变预览的色表按钮选择。优先显示六种常用色表及当前色表，其余可展开；CT 保持灰阶。
- 融合比例：独立工具按钮，通过百分比输入、滑杆或 0/25/50/75/100% 快捷项设置 PET 叠加。0% 显示 CT，100% 在有效 PET 区域显示 PET。
- 配准：只管理 PET 到 CT 的空间变换。

各工具重置只作用于自身设置：CT 调窗恢复 CT 初始窗，PET 调窗恢复 PET 初始范围和单位，两者互不影响；伪彩恢复 PET 默认色表和融合 Hot Iron，融合比例恢复 50%，配准恢复恒等矩阵。

「视口设置」内用带边框、选中底色、悬停和键盘焦点反馈的互斥按钮选择「小十字 / 参考线」和「精简 / 详细」，作用于当前 PET 工作区四格，默认小十字、精简信息。原有定位标记显隐和信息显隐设置继续生效。

默认精简四角文字，保留姓名、物理位置、显示范围和游标值；融合四格的精简、详细模式都不再显示患者 ID，也不以 Series UID 代替缺失的序列名称。多视口布局或宽度小于 640 px／高度小于 480 px 时，字号按设置的 85% 四舍五入，最低 10 px，例如 12 → 10、20 → 17。每角宽度严格小于视口的一半，每条信息单行显示；长文本（含无空格长串）以省略号截断，不自动换行。PET 工作区比例尺避让底部文字，色条避让左侧上下文字；空间不足 32 个逻辑像素时隐藏色条。四格精简/详细切换即时生效，无需等待影像重建。

四角标签优先使用英文，保留原始姓名和序列描述：融合标题为 `FUSION · AXIAL`（或其他方向），详细模式各列一次 `CT series` / `PET series`，不重复姓名及 PET 描述。CT 网格上的 PET 图像标为 `Reformatted slice`，详细模式另列 `Source images`，避免把重建层号误读为源 PET 图像编号。MIP 为 `PET MIP` / `Whole-volume projection`，不显示虚假的切片序号；预览为 `Reduced-resolution projection`。游标使用 `Col` / `Row` 标明图像像素坐标，MIP 值标为 `PET max`。

强度窗使用 `Display range`，区别于实际像素统计范围；`DICOM units` 与 `SUV type` 保留源代码和真实定量类型。`Corrections` 与 `Decay correction` 分行，分别对应 DICOM Corrected Image 和 Decay Correction。源层厚使用 `Source thickness`，不作为重建层厚或 MIP 投影厚度；`Matrix` 与 `Pixel spacing` 描述当前采样图像，按行、列顺序。缺失元数据不占行；未指向影像时游标仍显示 `--`。整数窗值取整后保留末尾零（如 1999.72 显示 2000）。这些标签遵循 [DICOM PET Image 模块](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.8.9.html) 对校正、源单位和 SUV 类型的区分，不改变定量计算。

## 手动配准

CT 固定，4×4 矩阵的方向始终是 `PET LPS → CT LPS`。采样使用逆映射，不按切片号或矩阵尺寸配对。空间参考依据 [DICOM Frame of Reference 模块](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.7.4.html)。

初始使用 DICOM 物理坐标；不同或缺失 FrameOfReferenceUID 时不视为已经核对的配准结果。阅片区不常驻显示配准状态，进入工具但未调整时也不显示进行中或待配准。实际编辑与已应用变换仅由配准面板说明。无重叠、加载失败等实际错误继续显示；没有重叠时可用「中心对齐」或继续调整。

点击独立的「配准」工具进入编辑：PET/融合格左拖为面内平移，右拖绕当前切面法线旋转。数值输入支持 CT LPS 三轴平移（mm）与旋转（°），旋转顺序 `Rz·Ry·Rx`；枢轴在进入编辑时固定为物理十字线位置。Esc 或切换到调窗、平移等工具会退出编辑并保留变换；「重置配准」恢复初始恒等坐标变换。画面平移/缩放/旋转与配准矩阵分别保存。

拖动和输入过程中持续更新 PET、融合与 MIP。切片保持完整采样网格；MIP 预览限制到 128×128、最多 64 个深度样本，并明确标注 `PET MIP · Preview` / `Reduced-resolution projection`，暂不提供投影值读数和点击定位。松开鼠标（含最后释放点）后提交完整精度结果；数值输入停顿 180 ms 或提交时同样细化。若上一轮完整 MIP 仍在计算，新手势会在采样边界取消它，优先开始新的预览；连续移动不会取消执行中的预览。预览和完整 MIP 使用独立缓存。旋转依据按下时的切面几何和固定枢轴，避免回图改变当前手势的参考系。

保存/加载使用本地 JSON，不是 DICOM REG。版本 1 包含固定/移动 Series UID、FrameOfReferenceUID、两卷几何指纹、变换方向、矩阵和枢轴。序列或几何不匹配、非有限值、非刚性矩阵和损坏文件均拒绝加载。

## 独立三维标签页

四宫格上方「融合 3D」打开与当前融合页签关联的独立三维页签。再次从这个四宫格点击「融合 3D」，会返回对应的三维页签。保留四宫格以便阅片与定量，三维作为热点和解剖结构空间关系的辅助观察方式，不默认扩成五宫格。这个布局是本项目的设计选择，并非行业要求。

三维页内可切换「CT 3D / PET 3D / 融合 3D」，支持旋转、平移、滚轮缩放和六个标准观察方向。右侧「三维显示」分别控制 CT 组织预设/不透明度，以及 PET 阈值/不透明度/色表。PET 范围和单位取自四宫格最后成功提交的结果，CT/PET 的透明度独立于二维融合比例。重置三维显示只恢复三维预设，不改变配准或定量像素。

使用 VTK GPU 多体积直接体绘制：CT 与 PET 保留各自浮点强度、物理网格和传递函数，在同一条视线中按深度合成，PET 应用 `PET LPS → CT LPS` 矩阵；相机初始范围包含两卷变换后的边界。该功能不生成分割网格模型，三维阈值仅用于显示，不作为病灶分割或体积测量。

三维复用已解码体积，并在二维完整重建成功后同步配准和定量单位；交互 MIP 预览不会成为三维数据源。标签页切换保留相机和显示参数。关闭来源四宫格后，三维保留最后快照并明确标示；从序列列表再开同一对序列，会得到独立的融合页签；在新的四宫格中点击「融合 3D」，可以查看新页签的配准结果。硬件需要支持 VTK 多体积 GPU 体绘制；本轮已用原生 Qt/OpenGL 窗口验证，未承诺软件渲染回退。

## 独立 PET 3D

选中 PET 序列，点击左侧 3D 图标或右键「3D 视图」即可打开；无需 CT、MPR 或融合页签。从序列列表再次打开同一序列，会新建独立的 PET 3D 页签。要回到已有视角，直接点击原页签。

采用单体 GPU 体绘制，支持旋转、平移、缩放、六方向、三维显示、裁剪、PNG 导出和重置。PET 三维显示提供可用定量单位、显示上限、低值隐藏阈值、色表和不透明度；数值输入按回车或结束编辑提交。初始范围与 PET MPR 一致，默认隐藏上限的 10% 以下、不透明度 80%，初始色表来自 PET 偏好。单位缺失时不提供该选项，单位转换按真实比例同步换算显示上限及阈值，支持小于 1 的数值。

解码和单位转换在后台执行，使用统一 loading、关闭和失败重试流程；过期任务无法覆盖较新的视图。单位/色表切换保留相机与当前裁剪。裁剪采用 CT 相同的沿视线圈选及内部/外部移除方式，仅影响当前页签，不修改源文件或其他视图。清除裁剪恢复遮罩；整体重置同时恢复初始视角、单位及显示参数。PNG 使用当前原生渲染画面，包含裁剪效果；不提供 PET 3D DICOM 导出、CT 窗模板或去床板。

## 支持边界与验收

要求至少两张经典单帧静态/全身 PET，以及有限、完整、一致的规则正交空间网格。拒绝重复层位、不等距、层间偏移和不一致的方向/矩阵/FrameOfReferenceUID。CT 与 PET 之间允许不同方向、尺寸、间距和覆盖范围。

不包含自动/非刚性配准、动态或门控 PET、Enhanced PET、三维分割测量、DICOM REG 导入导出，也不新增压缩解码依赖。当前验证使用合成 DICOM、实际 QML 事件和原生 OpenGL，不替代真实设备数据验证或临床验证。

后台按视口/融合标签合并为一个执行中请求及一个最新待执行请求。配准手势允许同一交互内已完成的预览先显示，避免连续拖动期间所有结果被丢弃；预览不会回写较新的目标矩阵或成为失败回滚基线。切面、单位、强度、伪彩、比例变化或新手势会使旧交互结果失效。完整结果仅接受最新请求；精细重建失败时同步恢复上次完整结果的矩阵、像素、几何、ROI 与 MIP。体积、浮点切面和 MIP 峰值位置有缓存；仅调强度、色表或叠加比例不重新采样。MIP 按整个体积深度逐平面累积，内存不随投影深度线性增长。

定位采用独立交互周期：主线程立即同步四格标记，后台定位请求最多每 33 ms 提交一次，保持一个执行中和一个最新待执行请求。完成的同手势影像可以显示，但不回写最新定位目标；释放时重新校验体积指纹并提交最终全精度位置，失败回退到最后一次完整成功结果。手势期间复用已验证体积，定位重建始终使用完整采样精度，和配准的低分辨率 MIP 预览相互独立。

切片缓存键由实际物理采样网格、体积版本、定量域和配准矩阵组成，不包含整份定位状态；同切面内移动只改变标记。MIP 投影、MIP 着色和切片显示分别缓存。每帧携带影像内容版本，未变时不复制 QImage、不改变 imageSource、不刷新 ROI。真正切面变化仍重新采样 CT/PET，并更新融合像素和定量结果。缓存网格键按 1e-7 mm 去除浮点消减噪声，实际几何和采样精度保持不变。

性能数据、复现方法与截图见 [验证记录](validation/pet-fusion-workflow/README.md)。

自动化验收包括定量域与逐切片比例、NaN/padding、不同网格刚性对齐、MIP 定位、双层 ROI、单位切换回滚、请求合并、配对与身份确认、JSON 校验，以及真实 QML 四宫格/按钮/输入/鼠标配准事件。运行：

```bash
PYTHONPATH=src QT_QPA_PLATFORM=offscreen uv run pytest -q
```

本轮业务与交互整理基于 `main` 的 `91adbf1`，独立 worktree 为 `qt-dicom-viewer-pet-fusion`，分支为 `codex/pet-fusion-workflow`。

## 业务与设计依据（2026-09-07）

完整流程为：选择互补序列 → 核对患者/检查 → 按物理坐标建立初始融合 → 用三个平面核对对齐 → 必要时进入配准 → 退出配准后联动阅片、调窗和定量测量。
