# 2D CT 水模 QA

## 操作与范围

选择 2D CT 切片，打开“分析 → QA”。水模 QA 分为 **CT 值与均匀性**、**水中噪声** 两组；**模体外空气**为独立可选取样。各组保留自己的 ROI、尺寸和结果，切换组不会重建或删除已有数据。画布只显示并编辑当前组。

检测到完整、近圆形且均质的水模后，CT 值与均匀性组生成中心及四周五个小圆，直径初始为检测水模直径的 **10%**，外围 ROI 外缘距水模边缘 **10 mm**；水中噪声组生成独立中心大圆，直径初始为水模直径的 **40%**。这些可编辑的取样几何参考 WS 519—2019 §5.6，不代表软件自动执行完整验收或判定合格。未检出水模时，仍提供五个普通圆形 ROI 供手动取样，不输出水模汇总；模体外空气不依赖检测成功。

“尺寸与取样条件”默认收起，直径支持 0.1 mm。直径上限由本组剩余 ROI、影像和水模边界计算，噪声大圆不受五个小圆的间距限制。只保留中心小圆时可扩大取样范围。改直径保留位置、副本和删除状态；改边距只移动仍保留的外围初始区域。**计算**保留布局，**重新生成当前组 ROI**只替换当前组，其他组不变。

单击当前组圆形 ROI 后显示四个控制点，拖动控制点独立调整该圆直径，圆心不变；按住圆内区域拖动可移动圆心。拖动时只预览，松开后计算并记录为一步撤销；Esc 或切换组/工具取消尚未提交的修改。修改参数期间保留面板高度和圆的位置，暂时隐藏旧统计，避免滚动位置跳动。水模内的初始五个小圆不能互相重叠，大圆与小圆属于不同取样组，可以重叠。副本不参加五点汇总；独立噪声 ROI 不提供复制。有效 ROI 至少包含 16 个像素，不能越出图像、包含无效填充值或非有限像素。无效编辑保留上次结果。

模体外空气：首次切入当前切片的空气页时，若已检测到完整水模，会尝试在有效模体外空气中自动放置一个圆。无法可靠定位时提示手动添加；点击“添加空气 ROI”后，在有效影像中、水模外部单击放置，Esc 取消。默认直径 **20 mm**，可调整、移动、复制和删除。用户删除后不会因切换组而重新生成。它不参与水 CT 值、均匀性或噪声归一化。自动定位按几何净空排序，避开水模、外壳、支撑物、无效像素和无法确认来源的常量背景；不挑选均值最接近 −1000 HU 或 SD 最小的圆，也不剔除实际圆内的高低值。人工添加仍允许独立于水模检测使用。

QA 结果按视口和切片保留，调窗、旋转、镜像、缩放和平移不改变统计。近期计算最多缓存 16 层，完整结果保存在工作区记录中。底部重置清除本视口 QA 记录、缓存和轮廓，并停止自动分析；普通测量和 MTF 独立保留。结果面板优先显示本组指标，参数默认折叠，重置固定在底部。

## 自动定位

计算输入为已经应用 DICOM Rescale Slope/Intercept 的原始 CT 模态像素及原始 PixelSpacing，显示用的灰度图、窗值和回退间距不参与。检测阶段先在宽水等效 HU 区间提取连通区，再从各候选轮廓通过确定性 RANSAC 和最小二乘拟合物理空间圆，检查环周支持和完整性，并用内部像素判断候选是否为均质水等效区域。可容忍小噪声和窄连接支撑物，非等距像素先转换为毫米。

此识别针对完整、近圆形、半径至少 20 mm 的均质水模横断面。裁断轮廓、明显椭圆、多个大小接近的候选、多材料模体层或没有水模的图像可能无法自动识别，此时转为普通圆形 ROI 取样，不推测缺失边缘或显示水模五点汇总。检测阈值只影响定位，不是合格判据；取样不会剔除 ROI 内的高低 HU 值。

普通取样仍要求真实像素间距、有效 CT 像素及足够的空间／采样数；每个 ROI 至少 16 个像素。缺少间距、像素无效、范围不足或检测器执行异常仍显示实际错误，不当作有效取样结果。

圆形 ROI 采用物理半径逐像素中心判定，统计所有入选像素。左右方向沿原图列轴，上下方向沿原图行轴；显示旋转或镜像后标记跟随原图，不改写测量位置。

## 公式与定义

水 CT 值只依赖小圆中心；噪声只依赖独立噪声大圆。删除小圆中心不会删除或改变大圆噪声结果。其余五点指标要求五个初始小圆完整，副本不参加汇总。缺少条件的指标隐藏，不以零代替。

每个 ROI 的标准差采用总体公式 `sqrt(sum((x−μ)²)/N)`。记中心小圆均值为 μ₀，四周小圆均值为 μL、μR、μT、μB，独立大圆标准差为 σnoise：

| 指标 | 计算方式 | 单位 |
|---|---|---|
| 水 CT 值 | 中心小圆均值 μ₀ | HU |
| 噪声标准差 | 独立中心大圆 σnoise | HU |
| 噪声 | `σnoise / 1000 × 100%` | % |
| 均匀性 | `max(abs(μi−μ₀))`，i 为四周小圆 | HU |
| 一致性 | 5 个小圆均值的 `max(μ)−min(μ)` | HU |
| 横向差 | `abs(μL−μR)` | HU |
| 纵向差 | `abs(μT−μB)` | HU |
| 噪声范围 | 5 个小圆标准差的 `max(σ)−min(σ)` | HU |

表格保留像素数、采样面积 `N × rowSpacing × columnSpacing`、最小值、最大值。Δ中心仅用于小圆组，是该 ROI 与中心小圆均值的有符号差；中心删除时显示“—”。一致性描述本层空间差异，不表示跨扫描重复性。噪声百分比使用固定 1000 HU 归一化，不使用接近零的水均值，也不受手动空气 ROI 影响，不作层厚校正。

默认取样几何及噪声归一化参考 [WS 519—2019《X 射线计算机体层摄影装置质量控制检测规范》§5.6.4–5.6.7](https://www.nhc.gov.cn/wjw/pcrb/201902/ca5eb37bd96c4909a24e4d978b2c082d/files/1739781009650_81445.pdf)。软件不自动套用通过/失败阈值。

## 异步行为与验证

后台任务持有原始像素快照。缓存键包括序列、SOP、切片索引、原始间距、数据形状与像素摘要，并结合 ROI 参数。快速翻页最多保留一个运行任务及一个最新待处理快照；返回旧切片、重置、参数变化或关闭后的旧任务不会覆盖当前结果。当前视口最多缓存 16 张切片的数值与几何结果。

`tests/test_water_qa.py` 覆盖物理定位、形状/完整性拒绝、自动与手动五区采样和逐像素公式；`tests/test_water_qa_controller.py` 覆盖线程、缓存、快速翻页、拖动预览/提交/取消、越界/重叠、重置和数据快照；`tests/test_water_qa_qml.py` 用真实 QML 点击与拖动验证五个 ROI、变换后坐标、Esc、手册跳转、参数和小窗口滚动。

`tests/manual/smoke_water_qa.py` 创建三个不同水 CT 均值、带噪声和外壳/支撑物的合成 DICOM，设置非等距 PixelSpacing 及 `RescaleSlope=2, RescaleIntercept=-1024`，通过完整文件加载、worker 和实际桌面 UI 验证 HU、QA、切层、显示变换和重置。测试使用合成数据，实际水模图像的识别表现仍需结合设备与扫描协议检验。

## 复制与删除

小圆和空气统计表每行提供复制与删除，噪声大圆只提供删除。当前组初始 ROI 与副本均可删除，也可选中后按 Delete / Backspace；副本可独立移动，显示自身均值、SD、Δ中心，不参与五点汇总。重新计算、切片往返及工作区保存保留位置、副本与删除状态；需要初始布局时使用“重新生成当前组 ROI”。

QA 圆暂不提供剪贴板复制粘贴；⌘/Ctrl+C、V 用于选中的测量和标注。

## 自动计算与重试

移动或缩放圆后，松开鼠标自动计算；修改尺寸参数也会自动计算。保留“计算”按钮，可按当前区域重新计算或在失败后重试。同样的区域与像素得到同样的数值，不会额外重置圆的位置。

同一层重新计算时保留圆及表格布局，旧数值暂以“—”显示。计算失败会显示原因，分组切换不会抹掉错误提示；“计算”可再次触发后台任务。拖动、计算或等待影像期间暂时禁用按钮，避免重复请求。空气区域自动识别失败后也可以重试；主动删除的空气圆不会自动补回。

## 撤销、重做与保存

移动、缩放、复制、删除 ROI、重新生成、自动添加空气圆、成功的参数变更及重置均接入页签编辑历史。使用 QA 底栏的撤销／重做图标，或 Ctrl+Z / Ctrl+Y（macOS：⌘Z / ⇧⌘Z）；悬停可查看操作及当前系统快捷键。输入框内沿用文本自身的撤销，打开弹窗时不触发阅片区撤销。一次完整拖动记为一步；单击不移动、切片导航、调窗、自动切片分析及未找到空气候选不增加历史，QA 和测量按编辑顺序回退。

工作区保存各层的完成结果、参数、ROI 与来源信息，恢复后保留已存数值；重新计算才使用当前设置更新。旧版共用中心圆的噪声结果会标明旧取样方式，主动重新计算后才生成独立噪声圆。像素或几何不匹配时不复用结果。工作区和已关闭页签保留完成结果，不保存撤销历史。

当前行为与原生界面核对记录见 [圆形 ROI 兜底与编辑](validation/qa-roi-fallback-20261026.md) 和 [结果保留与 QA 编辑历史](validation/workspace-retention-qa-history-20261026.md)。

## 导出报告

点击底部固定操作区的“**导出报告**”图标并选择保存位置。撤销、重做、导出、清除四个图标固定为一行，悬停查看详情。A4 报告包含当前影像及 ROI 截图、可用汇总指标、对应类别 ROI 的统计、位置、直径和采样面积；长表自动分页并重复表头。截图保持当前窗宽窗位和显示变换，隐藏患者身份四角信息、鼠标和圆形控制点；截图显示当前组，表格列明对应类别的取样条件。水模报告包含 CT 值与均匀性、水中噪声两组；模体外空气报告仅包含空气 ROI，不混入水模指标。标题及默认文件名按类别区分，文件名包含切片编号，例如 `Water-QA-slice-001.pdf` 和 `Air-QA-slice-001.pdf`。

报告默认没有软件名称。在“**设置 → 导出 → QA 报告 → 报告软件名称**”填写可选署名，显示于页脚和 PDF 创建者字段；留空取消。报告不自动判定合格。

导出先冻结完成结果并获取匹配截图，再打开保存对话框。截图期间若切片、ROI、分组或显示状态发生变化则中止，防止图与数据不符；保存对话框期间切片变化不会混入已冻结报告。编辑中、计算中或无 ROI 时不可导出。取消不创建文件，成功后可以打开所在文件夹。
