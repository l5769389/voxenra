# 本地文件与压缩导入

将一个或多个 DICOM 文件、文件夹、压缩包拖入 Voxenra 窗口即可导入，也支持直接拖到 CT、PET 或融合的原生 3D 画面。点击首页或侧栏「打开影像」，或使用 Cmd/Ctrl+O，直接进入同一个混合选择窗口，无需先选择导入类型。可按住 Ctrl / ⌘ 同时勾选文件夹、文件和压缩包，再点击「打开所选」一次导入；双击文件夹进入，未选项目时可打开当前文件夹。路径栏支持直接输入路径：回车仅定位，直接点击确认则校验并导入该路径；路径无效时保留输入并提示错误，不会导入旧目录。本地数据源关闭时这些入口禁用。

导入后，首页提供「打开选中序列」进入 2D 阅片；未选择序列时该按钮禁用。「继续导入」用于追加影像。

解压和扫描在后台执行，已有视图可以继续使用；再次点击导入入口可取消，本批完成或取消前不接收第二批文件。导入使用独立任务窗口，显示枚举、解压和 DICOM 读取进度；顶部与侧栏不增加常驻状态条。重复导入按序列和来源实例标识合并，同一序列后续补入的切片追加到原序列。正文 SOPInstanceUID 与文件头 MediaStorageSOPInstanceUID 不一致时，两者共同标识来源，避免将正文编号相同、文件头编号不同的切片误判为重复；相同来源文件的副本仍去重。原始编号与文件内容保持不变，Tag 和工作区恢复使用同一来源区分规则。无后缀 DICOM 也按内容识别。损坏或非 DICOM 文件会跳过；无法解压或没有可用影像时不会加入无效项，可重新选择文件导入。

## 大批量导入

- 枚举阶段显示已发现文件数；解压阶段同时显示已解压体积，读取阶段显示文件进度、识别和跳过数量。总量未知时使用等待进度，枚举完成后显示确定进度。
- 可以在任务窗口或导入入口取消。取消枚举或解压会清理本次临时输出；取消读取保留此前已读取的实例、已有视图与缓存。
- 任务窗口使用系统原生标题栏和无内框的内容区，固定尺寸；进度数字与状态文字不会撑宽窗口或移动底部按钮。长错误信息自动换行，可纵向滚动、选中复制。进行中保留“取消导入”，需要确认结果时底部显示“确定”；失败时同时提供“重试”和“重新选择”。
- 所有文件正常导入后，任务窗口立即关闭。有重复（包括已在列表中的文件）、跳过或取消时保留结果，点击“确定”关闭。失败结果保留，提供重试、重新选择和确定；权限不足、损坏压缩包、文件数量 / 解压体积超限均显示原因。异常原因写入应用日志。
- 解析、排序、重复合并和时相识别在后台进行；序列预览最多约每 0.75 秒更新一次，界面队列最多保留一个待处理预览。最终结果仍完整更新。
- 单次文件上限为 **100,000**，目录中的非 DICOM 文件也计入枚举上限。超过上限时按患者 / 检查拆分目录，减少本次选择后再导入；本批结束前不会叠加启动第二批任务。

## 支持范围

| 类型 | 格式 |
| --- | --- |
| 压缩包 | ZIP、RAR4 / RAR5（含固实压缩）、7z、TAR、TAR.GZ / TGZ、TAR.BZ2 / TBZ2、TAR.XZ / TXZ |
| 单文件压缩 | GZ、BZ2、XZ |

可直接导入包含多层文件夹和多个 DICOM 文件的 RAR 压缩包。RAR 解包库随应用提供，无需安装 WinRAR 或配置外部命令；中文文件名和无扩展名的 RAR 包也能识别。压缩包展开后进入原有 DICOM 扫描与加载流程，不改动影像像素编码能力。

当前不支持加密包与分卷包，请先解密、合并解压后导入。

## 文件与缓存

- 拖入始终使用复制语义，不移动、覆盖或改写源文件。解压输出进入独立的当前会话临时目录。
- 从列表移除或清空序列不会删除缓存，已打开视图与导出仍可使用；再次导入部分切片不会截短已有完整序列。
- 正常退出时先取消 / 等待加载、渲染和导出任务，再清理解压缓存。
- 解压期间取消或失败，会删除本次产生的半成品；扫描期间取消，保留已载入项及其缓存。
- 单次最多 100000 个文件；归档中单文件不超过 8 GiB，累计解压不超过 32 GiB，嵌套最多 3 层，RAR 字典不超过 512 MiB。拒绝路径越界、软硬链接、设备文件、重复冲突文件名。超限数据可手动解压后分批导入。

## 窗值精度

WW / WL 输入框显示最多一位小数，整数不显示 `.0`。回车、点击应用和保存模板都使用相同精度，例如 `167.23147 / 56.995304` 提交为 `167.2 / 57`。输入期间不改变影像；原有固定输入框大小保持不变。
