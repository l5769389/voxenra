## AI 自动分割 / Local AI segmentation

在“设置 → AI”选择已有 Python 环境与模型目录并检测环境，再从 CT MPR／4D 分割面板进入自动分割。默认选择肝脏、脾脏和双肾；部位列表读取所配置 TotalSegmentator 的结构定义，支持搜索和多选。完整原始 CT 当前时相作为输入，窗值和视图裁剪不改变推理范围。

安装包不包含 TotalSegmentator、PyTorch 或模型权重，也不会自动下载它们。需要另行准备 TotalSegmentator 环境与 CT 快速模型；支持按环境能力选择 CUDA、Apple MPS 或 CPU。已实际验证 TotalSegmentator 2.18.0 / macOS MPS。其他版本会检查接口和模型状态，不保证所有未来版本兼容。

结果经过网格与来源校验后整批追加，不覆盖原有分割；可以精修、撤销、保存和交换。工作区恢复不需要推理环境，也不会自动重新计算。当前支持可靠 HU 标定、规则正交网格的 CT 快速模式；不包含 MR、高精度模式或跨时相批处理。自动结果需要核查，演示动画压缩了等待时间，不代表计算耗时。

Configure an existing Python environment and model directory under Settings → AI, then use automatic segmentation in CT MPR / 4D. The structure list comes from the selected TotalSegmentator installation. Packages do not bundle the inference runtime or model weights and do not install them automatically. Only calibrated HU CT on a regular orthogonal grid is supported in fast mode; MR, high-resolution inference, and batch processing across phases are not included. Results are validated, appended as editable segments, and saved with the workspace. Review automatic results before use.

## 安装与兼容 / Installation and compatibility

- macOS Apple Silicon：本地生成 DMG，仍为 ad-hoc 签名，未配置 Apple Developer ID 或公证；首次启动可能需要在系统隐私与安全性中允许。
- Windows x64：GitHub Actions 构建安装版和单文件便携版，未配置 Authenticode 签名。
- 不修改 MTF／FWHM 计算公式；旧工作区继续读取，AI 来源信息使用可选字段保存。
- macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed. Existing workspaces remain readable.

## 验证 / Validation

本机 CT 四器官推理、叠加、精修、整批撤销重做及保存后重启恢复已通过原生界面验证；掩膜、名称、颜色和来源信息保存恢复一致。Windows/CUDA 真实推理及全部器官、真实 4D 推理尚未完成实机验收。发布时的回归、平台构建和附件核验结果另见发布检查记录。

The CT four-organ workflow was exercised on macOS/MPS, including editing, undo/redo, and workspace save/reopen. Windows/CUDA inference, every structure, and real 4D inference have not received native end-to-end validation. Build and regression evidence is recorded in the release checklist report.
