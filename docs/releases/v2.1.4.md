# Voxenra 2.1.4

## 更新摘要
- 新增传统 DICOM PACS 连接、查询与影像导入。
- 优化工具栏分类与拖拽设置，支持常用工具排序和保存。
- 改进阅片信息、窗模板收藏和视图区最大化操作。
- 修复部分工具栏配置及界面交互问题，提升使用稳定性。
- 补充操作手册、截图与演示动画，优化主页加载速度。

## Update summary
- Added traditional DICOM PACS connections, queries, and image import.
- Improved toolbar categories and drag editing, with saved tool ordering.
- Improved reading information, favorite window presets, and image-area maximization.
- Fixed toolbar configuration and interface interaction issues for improved reliability.
- Expanded manuals, screenshots, and tutorials, and improved homepage loading.

## 安装与兼容 / Installation and compatibility

- 提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版。
- macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 未配置 Authenticode 签名。
- 已有工作区与设置继续兼容；工作区仍需保留原始影像。DIMSE 需 PACS 管理员登记接收节点，暂不支持 C-GET 或 DICOM TLS。
- macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed. Existing workspaces and settings remain compatible. Keep the original images. DIMSE requires a registered receiver and does not support C-GET or DICOM TLS.

## 验证范围 / Validation scope

发布检查记录将列出平台回归与产物验收结果。Windows/Linux 真实 AI 推理、崩溃恢复及旧版 Windows 客户端完整点击更新流程未完成实机验收；本地 DIMSE 演示不等同于所有厂商 PACS 兼容认证。

Platform regression and package checks are documented in the release validation report. Native AI inference and crash recovery on Windows/Linux, and the complete update workflow in older Windows clients, remain unverified. Local DIMSE validation does not certify every PACS vendor.
