# Voxenra 2.1.3

## 更新摘要
- 改进工作区新建、保存和页签关闭流程，保留已关闭页签的编辑结果。
- 完善 QA 圆形 ROI 操作，支持自动取样、移动、复制、删除及撤销重做。
- 优化部分界面样式、提示和本地操作手册。
- 修复工作区恢复、分析状态及相关交互问题，提升操作稳定性。

## Update summary
- Improved workspace creation, saving, and tab closing while retaining results from closed tabs.
- Improved circular QA ROIs with automatic sampling, moving, copying, deleting, undo, and redo.
- Refined interface styling, messages, and the offline user manual.
- Fixed workspace restoration, analysis state, and related interaction issues to improve reliability.

## 安装与兼容 / Installation and compatibility

- 提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版。
- macOS 包使用 ad-hoc 签名，未经过 Apple 公证；Windows 包未配置 Authenticode 签名。
- 已有工作区可继续打开；工作区文件仍需配合原始影像使用。
- macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed. Existing workspaces remain supported and require their original images.

## 验证范围 / Validation scope

平台回归与产物验证结果见发布验证记录。Windows/Linux 的真实 AI 推理、崩溃恢复及 Windows 旧版客户端完整点击更新流程尚未完成实机验收。

Platform regression and package checks are recorded in the release validation report. Native AI inference and crash recovery on Windows/Linux, and the complete update workflow in older Windows clients, remain unverified.
