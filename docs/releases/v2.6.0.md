# VoxPlane 2.6.0

分组进行 CT 质量分析，编辑取样区域并导出带图报告；改善影像显示和视口控制。

## 更新摘要

- 应用更名为 VoxPlane；2.5.0 及更早版本需手动安装一次，已有设置和工作区保留。
- QA 分组显示 CT 值与均匀性、水中噪声及模体外空气，圆形区域支持控制点缩放。
- 调整 QA 区域后自动计算，保留“计算”按钮重试；改进指标显示、撤销重做和旧结果恢复。
- QA 可导出带影像截图和统计表的 PDF，区分水模与空气报告，并支持可选软件署名。
- 四角信息支持全局默认与视口独立覆盖；正方形视口可自动调整应用窗口。
- 改善灰度插值显示，原始像素与测量统计不变；修复操作栏焦点下测量与标注的复制粘贴。

## Update summary

- Renamed to VoxPlane. Version 2.5.0 and earlier require a one-time manual installation; settings and workspaces are preserved.
- QA separates CT number/uniformity, water noise, and external air, with control handles for resizing circular regions.
- QA recalculates after edits and keeps Calculate for retries; improved metrics, undo/redo, and historical result restoration.
- Export QA PDFs with images and tables, separate water/air report titles, and an optional software name.
- Corner overlays support global defaults and viewport overrides; Square viewport adjusts the application window.
- Improved grayscale interpolation without changing source pixels or statistics; fixed measurement/annotation clipboard actions when toolbar buttons have focus.

## 中文说明

### 升级须知

升级前保存工作区并保留原始影像。已有设置、测量及 QA 记录继续保留，不自动重新计算。旧版噪声使用中心小圆的结果仍显示旧值；主动点击 **计算** 后，才使用本版独立的噪声大圆重新取样，数值可能变化。请保留旧工作区副本再比较。

应用从 Voxenra 更名为 **VoxPlane**，Logo 保持不变，项目迁移至 **junforge-dev/voxplane**。2.5.0 及更早版本的更新器不能安装改名后的附件，请从 [2.6.0 下载页](https://github.com/junforge-dev/voxplane/releases/tag/v2.6.0)手动安装一次，之后可继续应用内更新。

- macOS：退出旧应用，将 DMG 中的 VoxPlane 拖入“应用程序”。首次启动并确认设置、工作区正常后，可以移除旧 Voxenra.app。
- Windows 安装版：退出旧应用，运行新安装器；沿用原安装位置和卸载记录，替换程序及快捷方式。
- Windows 便携版：退出旧程序，保存新 VoxPlane.exe，运行并核对后移除旧可执行文件。

首次启动会复制旧版显示设置、PACS、最近工作区、恢复工作区和自定义语言文件，不覆盖已有 VoxPlane 设置，也不删除旧数据。工作区格式及影像引用保持兼容；影像、日志和自选文件夹不移动。

### 主要改进

- **分组 QA**：CT 值与均匀性使用中心和四周小圆，水中噪声使用独立大圆；模体外空气单独取样。画布只显示当前组，切换组保留位置和结果。可靠识别到模体外空气时可自动添加一个圆，无法确定时手动放置；主动删除后不会自动补回。
- **圆形编辑**：单击选中后显示四个控制点，拖动调整大小，圆内拖动改变位置。直径上限随剩余区域及边界变化；删除外围圆后可扩大中心圆。松开后自动计算，Esc 取消；底部固定撤销、重做、导出和清除。
- **计算与恢复**：失败显示原因，保留 **计算** 按钮重试；切换组不抹掉错误。表格位置在计算期间保持稳定，旧数值暂以“—”显示。缺少必要 ROI 时只展示可计算指标。切片往返和工作区保存保留区域与已完成结果。
- **带图报告**：PDF 包含当前影像截图、取样条件和统计表，长表可分页。水模报告包含水模各组，空气报告仅包含空气取样；标题与文件名区分。默认不添加软件名称，可在 **设置 → 导出 → 报告软件名称** 中设置。
- **视口控制**：四角信息默认继承全局设置，可在当前视口独立覆盖并恢复跟随；2D 切面选择入口也随四角信息显隐。开启 **正方形视口** 调整应用窗口，使当前 2D 画布为正方形，手动调整窗口或侧栏使其变形后自动取消。

### 行为变化与问题修复

- 灰度显示先插值再应用窗值，改善重建影像缩放时的显示；提供软件回退。此调整不修改源像素、MTF、测量或 QA 的统计输入。
- 测量和标注复制粘贴在操作栏按钮获得焦点后仍可使用；输入框、弹窗保留各自按键行为。QA 圆不新增剪贴板快捷键。
- 统一更新应用内教程和由其生成的在线手册。保留原有章节链接与搜索入口，修复首页截图宽度变化后高度不跟随的问题。

### 安装兼容性与已知限制

- macOS：Apple Silicon DMG，ad-hoc 签名，未经 Apple 公证。
- Windows：x64 安装版及单文件便携版，未配置 Authenticode 签名。
- QA 自动识别针对完整、近圆形的均质水模；无法识别时提供普通圆形取样，不自动判定合格。空气自动定位不能代替人工核查。
- 旧记录保持原值；主动重新计算后采用当前取样规则。工作区仍引用原始文件，不内嵌影像像素，也不保存撤销历史。
- 平台验收以发布验收记录中的实际执行范围为准；不代表所有显卡、触控设备或干净物理 Windows 设备均已测试。

## English details

### Upgrade notes

Save your workspace and retain its source images before upgrading. Existing settings, measurements, and QA records remain available without automatic recalculation. Historical noise values measured with the small central ROI remain unchanged until you choose **Calculate**, which uses the independent large noise circle. Keep a copy of the old workspace when comparing results.

Voxenra is now **VoxPlane**, retaining its logo. The repository is **junforge-dev/voxplane**. Updaters in version 2.5.0 and earlier cannot accept renamed assets: install once from the [2.6.0 release](https://github.com/junforge-dev/voxplane/releases/tag/v2.6.0), then use in-app updates again.

- macOS: quit the old app and drag VoxPlane from the DMG into Applications. Verify settings and workspaces before removing the old Voxenra.app.
- Windows installer: quit the old app and run the new installer. It retains the registered directory and uninstall entry while replacing the executable and shortcuts.
- Windows portable: quit the old executable, save and run VoxPlane.exe, then remove the old executable after verification.

On first launch, display settings, PACS, recent/recovery workspaces and custom languages are copied without overwriting existing VoxPlane data or deleting old files. Workspace format and image references stay compatible. Images, logs and custom folders are not relocated.

### Main improvements

- **QA groups:** central/peripheral circles measure CT number and uniformity, a separate large circle measures water noise, and external air uses its own sampling group. Only the current group is drawn. Reliable external-air detection can add a circle automatically; otherwise place it manually. Deleted air circles are not recreated automatically.
- **Circle editing:** select a circle to reveal four resize handles, or drag its interior to move it. Diameter limits reflect remaining circles and boundaries. Releasing the mouse recalculates; Esc cancels. Undo, redo, export, and clear stay in the footer.
- **Calculation and recovery:** errors retain a visible reason and a **Calculate** retry action. Switching groups does not hide errors. Table geometry remains stable during calculation, with dashes replacing stale values. Summaries appear only when required ROIs exist. Slice navigation and workspaces retain completed results.
- **Reports:** PDFs include the image, sampling conditions, and paginated ROI tables. Water reports include water sampling groups; air reports contain only air statistics, with distinct titles and filenames. No software name appears by default; set an optional name under **Settings → Export**.
- **Viewport controls:** corner information follows a global default until locally overridden, with an action to restore inheritance. The 2D plane selector follows corner visibility. **Square viewport** resizes the window for the current 2D canvas; manual window or sidebar changes that alter its shape turn it off.

### Behavior changes and fixes

- Grayscale interpolation precedes windowing, improving the appearance of zoomed reconstructed images, with a software fallback. Source pixels and measurement, MTF, and QA statistics are unchanged.
- Measurement and annotation clipboard actions work when a toolbar button has focus. Text inputs and dialogs retain their own shortcuts. QA circles do not gain clipboard shortcuts.
- Updated offline tutorials feed the online manual, preserving chapter addresses and search. Refreshed images and fixed manual-home screenshot proportions.

### Compatibility and limitations

- macOS Apple Silicon DMG: ad-hoc signed, not Apple-notarized.
- Windows x64 installer and portable executable: no Authenticode signature.
- Automatic QA detection targets complete, near-circular homogeneous water phantoms. Otherwise use ordinary circular sampling; no automatic acceptance decision is made. Inspect automatically placed air ROIs.
- Historical values change only on explicit recalculation. Workspaces reference source images and do not embed pixels or retain undo history.
- See the release verification record for actual platform coverage; it does not imply testing on every GPU, touch device, or clean physical Windows computer.
