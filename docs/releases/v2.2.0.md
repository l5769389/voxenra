# Voxenra 2.2.0

## 更新摘要
- 新增 CPR 曲面重建，支持手动路径编辑、联动横截面和图像导出。
- 改进重建操作、工作区保存恢复及多语言界面的一致性。
- 修复路径微调、撤销、标注显示和错误提示等问题。
- 4D 影像与导出图保留当前时相，小视口分析标签避开测量目标。
- 改进分屏拖入序列，更新操作手册与 CPR 界面示例。

## Update summary
- Added CPR with editable manual paths, linked cross-sections, and image export.
- Improved reconstruction workflows, workspace persistence, and language consistency.
- Fixed fine path adjustments, undo behavior, annotation display, and error messages.
- 4D images and exports show the displayed phase. Compact analysis labels leave the ROI visible.
- Improved drag and drop in split views and updated the manual with CPR screenshots.

## 完整说明 / Details

CPR 支持单个灰度 CT / MR 体数据和手动三维折线路径。当前不自动提取或平滑血管中心线。普通物理测量用于参考平面和垂直横截面；曲面图提供中心线距离。工作区保留路径、参数与测量，导出格式为 PNG。

CPR supports one grayscale CT / MR volume and manual 3D polylines. Automatic vessel tracking and smoothing are not included. Physical measurements use reference planes and perpendicular cross-sections; curved images provide centerline distances. Workspaces retain paths, parameters, and measurements. Image export uses PNG.

提供 macOS Apple Silicon、Windows x64 安装版与单文件便携版。本次 macOS 包使用 ad-hoc 签名，未经过 Apple 公证；Windows 包未配置 Authenticode 签名。Windows 完整人工阅片和旧客户端自动更新流程仍未完成实机验收。

Packages cover macOS Apple Silicon and Windows x64 (installer and single-file portable). The macOS package is ad-hoc signed and not Apple-notarized; Windows packages are not Authenticode-signed. Full manual Windows viewing and previous-client update workflows have not been verified on a physical Windows computer.
