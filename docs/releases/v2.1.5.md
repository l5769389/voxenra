# Voxenra 2.1.5

## 更新摘要
- 新增常用影像目录收藏，支持快捷切换、拖拽排序和取消收藏。
- 改进四角信息设置，支持直接预览、拖拽排序和跨角移动。
- 优化页签、调窗面板及提示样式，减少多余留白和说明。
- 修复收藏切换抖动、拖拽取消及部分界面状态问题，提升操作稳定性。
- 更新操作手册和界面示例。

## Update summary
- Added favorite image folders with quick access, drag ordering, and easy removal.
- Improved corner information settings with direct previews, drag ordering, and moves between corners.
- Refined tabs, windowing controls, and tooltips to reduce excess spacing and text.
- Fixed favorite-folder flicker, drag cancellation, and interface state issues for smoother operation.
- Updated the user manual and interface examples.

## 安装与兼容 / Installation and compatibility

提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版。macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 未配置 Authenticode 签名。已有工作区和设置继续兼容，工作区仍需保留原始影像。

Available for macOS Apple Silicon and Windows x64 (installer and portable). macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed. Existing workspaces and settings remain compatible. Keep the original images used by workspaces.

## 验证范围 / Validation scope

发布检查记录列出本次平台回归及安装包验收结果。Windows/Linux 外部 AI 实际推理、真实崩溃恢复和旧版 Windows 客户端完整点击自动更新流程未完成实机验收。

The release validation report records platform regressions and package checks. External AI inference and real crash recovery on Windows/Linux, and the complete update workflow in older Windows clients, have not been verified on physical target machines.
