# Voxenra 2.3.0

发布日期：2026-11-03 · CPR 操作、阅片快捷键与界面主题更新。

## 更新摘要

- Windows 2.2.0 用户需手动下载安装本版；修复 Windows 更新程序未启动安装的问题。
- 改进 CPR 路径绘制，支持采样示意、沿线区间标记和结果视图大小调整。
- CPR 页签关闭后，从序列打开会新建空白路径；通过「重新打开页签」恢复原结果。
- 新增菜单数字快捷键、色表收藏和「跟随系统」主题。
- 修复曲线与自由手绘 ROI 完成时的交互问题，保留已有控制点和分屏布局。
- 完善对话框 Enter / Esc 操作；首次本地导入自动选中首个序列。

## Update summary

- Windows 2.2.0 users must download and install this release manually. Fixed the Windows updater failing to start installation.
- Improved CPR path drawing with sampling guides, centerline interval markers, and resizable result views.
- Opening CPR from a series after closing its tab starts a blank path. Use Reopen tab to restore earlier results.
- Added number-key menu shortcuts, favorite color maps, and a Follow system theme.
- Fixed curve and freehand ROI completion so existing control points and the split layout are preserved.
- Improved Enter and Esc actions in dialogs. The first local import automatically selects the first series.

## 中文说明

### 升级须知

**Windows 2.2.0 用户需要手动升级。** 请从[本版下载页](https://github.com/l5769389/voxenra/releases/tag/v2.3.0)下载安装版或便携版。旧版更新程序可能在开始安装前退出，本版已修复该问题。

### 主要改进

- **CPR**：参考影像加载完成即可布点。支持直接拖动控制点、在线段上插点、查看采样宽度与投影厚度，以及标记中心线区间。完成路径后继续显示参考布局；结果视图之间的分隔比例可调整，并随工作区保存。
- **阅片操作**：布局、窗模板和色表支持按当前列表顺序使用数字快捷键；缩放支持数字键选倍率，常用色表可以收藏置顶。快捷键作用于当前窗口和菜单，数值输入框保持正常输入。
- **对话框与导入**：支持 Enter 执行默认操作、Esc 返回或请求取消任务；多行输入框保留换行。首次本地导入选中首个序列，追加导入保留已有选择。
- **外观**：新增「跟随系统」主题，系统切换明暗模式时同步更新。深色、中性深灰和浅色仍可单独选择，新安装默认深色。

### 行为变化与问题修复

- CPR 页签关闭后，从序列再次打开会开始空白路径。原路径与测量可通过 **工作区 → 重新打开页签** 恢复。
- 双击结束 CPR、曲线或自由手绘 ROI 时，不再把结束手势追加为控制点，也不切换分屏布局。再次选择当前测量工具会保留正在绘制的测量。
- 修复移动、拆出及反复打开页签时出现的加载提示、悬停提示和视口显示异常。

### 安装兼容性与验证范围

- macOS：Apple Silicon DMG，使用 ad-hoc 签名，未经 Apple 公证。
- Windows：x64 安装版和单文件便携版，未配置 Authenticode 签名。
- Windows 物理机人工阅片，以及从已安装的 2.2.0 客户端点击更新的完整流程，尚未完成验收。已完成的自动化升级与安装检查不能替代这些场景。

## English details

Released 2026-11-03. This version improves CPR workflows, reading shortcuts, and interface themes.

### Upgrade notes

**Windows 2.2.0 users must upgrade manually.** Download the installer or portable executable from [this release](https://github.com/l5769389/voxenra/releases/tag/v2.3.0). The older updater may exit before installation starts; this version fixes that issue.

### Improvements

- **CPR:** Place points as soon as reference images are ready. Drag control points, insert points on segments, inspect sampling width and projection thickness, and mark centerline intervals. Completing a path keeps the reference layout open. Result-view split ratios are adjustable and saved in the workspace.
- **Reading controls:** Number keys select layouts, window presets, and color maps in list order, or choose zoom levels. Favorite color maps appear first. Shortcuts follow the active window and menu while numeric fields retain normal typing.
- **Dialogs and import:** Enter activates the default action; Esc dismisses a dialog or requests task cancellation. Multiline fields retain line breaks. The first local import selects the first series; subsequent imports preserve the current selection.
- **Appearance:** Follow system tracks the operating system's light or dark mode. Dark, Neutral dark, and Light remain available as fixed themes. New installations default to Dark.

### Behavior changes and fixes

- Opening CPR from a series after closing its tab starts a blank path. Recover earlier paths and measurements through **Workspace → Reopen tab**.
- Double-clicking to finish CPR, a curve, or a freehand ROI no longer adds the finishing gesture as a control point or changes the split layout. Selecting the current measurement tool again preserves the measurement in progress.
- Fixed loading, tooltip, and viewport display errors when moving, detaching, or repeatedly opening tabs.

### Installation and validation scope

- macOS: Apple Silicon DMG, ad-hoc signed and not Apple-notarized.
- Windows: x64 installer and single-file portable executable, without Authenticode signatures.
- Manual image review on a physical Windows computer and the complete update flow initiated from an installed 2.2.0 client remain unverified. Automated installation and upgrade checks do not cover those scenarios.
