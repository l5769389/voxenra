# Voxenra 2.3.0

## 更新摘要
- 关闭 CPR 页签后，从序列再开会从空白路径开始。要找回原路径和测量，请在工作区选择「重新打开页签」。
- CPR 参考图就绪后可直接布点，双击完成。可查看采样宽度和厚度、标记沿线区间，并拖动分隔线调整结果图大小。
- 阅片时可用数字键选择当前菜单中的布局、窗模板、色表或缩放倍率。常用色表可收藏置顶。
- 完成曲线或自由手绘 ROI 时，双击会保留已有控制点和当前分屏。再次选择测量工具也会保留正在绘制的测量。
- 对话框支持 Enter 确认、Esc 返回。首次本地导入会选中首个序列，追加导入会保留已有选择。
- 新增「跟随系统」主题，可在系统切换明暗模式时同步更新界面。

## Update summary
- Opening CPR from a series after closing its tab now starts a fresh path. Use Reopen tab in the workspace to recover earlier paths and measurements.
- Start placing CPR points as soon as the reference images are ready. Double-click to finish, inspect sampling width and thickness, mark intervals, and resize the result views.
- Number keys select layouts, window presets, color maps, or zoom levels in the open tool menu. Star a color map to move it to the top of the list.
- Double-click to finish a curve or freehand ROI while keeping its points and the split view. Selecting the measurement tool again preserves the measurement in progress.
- Use Enter and Esc in dialogs. The first local import selects the first series, and adding more images preserves your selection.
- Choose Follow system to switch the interface between light and dark when the operating system does.

## 完整说明 / Details

### CPR 路径与区间 / CPR paths and intervals

在参考图上单击两个或更多不同位置后，双击即可完成手动路径。双击位置不会成为新点，点数不足时会取消草稿。要微调路径，可直接拖动控制点，或先单击线段进入编辑，再单击需要插点的位置。完成后保留当前视图。

Click at least two distinct points on a reference image, then double-click to finish the manual path. The finishing click does not add a point. A double-click on a shorter draft cancels it. Drag a control point to adjust it, or click a segment to enter editing and click again where you want to insert a point. Finishing keeps the current view open.

打开采样示意后，横截面上的实线表示曲面宽度，虚线表示投影厚度。可以在曲面图上选位置，或按 J / K 逐个移动采样点，再按 S / E 设置区间端点 A / B。曲面图显示沿中心线的距离，参考图会标出当前切面上的端点。宽窗口可左右调整结果图，窄窗口可上下调整，分隔比例随工作区保存。

Enable sampling guides to see the curved image width as a solid line and the projection thickness as dashed lines on the cross-section. Select a position in the curved image or step through samples with J / K, then press S / E to mark endpoints A / B. The curved view shows the distance along the centerline. Reference images mark endpoints that lie on the displayed slice. Drag the divider sideways in wide windows or vertically in narrow windows. The workspace saves the split ratio.

### 阅片、导入与外观 / Reading, import, and appearance

打开布局、调窗或伪彩菜单后，1–9 对应当前顺序的前九项。缩放面板的滑杆覆盖 0.1× 至 20×，数字键 1–9 和 0 可选 1× 至 10×。快捷键随窗口和菜单切换，输入数值时可直接打字。紧凑工具栏会展开所选工具组，悬停或用 Tab 聚焦可查看完整提示。

In the layout, windowing, and color map menus, keys 1–9 choose the first nine visible presets in order. The zoom slider spans 0.1× to 20×, with keys 1–9 and 0 selecting 1× through 10×. Shortcuts follow the active window and menu. Numeric fields accept typing while focused. The compact toolbar expands the selected tool group. Hover or focus a control with Tab for its full hint.

Enter 执行最上层对话框的默认操作，也可用 Tab 选择其他按钮后按 Enter。多行输入框保留 Enter 换行。Esc 关闭当前弹窗，在导入或导出进行时请求取消任务。在本地导入路径栏输入新目录后，第一次按 Enter 定位，加载后再按一次导入。首次导入会按左栏显示顺序选中首个序列。主题设置保留深色、中性深灰和浅色，新安装默认深色。

Enter activates the top dialog’s default action, or a button selected with Tab. In multiline text fields, Enter inserts a new line. Esc dismisses the current popup or requests cancellation of an import or export in progress. When you type a new folder in the local import path field, press Enter once to navigate and again after loading to import. The first imported series is selected in sidebar order. Dark, Neutral dark, and Light remain available as fixed themes. New installations default to Dark.

修复拆分或移动页签时加载提示销毁产生的界面错误，并稳定控制器接口，改善反复打开 CPR、2D 页签时的视口显示。

Fixed a loading-indicator error while moving or detaching tabs and stabilized controller interfaces when repeatedly opening CPR and 2D views.

## 安装与验证 / Installation and validation

Windows 2.2.0 用户请下载安装包或便携版手动升级。本次修复了 Windows 更新辅助进程可能直接退出、没有执行安装的问题。

Windows 2.2.0 users should download the installer or portable executable to upgrade manually. This release fixes the Windows update helper exiting before running the installation.

macOS DMG 适用于 Apple Silicon，使用 ad-hoc 签名，未经 Apple 公证。Windows x64 提供安装版和单文件便携版，均无 Authenticode 签名。Windows 实机的人工阅片以及从已安装的 2.2.0 客户端点击更新的完整流程尚未完成验收。

The macOS DMG is for Apple Silicon and uses an ad-hoc signature without Apple notarization. Windows x64 is available as an installer and a single-file portable executable, both without Authenticode signatures. Manual image review and an end-to-end update initiated from an installed 2.2.0 client remain unverified on a physical Windows computer.
