# Voxenra 2.1.1

## 更新摘要
- 优化界面样式、主题配色及部分设置和提示文案。
- 改进影像导入、自动分割、工作区及导出操作流程。
- 修复部分测量、分割、跨时相报告和工作区数据保护问题。
- 提升异常处理与运行稳定性，完善失败提示、取消和重试。

## Update summary
- Improved interface styling, theme colors, settings, and on-screen messages.
- Refined image import, automatic segmentation, workspace, and export workflows.
- Fixed issues affecting measurements, segmentation, reports across phases, and workspace data protection.
- Improved reliability and error handling, including failure messages, cancellation, and retries.

## 安装与兼容 / Installation and compatibility

- 提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版。
- macOS 包仍为 ad-hoc 签名，未经过 Apple 公证；Windows 包未配置 Authenticode 签名。
- 本地 AI 分割仍需单独配置 TotalSegmentator 环境和模型；已有工作区可继续打开。
- macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed. Local AI segmentation requires a separately configured runtime and models.

## 验证 / Validation

发布检查覆盖回归测试、macOS 原生界面与故障恢复、平台构建及附件校验。Windows／Linux 的真实 AI 推理和崩溃恢复、旧版客户端的完整点击更新流程尚未完成实机验收。

最终 macOS 包的启动、压缩影像解码及隔离升级已验证，可见界面复核尚未完成。

Release checks cover regression tests, native macOS workflows and failure recovery, platform builds, and asset checksums. Native AI inference and crash recovery on Windows/Linux, and complete update workflows in previously installed clients, remain unverified.

Startup, compressed-image decoding, and an isolated upgrade were verified for the final macOS package; its visible-interface recheck remains incomplete.
