# Voxenra 2.4.0

发布日期：2026-11-05 · 统一测量与 CPR 操作，改善四图定位和右侧工具栏。

## 更新摘要

- 从序列打开视图统一新建独立页签；误关阅片页签可用「撤销关闭页签」找回。
- 长度、角度、矩形和椭圆按下即定点，点数足够自动完成；曲线、勾画和 CPR 双击结束。
- CPR 四图联动显示青色取样标记，区分层内、端视与投影；路径可直接点选编辑和删除。
- 重整右侧操作栏与测量结果层级，底部操作固定，长列表独立滚动。
- 统一测量与 CPR 的绘制状态样式，标注可使用独立颜色；完善工具快捷键和悬停提示。
- 改进导入反馈、DICOM 标签浏览状态恢复，以及测量结果定位、分割转换和图像导出。

## Update summary

- Opening a view from a series creates an independent tab. Use Undo close tab to recover an accidentally closed reading tab.
- Length, angle, rectangle, and ellipse tools place points on press and finish at the required count. Curves, freehand ROIs, and CPR finish on double-click.
- Cyan CPR guides link all four views and distinguish in-plane, end-on, and projected samples. Click paths to edit or select them for deletion.
- Reorganized the right sidebar and measurement results, with fixed footer actions and independently scrolling lists.
- Unified drawing-state styles for measurements and CPR, with separate annotation colors and clearer tool shortcuts and hints.
- Improved import feedback, DICOM tag-state restoration, result navigation, segmentation conversion, and image export.

## 中文说明

### 升级须知

从 [2.4.0 下载页](https://github.com/l5769389/voxenra/releases/tag/v2.4.0)选择对应平台安装包。Windows 2.2.0 用户仍需手动下载安装；该旧版本的更新器可能在开始安装前退出。

升级前保存工作区，并在覆盖保存前保留一份副本。新版读取旧工作区时保留已有标注颜色；新增的标注样式与标签浏览状态不保证被旧版本完整读取。工作区仍引用原始影像，请保留源文件。

### 主要改进

- **测量与标注**：固定点数工具按下即确认点位，满足点数后自动完成，减少等待双击判定带来的延迟。曲线、勾画和 CPR 保留双击完成，结束手势不会额外添加末端点。完成后再次双击可放大或还原视口。
- **CPR 定位**：青色标记关联参考图、曲面图和横截面；层内取样线显示实线，端视显示点，离层或倾斜投影显示虚线与说明。横截面取样线使用端帽或延伸尖角区分实际端点和超出显示范围的部分。完成或切换路径时，参考切片对齐起点 s=0，避免首次微移位置线才发生大幅重定位。
- **CPR 路径操作**：点击路径进入编辑，拖动控制点调整，点击空白处开始下一条路径。绘制新路径时保留历史路径参考。删除已选路径后继续使用 CPR 工具；草稿状态支持逐点撤回。
- **操作栏与结果列表**：工具入口、当前工具内容及底部操作分层展示。测量结果按来源视图分组，名称、数值与操作更易区分。长列表独立滚动，重置和清除等底部操作保持可见。
- **显示与快捷键**：测量和 CPR 使用一致的绘制、编辑与完成状态样式；标注可独立设色或跟随完成色。补齐测量工具快捷键，重置操作使用统一的菜单作用范围，悬停提示说明用途。
- **导入与工作区**：影像导入入口简化结果反馈；工作区保存 DICOM 标签页的搜索、页码、展开及滚动状态。

### 行为变化与问题修复

- 从序列列表打开同类型视图时，每次都会新建独立页签。继续已有工作请切换原页签；误关时使用 **撤销关闭页签**。没有已完成编辑的已就绪阅片页签在本次会话中保留最近关闭的 20 个，含编辑结果的页签随工作区保存。
- 完成 CPR 路径后保留参考布局，但参考切片会对齐路径起点。绘制过程中不自动翻层。独立翻阅参考切片后，单纯激活结果视图不会重新定位；主动沿路径导航才更新参考位置。
- 修复 CPR 选中后 Delete 无效、近距离点选行为不一致，以及工具切换后错误回到调窗的问题。
- 修复窗口失焦后悬停提示残留、列表挤占底部操作区及部分按钮文字截断。
- 改善测量结果定位和自由形状 ROI 转分割时的对象、切面判定；图像导出不再带入操作光标，导出完成后恢复显示状态。
- 修复对比视图和角度绘制提示在切换语言后未及时更新的问题。

### 安装兼容性与已知限制

- macOS：Apple Silicon DMG，ad-hoc 签名，未经 Apple 公证。
- Windows：x64 安装版及单文件便携版，未配置 Authenticode 签名。
- CPR 仍使用手动三维折线路径，不提供自动血管追踪；曲面图提供沿线距离，普通物理测量用于参考平面和垂直横截面。
- 自动化检查不能替代 Windows 物理机人工阅片、干净设备安装及实际部署环境验收。最终完成与未覆盖的检查见发布验收记录。

## English details

Released 2026-11-05. This version unifies measurement and CPR interactions and improves linked positioning and the right sidebar.

### Upgrade notes

Choose the appropriate package from [the 2.4.0 release](https://github.com/l5769389/voxenra/releases/tag/v2.4.0). Windows 2.2.0 users still need a manual installation because that older updater may exit before installation begins.

Save your workspace and keep a copy before overwriting it. Existing annotation colors are retained when loading older workspaces. Older versions may not fully read the newly saved annotation styles and DICOM tag-browser state. Keep the original images referenced by your workspace.

### Improvements

- **Measurements and annotations:** Fixed-point tools place each point on press and complete at the required count, avoiding double-click recognition delays. Curves, freehand ROIs, and CPR retain double-click completion without adding a final point. A subsequent double-click maximizes or restores the viewport.
- **CPR positioning:** Cyan guides connect reference images, the curved view, and the cross-section. In-plane lines are solid, end-on lines appear as points, and oblique or off-plane projections use labeled dashes. End caps and continuation chevrons distinguish actual sampling-line endpoints from ranges extending outside the display. Completing or selecting a path aligns reference slices to s=0 before the first small navigation step.
- **CPR paths:** Click a path to edit, drag control points, or click an empty area to begin another path. Earlier paths remain visible as references while drawing. Deleting a selected path keeps the CPR tool active; draft points can be removed one at a time.
- **Sidebar and results:** Tool selection, tool content, and footer actions have distinct areas. Measurement results are grouped by source view, with clearer names, values, and actions. Long lists scroll independently while reset and clear actions remain visible.
- **Styles and shortcuts:** Measurements and CPR share drawing, editing, and completion styles. Annotations can use a separate color or follow the completion color. Measurement shortcuts, scoped reset actions, and explanatory tooltips are more consistent.
- **Import and workspaces:** Simplified image-import feedback. Workspaces now retain DICOM tag search, page, expansion, and scroll state.

### Behavior changes and fixes

- Opening a view from the series list creates an independent tab each time. Select the original tab to continue existing work, or use **Undo close tab** after an accidental close. The session retains the last 20 ready reading tabs without completed edits; tabs with editing results are retained in saved workspaces.
- Completing CPR keeps the reference layout open while aligning its slices to the path start. Drawing does not automatically scroll reference images. After independently browsing references, activating a result view alone does not relocate them; deliberate path navigation does.
- Fixed ineffective Delete actions on selected CPR paths, inconsistent placement of nearby points, and unintended switches back to windowing.
- Fixed tooltips remaining after window deactivation, lists overlapping footer actions, and truncated button text.
- Improved result navigation and object/plane checks when converting a freehand ROI to segmentation. Image exports omit the tool cursor and restore the display state afterward.
- Fixed comparison-view and angle-drawing hints not refreshing when the interface language changes.

### Installation, compatibility, and known limitations

- macOS: Apple Silicon DMG, ad-hoc signed and not Apple-notarized.
- Windows: x64 installer and single-file portable executable, without Authenticode signatures.
- CPR still uses manual 3D polylines, without automatic vessel tracking. Curved views provide centerline distances; ordinary physical measurements use reference planes and perpendicular cross-sections.
- Automated checks do not replace physical Windows image review, clean-device installation, or validation in the actual deployment environment. The release validation record lists completed checks and remaining gaps.
