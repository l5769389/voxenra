# Voxenra 2.0.2

## 更新摘要
- 自动更新流程验证版本，用于从 2.0.1 检查、下载并安装更新。
- 功能与影像处理算法保持与 2.0.1 一致，无新增功能。

## Update summary
- Update verification release for checking, downloading and installing an update from 2.0.1.
- Features and image-processing algorithms are unchanged from 2.0.1.

## 验证方式 / How to verify

先手动安装 2.0.1，再启用启动更新检查并重启，或在设置中点击“检查更新”。应显示 2.0.2 及当前界面语言的简短摘要。点击“下载并更新”后下载和校验安装包，按工作区保存选择退出，安装成功后重新启动并显示版本 2.0.2。

Install 2.0.1 manually, then enable startup checks and restart, or choose Check for updates in Settings. The dialog should show 2.0.2 and the summary in the selected interface language. Download and update verifies the package, respects the workspace save choice, installs it, and restarts the app as version 2.0.2.

此版本作为正式 Release 发布，以便现有更新器识别；未使用 GitHub 的预发布标记。1.7–2.0.0 的旧客户端包含下载缺陷，仍需先手动安装 2.0.1 或本版本。

This release is marked stable so that the existing updater can detect it. Clients from 1.7 through 2.0.0 still require a manual installation of 2.0.1 or this version.

- macOS Apple Silicon：本地构建，ad-hoc 签名，未 Apple 公证。
- Windows x64：GitHub Actions 构建安装版和单文件便携版，未 Authenticode 签名。
- macOS is ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed.
