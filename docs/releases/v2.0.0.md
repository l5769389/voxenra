# Voxenra 2.0.0

## 新增与改进

- **操作偏好**：新增鼠标与快捷键设置，可调整滚轮方向、右键／中键拖动、调窗与缩放灵敏度，并自定义常用工具快捷键。冲突或保留按键不会覆盖原绑定；录入时点击别处可取消。
- **界面与隐私**：支持 100%、115%、130% 界面大小；新增新视图隐藏身份信息、清除最近工作区记录。主题、输入和隐私偏好自动保存，界面大小重启生效。
- **开始工作更直接**：空白工作区提供打开影像、恢复工作区及最近工作区入口，并保留初次使用指引。
- **工具栏整理**：按 2D、MPR、3D 与融合视图安排常用工具；默认仅显示图标，悬停查看名称与快捷键。统一二级面板、帮助入口和窄侧栏布局。
- **分割显示与精修**：增加轮廓、填充和透明度控制；直径设置随画笔／橡皮切换显示对应名称。优化局部遮罩更新、预览与撤销重做，减少编辑期间的闪烁和重复计算。
- **降低加载内存**：体数据逐帧装配，减少整组切片复制；解码缓存增加内存限额。PET 原始单位回退保留正确的数值与单位。
- **空间校准保护**：缺少有效像素间距的影像仍可二维浏览，但不再使用默认像素网格输出毫米测量或定量分析。
- 更新中英文 README、官网和操作手册，替换当前工具栏、工作区、MTF、设置与分割截图及动画。

## 支持范围与安装

- 本次不修改 MTF／FWHM 计算公式。空间与数值验证覆盖已记录样本和合成案例，不代表所有厂家、传输语法或临床场景均已验证。
- 隐私选项控制视口身份叠加，不匿名化原始 DICOM，也不清除影像内烧录文字；匿名导出仍需单独选择。
- NRRD 分割交换仍要求与参考 DICOM 网格匹配；不新增独立 NRRD／NIfTI 阅片或自动重采样。
- **macOS Apple Silicon**：本机生成 DMG，采用 ad-hoc 签名，尚未配置 Apple Developer ID 与公证。首次打开仍可能需要在系统隐私与安全性中允许。
- **Windows x64**：GitHub Actions 生成安装版与单文件便携版，尚未配置 Authenticode 签名，可能出现 SmartScreen 提示。
- Windows 弱 GPU、不同显示器 DPI 切换以及正式上一版本至本次版本的完整自动更新链路未完成实机验收；自动检查、下载与失败恢复使用回归测试验证。

## English summary

Voxenra 2.0.0 adds configurable mouse bindings and tool shortcuts, interface scaling, privacy preferences, and an improved workspace start screen. Context-aware icon toolbars and secondary panels make common actions easier to find. Segmentation gains outline/fill controls, contextual paint/erase size controls, and more efficient preview and undo updates. Volume assembly reduces intermediate memory use, while images without reliable spacing can no longer produce misleading millimeter measurements.

Bilingual documentation, screenshots, and workflow animations have been refreshed. MTF/FWHM formulas are unchanged. NRRD segmentation exchange still requires a matching DICOM reference grid. macOS builds use ad-hoc signing without notarization; Windows builds are not Authenticode signed. Weak Windows GPUs, multi-monitor DPI behavior, and the complete installed-version upgrade to 2.0.0 remain unverified on physical Windows hardware.
