# Voxenra 2.0.1

## 更新摘要
- 修复自动更新下载跳转失败，避免已发现新版本却无法下载安装包。
- 更新弹窗仅显示简短摘要，清除 Markdown 符号，优化间距和滚动位置。
- 更新摘要随界面语言切换中英文，并提供对应版本的完整发布说明入口。
- 旧 1.7 至 2.0.0 客户端包含下载缺陷，请从发布页手动下载并安装 2.0.1。

## Update summary
- Fixed update downloads failing when GitHub redirects to its asset server.
- Update dialogs now show concise summaries without Markdown clutter, with improved spacing and scrolling.
- Summaries follow the selected Chinese or English interface language, with access to full release notes for the version shown.
- Clients from 1.7 through 2.0.0 contain the download defect. Download 2.0.1 from this release page and install it manually.

## 修复与安装 / Details and installation

修复 Qt 下载重定向信号的调用，保留原有的下载域名限制、文件大小与 SHA-256 校验。新摘要格式按当前界面语言选择中文或英文，其他语言暂回退英文；旧发布说明自动提取主要内容，完整记录仍在对应版本的 GitHub 页面。取消和下载操作保持原有行为。

本次不修改影像、测量、分割、MTF 或 FWHM 算法。2.0.0 的原标签和附件保持不变。旧客户端可以检测到 2.0.1，但无法通过发布页修复自身的下载逻辑，请手动下载覆盖安装，不必先卸载。

The Qt download redirect signal is now emitted correctly. Host restrictions, file-size checks and SHA-256 verification remain in place. Other interface languages fall back to the English summary, and older release text is condensed for display. Image, measurement, segmentation, MTF and FWHM algorithms are unchanged. The original 2.0.0 tag and assets are retained. Older clients require a manual download and installation; uninstalling first is unnecessary.

- macOS Apple Silicon：本地构建 DMG，仅 ad-hoc 签名，尚未配置 Apple Developer ID 或公证。
- Windows x64：GitHub Actions 构建安装版与单文件便携版，尚未配置 Authenticode 签名。
- macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed.
