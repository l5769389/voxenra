# Voxenra v1.7.0

本版完善从测量、分析到工作区保存和报告导出的流程，并新增常见彩色 DICOM 二维阅片。

## 新增与改进

- **彩色 DICOM**：RGB、YBR、PALETTE COLOR 支持二维、平铺、多帧播放、标注和 PNG 导出；正确应用调色板，保留源颜色。有有效像素间距时开放物理尺寸测量。
- **测量管理**：结果列表支持重命名、定位、显隐、锁定、复制与删除；操作按钮合并为紧凑行，名称与状态随工作区保存。
- **报告与分析保存**：PDF 默认匹配测量所在切片／平面的参考图；MTF、FWHM、QA 的 ROI、曲线、数值和计算信息随工作区保存，恢复后不自动重算。
- **工作区恢复**：恢复此前选择的一级功能及二级工具，播放保持暂停；不会恢复未完成拖拽或自动执行计算、导出等动作。
- **外观与窗模板**：新增中性深灰主题，统一界面配色；窗模板改为可编辑的本地 JSON，支持打开目录和重新读取，内置 13 个常用 CT 窗模板。
- **帮助与反馈**：提供 GitHub 和邮件反馈入口，可带入基础软件信息；邮件支持添加附件并交由用户确认发送。
- **自动更新**：可选择启动检查，查看更新内容并下载；取消同一版本后不再自动提醒，设置中保留更新标识。检查失败静默处理，安装失败尝试恢复旧版。
- **文档**：更新中英文 README、官网功能说明和操作手册，刷新测量、导出、工作区、设置及导入界面截图和相关动画。

## 修复

- 重构本地导入目录列表，避开 macOS 辅助功能读取后切换目录触发的 Qt 崩溃路径。
- 修复 PALETTE COLOR 被当作灰度图显示的问题。
- 修复彩色标记影响普通灰度／PET 影像窗值叠加信息的问题。
- 修复窗模板示例的语言包占位符校验及模板重名提示。

## 安装与范围

- 提供 macOS Apple Silicon DMG、Windows x64 安装版及单文件便携版，各附 SHA-256。
- **这是首个带自动更新的正式版本，旧版用户请先手动安装 1.7.0。** 后续更新可在设置中检查。
- 彩色支持限常见二维对象；不含彩色 MPR / 3D、视频编码、超声区域专用标定及大型病理图像。
- macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未做 Authenticode 签名，可能出现系统信任提示。
- Windows 实机视觉验收与真实用户安装的端到端自动升级尚未完成；CI 与隔离更新／回退测试不等同于这些验收。

## English summary

Voxenra 1.7.0 adds common color DICOM 2D viewing, a compact measurement results list, matching reference images in PDF reports, and persistent MTF/FWHM/QA analysis records. Workspaces restore the selected tools while keeping playback paused. Other additions include a neutral gray theme, editable JSON window presets, feedback with email attachments, and optional automatic update checks with rollback handling.

The release also fixes palette-color rendering, macOS import-directory navigation crashes triggered by accessibility inspection, and grayscale/PET overlay regressions. Documentation and screenshots have been refreshed.

**Install 1.7.0 manually when upgrading from older versions; this is the first official release with the updater.** Color support is limited to common 2D objects. macOS is ad-hoc signed and not notarized; Windows binaries are not Authenticode signed. Windows desktop visual checks and end-to-end upgrades of real user installations remain unverified.
