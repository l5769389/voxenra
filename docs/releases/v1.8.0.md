# Voxenra 1.8.0

## 新增与改进

- 分割精修：画笔、橡皮、保留或删除点选连通区域；支持当前切面及 3D 球形范围。
- 画笔直径支持毫米与相对视图模式，滑块和精确输入并用；不同光标区分绘制与擦除，新区域优先使用未占用颜色。
- NRRD / Slicer 交换：导出当前时相体数据和分割，导入匹配参考网格的分割；保留区域名称、颜色、重叠和空区域。
- 改善连续擦除与撤销重做时的遮罩稳定性；工作区恢复分割掩膜、选中区域和精修参数。
- 统一紧凑侧栏弹出层，再次点击同一按钮即可关闭；伪彩选择向左展开。
- 修复撤销控制器的动态 Qt 元对象导致的偶发页签切换崩溃，以及恢复工作区时撤销快捷键的空值绑定。
- 更新中英文 README、主页、操作手册和分割操作动画。

## 支持范围

NRRD 分割导入要求与当前 DICOM 参考网格一致；不自动重采样，不提供独立 NRRD 影像浏览或 NIfTI 支持。NRRD 通常不包含可靠的患者或时相身份，请选择对应原影像和时相。

本地 Slicer 5.12.4 验证覆盖 MR、P113 CT 和倾斜各向异性体积：双向逐体素、几何、区域元数据与统计核对通过。

## 安装

- macOS Apple Silicon：本地构建 DMG。
- Windows x64：GitHub Actions 构建安装版与单文件便携版。
- 当前产物未进行 Apple Developer ID 公证或 Windows Authenticode 签名。Windows 低性能显卡和本次正式包的上一版本端到端自动更新尚未实机验收；自动更新检查、下载与失败恢复由回归测试覆盖。

## English summary

Voxenra 1.8.0 adds paint/erase segmentation refinement, connected-region tools, physical and view-relative brush sizes, and NRRD/Slicer exchange with preserved overlapping segments. Workspace restoration includes refinement settings. This release also improves mask stability during erase and undo/redo, unifies compact tool flyouts, and fixes an intermittent Qt crash when exposing undo history to QML. Bilingual documentation and segmentation screenshots have been refreshed.

NRRD segmentation import requires a matching DICOM reference grid; standalone NRRD image viewing, automatic resampling, and NIfTI are not included. macOS uses ad-hoc signing without notarization; Windows is not Authenticode signed. Low-performance Windows GPU visual checks remain unverified.
