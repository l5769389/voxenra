# VoxPlane 2.7.0

发布日期：2026-11-13 · 用可见预览配置初始显示、截图和报告。

## 更新摘要

- 新增影像初始显示、截图与报告预设，设置时可实时预览效果。
- 截图保存前可核对实际输出；报告支持版式、内容、署名与隐私选项。
- 默认使用影像自带窗值，窗模板同时显示具体 WW / WL；旋转与镜像支持菜单内快捷键。
- 修复镜像、旋转和重置组合下的测量位置，以及 QA 撤销后的自动计算与圆形尺寸显示。
- 重整应用内与在线操作手册，增加按任务导航和步骤搜索。

## Update summary

- Added live-preview presets for initial image display, screenshots, and reports.
- Review the actual screenshot before saving; configure report layout, content, attribution, and privacy.
- Source window values are the default; templates show WW / WL, with menu-scoped rotation and mirror shortcuts.
- Fixed measurement alignment during transforms and reset, plus QA automatic calculation after undo and ROI diameter display.
- Reorganized the in-app and online manuals with task navigation and step search.

## 中文说明

### 升级须知

VoxPlane 2.6.0 可通过应用内更新入口获取本版。Voxenra 2.5.0 及更早版本仍需手动安装一次 VoxPlane，见 [更名升级说明](https://github.com/junforge-dev/voxplane/blob/v2.6.0/docs/releases/v2.6.0.md)。本版沿用现有工作区格式，已有设置保留；新的初始显示偏好用于随后打开的影像，不覆盖正在查看的视口。

### 主要改进

- 初始显示：选择适应窗口或实际比例、影像自带窗值或指定模板。默认采用源影像提供的显示窗；MR 缺少有效窗值时仍采用自动范围。模板名称旁显示 WW / WL，便于确认。
- 截图：单独设置导出范围、PNG / JPEG、图像大小、叠加内容与隐私选项。先预览最终编码图像，再保存相同内容。没有保存过预设时不显示空的预设选择列表。
- 报告：分别设置纸张、方向、内容、署名和隐私，预览后保存 PDF。设置面板缩窄，页面按宽度放大，可纵向滚动及翻页；水模与空气 QA 保留各自报告内容。
- 教程：应用内与网站仍使用同一内容源；按任务查找操作，搜索可定位到步骤，既有章节地址保持可访问。

### 行为变化与问题修复

- 测量与标注随图像镜像和旋转正确定位；组合操作及重置后的显示与交互保持一致。
- 旋转菜单使用 H / V 水平与垂直镜像，J / K 逆时针与顺时针旋转 90°，R 重置；快捷键仅在当前菜单生效，输入框及弹窗优先。
- QA 撤销后继续自动计算；组尺寸读取圆形实际几何，混合尺寸不会显示成统一大小。
- 修复轴对齐 MPR 半层位置的分割画笔显示，保留倾斜切面的原有采样约定。
- 无可用原生 OpenGL 驱动时，3D 视图显示错误提示，避免误用离屏后端导致崩溃。
- 关闭 3D 视口后忽略迟到的失焦和尺寸事件，避免影响随后打开的视图。
- 修复设置和 PACS 页签分离时的界面警告，返回影像后操作栏正常恢复。
- 修复多窗口切换页签时短暂混用前一个视口状态的问题。
- 修复 Windows 打开预设设置页时可能出现的弹窗状态异常及崩溃。
- 修复 Windows 报告预览关闭后临时 PDF 文件仍被占用的问题。
- 导出默认目录应用于保存对话框。匿名导出隐藏受支持的身份叠加，不清除原始像素中已烧录的文字。

### 安装兼容性与已知限制

提供 macOS Apple Silicon DMG、Windows x64 安装版和单文件便携版。macOS 使用 ad-hoc 签名，未公证；Windows 未做 Authenticode 签名，系统可能提示未知发布者。Windows 验收在 GitHub Actions 的 Windows 环境执行，不代表所有显卡、驱动或医院 PACS 均已验证。外部服务、额外影像样本及未覆盖硬件的测试边界见验收记录。

## English details

Released 2026-11-13. Configure image display and exports with visible previews.

### Upgrade notes

VoxPlane 2.6.0 can obtain this version through the in-app updater. Voxenra 2.5.0 and earlier still require a one-time manual installation; see the [rename migration notes](https://github.com/junforge-dev/voxplane/blob/v2.6.0/docs/releases/v2.6.0.md). Existing settings and the workspace format are retained. Initial display preferences apply to newly opened images without overwriting current viewports.

### Improvements

- Initial display: choose fit or actual scale and source window values or a template. Source windows are the default; MR data without valid source values retains automatic windowing. Templates display exact WW / WL values.
- Screenshots: configure scope, PNG / JPEG, image size, overlays, and privacy. Review the final encoded image and save that same content. An empty preset selector is hidden until a preset is saved.
- Reports: configure paper, orientation, content, attribution, and privacy before reviewing and saving the PDF. Narrower controls leave more space for a width-fitted, scrollable page preview. Water and air QA retain distinct report content.
- Manuals: shared in-app and web content now offers task navigation and step search while preserving existing chapter addresses.

### Behavior changes and fixes

- Measurements and annotations remain aligned through mirroring, rotation, and reset.
- The rotation menu provides H / V for horizontal / vertical mirroring, J / K for 90° counterclockwise / clockwise rotation, and R for reset. Keys are scoped to the active menu; text fields and dialogs take priority.
- QA resumes automatic calculation after undo. Diameter fields reflect actual ROI geometry and distinguish mixed sizes.
- Fixed segmentation brush visibility at axis-aligned MPR half-slice positions while retaining oblique sampling behavior.
- When native OpenGL is unavailable, 3D views report the problem instead of attempting an incompatible headless backend.
- Closed 3D viewports ignore late focus and resize events instead of affecting views opened afterward.
- Fixed UI warnings when detaching Settings or PACS tabs; reading tools recover when returning to images.
- Fixed stale viewport state being used briefly during tab changes between windows.
- Fixed popup state errors and crashes that could occur when opening preset settings on Windows.
- Fixed temporary PDF files remaining locked after closing a report preview on Windows.
- Save dialogs use the configured export directory. Anonymous export hides supported identity overlays; it does not remove text burned into source pixels.

### Installation, compatibility, and known limitations

Packages cover macOS Apple Silicon, Windows x64 installer, and Windows x64 single-file portable. macOS uses ad-hoc signing without notarization. Windows packages lack Authenticode signing, so operating-system trust warnings may appear. Windows acceptance runs on GitHub Actions Windows hosts; this does not verify every graphics driver or external PACS. Validation records distinguish optional external-service, data, and hardware checks.
