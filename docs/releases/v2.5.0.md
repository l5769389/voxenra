# Voxenra 2.5.0

发布日期：2026-11-09 · 双指缩放与快捷打开视图，改善测量统计和绘制反馈。

## 更新摘要

- 各类影像视图支持双指缩放，触屏围绕双指中心、触控板围绕鼠标位置缩放。
- 为打开 2D、MPR、3D、CPR 等视图添加快捷键，序列右键菜单同步显示按键。
- 新增标注、导出和整体重置快捷键；弹窗、输入框及当前工具菜单保持独立作用范围。
- ROI 部分超出影像时，灰度统计只计算有效像素，面积和尺寸仍保留完整绘制范围。
- 测量点数不足时暂不显示指标；未选中的 ROI 收起统计卡片，减少结果标签遮挡。
- 修复切换页签后绘制确认键失效、首次拖动丢失位移，以及缩放后高亮边框被遮挡。

## Update summary

- Pinch to zoom in image views, anchored at the finger midpoint on touchscreens or the pointer position on trackpads.
- New shortcuts open 2D, MPR, 3D, CPR, and other views. Series context menus display the assigned keys.
- Added annotation, export, and full-reset shortcuts, with separate scopes for dialogs, text fields, and the active tool menu.
- ROIs extending beyond the image use valid pixels for intensity statistics while retaining their full drawn area and dimensions.
- Metrics wait for sufficient points. Unselected ROIs use compact labels to reduce overlapping statistics cards.
- Fixed drawing-confirmation keys after tab switches, lost initial drag movement, and highlight frames obscured by zoomed images.

## 中文说明

### 升级须知

从 [2.5.0 下载页](https://github.com/l5769389/voxenra/releases/tag/v2.5.0)选择对应平台安装包。Windows 2.2.0 用户仍需手动下载安装，该旧版本的更新器可能在开始安装前退出。

升级前保存工作区并保留副本，继续保留工作区引用的原始影像。已有自定义快捷键优先保留；若占用了新增的默认按键，新动作不会覆盖旧绑定，可在设置中重新分配。

### 主要改进

- **双指缩放**：支持 2D、MPR、CPR、融合、对比、蒙太奇、3D 与 4D，无需切换当前工具。触屏以双指中心为锚点，触控板以鼠标所在视图中的位置为锚点；没有有效位置时使用视图中心。倍率范围为 0.1×–20×，已有缩放联动继续生效。
- **快速打开视图**：选中序列后，D 打开 2D、X 打开 MPR、T 打开 3D、Y 打开 CPR、O 打开蒙太奇、U 打开 4D、I 打开 DICOM 标签。右键菜单中的快捷键作用于右击的序列，仅允许打开该序列支持的视图，每次创建独立页签。
- **常用操作按键**：A 打开标注、E 打开导出、Q 整体重置当前视图；标注菜单中 A 选择箭头、T 选择文字。当前二级菜单优先处理自己的按键，退出后恢复通用按键；输入文字、打开弹窗或拖动时不会触发底层操作。
- **更清晰的测量反馈**：长度、角度和 ROI 在满足最少有效点数及几何条件后显示指标。未选中的 ROI 显示名称和面积，选中后展开灰度统计；自动标签尽量避让轮廓、其他标签、方向文字和比例尺，仍可手动调整。

### 行为变化与问题修复

- MTF 保留对处理参数敏感的可计算数值，右侧面板逐项提示变化幅度。对照计算失败不清空默认结果；20% 现为可调整的提示阈值。明确区分实测与模型估计，工作区保留对照数据。影像及导出图像的标签只保留尺寸、指标与来源；绘制新 MTF/FWHM 选区时，旧选区标签保持原有结果。本项调整结果呈现，不代表已解决算法的噪声敏感性。

- ROI 部分超出有效影像范围时，平均值、标准差、最小值、最大值和像素数只依据有效像素计算；绘制面积和尺寸不裁减。完全没有有效像素时明确提示，不显示伪造的灰度数值。
- Q 沿用“全部重置”的行为，包括清除当前视图相应的测量和标注；需要保留结果时请先保存工作区。当前工具的局部重置仍使用 R。CPR 整体重置补齐图像显示状态的恢复，不删除已有路径。
- 修复切换页签或关闭工作区弹窗后，曲线与 CPR 的 Enter / Esc 不能确认或取消绘制的问题。
- 修复开始拖动时丢失第一段位移，改善平移和测量编辑的跟手反馈。
- 修复 CPR 绘制新路径时结果状态文字重复、窗模板命名时 Esc 无法取消，以及伪彩影响影像外留白的问题。
- 修复蒙太奇缩放、平移后悬停边框被影像覆盖，以及底部边框偶发裁切。

### 安装兼容性与已知限制

- macOS：Apple Silicon DMG，ad-hoc 签名，未经 Apple 公证。
- Windows：x64 安装版及单文件便携版，未配置 Authenticode 签名。
- 手势识别依赖操作系统和设备提供的触控事件；自动化事件验证不等于所有实体触控屏和触控板均完成验收。
- 标签空间不足时仍可能重叠，可手动移动。CPR 仍为手动路径，不提供自动血管追踪。
- 未在干净物理 Windows 设备或另一台 Mac 上完成人工安装及阅片验收；具体完成与未覆盖范围见发布验收记录。

## English details

Released 2026-11-09. Pinch zoom and view-opening shortcuts improve navigation, with clearer measurement feedback and valid-pixel statistics.

### Upgrade notes

Choose your platform package from [the 2.5.0 release](https://github.com/l5769389/voxenra/releases/tag/v2.5.0). Windows 2.2.0 users still need a manual installation because that older updater may exit before installation begins.

Save a copy of your workspace before upgrading and retain its source images. Existing custom shortcuts take priority: a new action will not overwrite an occupied binding. Reassign it in Settings if needed.

### Improvements

- **Pinch zoom:** Supported in 2D, MPR, CPR, fusion, comparison, montage, 3D, and 4D views without switching tools. Touchscreens use the finger midpoint; trackpads use the pointer position in the viewport, falling back to the viewport center when unavailable. The range is 0.1×–20×, and existing zoom links remain effective.
- **Open views quickly:** With a series selected, D opens 2D, X MPR, T 3D, Y CPR, O montage, U 4D, and I DICOM tags. Context-menu shortcuts target the right-clicked series. Only supported views open, and each opening creates an independent tab.
- **Common actions:** A opens annotations, E export, and Q resets the current view. Within annotations, A selects arrows and T text. Active tool menus take priority over general bindings; dialogs, text entry, and dragging isolate their input.
- **Measurement feedback:** Metrics appear after enough valid points and geometry are available. Unselected ROIs show compact name-and-area labels; selection expands intensity statistics. Automatic placement avoids nearby shapes, labels, orientation text, and scale bars when space permits, with manual adjustment available.

### Behavior changes and fixes

- MTF retains computable values that are sensitive to processing parameters, with metric-specific warnings in the side panel. Failed comparisons no longer erase baseline results; 20% is now an adjustable warning threshold. Measured and modeled results are distinguished, and comparison data is saved in workspaces. Image and export labels show only dimensions, metrics and their source; drawing a new MTF/FWHM ROI keeps the previous ROI's label unchanged. This changes reporting; it does not establish improved noise robustness.

- Partially out-of-image ROIs calculate mean, standard deviation, minimum, maximum, and pixel count from valid pixels only. Drawn area and dimensions remain unchanged. Empty intersections explicitly report no valid pixels.
- Q retains the existing Reset all behavior, including clearing the corresponding measurements and annotations in the current view. Save results first. R remains the local tool reset. CPR now restores image display state through the shared reset action while retaining its paths.
- Fixed Enter / Esc failing to finish or cancel curve and CPR drawing after switching tabs or closing workspace dialogs.
- Fixed lost initial drag movement when panning or editing measurements.
- Fixed duplicate CPR result-status labels during new-path drawing, Esc failing to cancel window-preset naming, and pseudocolor tinting the canvas outside the image.
- Fixed montage hover frames being covered by zoomed or panned images and occasional clipping of their bottom edge.

### Installation, compatibility, and known limitations

- macOS: Apple Silicon DMG with ad-hoc signing, without Apple notarization.
- Windows: x64 installer and single-file portable EXE, without Authenticode signing.
- Gesture availability depends on events supplied by the operating system and device. Automated event checks do not certify every physical touchscreen or trackpad.
- Dense labels may still overlap and can be moved manually. CPR uses manually drawn paths, without automatic vessel tracking.
- Manual installation and reading workflows on a clean physical Windows device or another Mac remain unverified. See the acceptance record for completed checks and remaining limits.
