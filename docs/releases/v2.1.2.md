# Voxenra 2.1.2

## 更新摘要
- 完善本地操作手册，增加操作动图和重点提示。
- 优化小屏幕界面、分析工具入口及部分交互细节。
- 修复工作区恢复、播放控制、十字线和触控板翻片问题。
- 修复部分数值输入和界面状态问题，提升操作稳定性。

## Update summary
- Improved the offline manual with workflow animations and clearer guidance.
- Improved small-screen layouts, analysis tool access, and interaction details.
- Fixed workspace restoration, playback, crosshair targeting, and touchpad scrolling.
- Fixed numeric input and interface state issues to improve reliability.

## 安装与兼容 / Installation and compatibility

- 提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版。
- macOS 包为 ad-hoc 签名，未经过 Apple 公证；Windows 包未配置 Authenticode 签名。
- 本地 AI 分割仍需单独配置运行环境和模型；已有工作区可继续打开。
- macOS packages are ad-hoc signed without Apple notarization; Windows packages are not Authenticode signed. Local AI segmentation requires a separately configured runtime and models.

## 验证范围 / Validation scope

平台测试及产物核验结果见发布验证记录。旧版客户端的完整点击更新流程、Windows/Linux 真实 AI 推理与崩溃恢复尚未完成实机验收。

Platform tests and package checks are recorded in the release validation report. Complete update workflows in previously installed clients, and native AI inference and crash recovery on Windows/Linux, remain unverified.
