# 工具栏可视化编辑

用户希望工具栏设置带图标，并使用类似网页的直接拖动方式，调整结果所见即所得。

沿用 QML 和现有工具图标，将文字排序列表与单独预览合并为可编辑按钮区域。右侧常用区按实际两行布局展示，更多区使用三列；左侧显示固定的导入入口作为上下文。设置中始终显示简短名称以便识别，不改变实际工具栏的文字开关。

整块按钮均可拖动。拖动超过阈值后显示浮动按钮、源位置淡化和目标插入标记。支持同组排序、常用与更多之间插入、空组接收、边缘自动滚动。松开后更新草稿；拖到区域外、按 Escape、切换配置或窗口失去激活时取消拖动。常用最多七项，超限保留原状态并提示。

点击按钮可选中，在统一的操作条中前移、后移或转组，供键盘及不习惯拖动的用户使用。保存、取消、恢复默认和多窗口独立草稿的现有语义不变。

方案取舍：仅给原列表加图标改动较小，但仍需在列表与预览之间对照；改用 Web 视图会增加独立技术栈与主题维护成本。本次采用原生 QML 的直接编辑区域，保持现有设置与持久化边界。

验证覆盖真实鼠标拖动、跨组插入、取消/超限/空组、滚动、键盘、保存重启以及中英文与浅深色的小窗口布局。
