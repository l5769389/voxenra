基线：`e505adfd72cfe970ac1c4a366e364b421a3cc48e`；分支 `codex/cpr-reconstruction`。原工作目录正在准备版本发布，本分支使用已有独立 worktree，不吸收其未提交修改。

## 审核结论

采用原方案的手动三维路径、独立 CPR 页签、参考切面与横截面联动路线。单平面牙弓方案无法覆盖跨层路径；自动血管提取与定量分析超出首版。四阶段顺序基本合理，但以下事项必须提前固定，不能留给 UI 接入时临时决定。

1. **先定义几何，再定义显示。** “曲面重建”不是唯一几何形式。首版采用沿中心线弧长展开、局部平行运输方向的 straightened CPR。横轴为中心线弧长，纵轴为局部横向偏移；仅中心线弧长具有约定的定量含义。远离中心线的曲面可能折叠，不能用统一二维像素间距解释任意距离、角度或面积。
2. **默认曲线不得悄悄越过控制点。** 首批采用三维分段线性路径，严格经过控制点、无插值过冲；尖角处使用前向线段的单侧切线，终点使用最后一段。平滑插值作为后续显式模式，须独立验证过冲和弧长误差，不能直接使用无约束样条替换旧算法。界面上线前须明确告知当前路径模式。
3. **把病态输入当作输入错误。** 连续重复点、近零线段、180° 折返、非有限值、过短路径、过大采样规模应可定位、可恢复地拒绝。闭合曲线与自交路径暂不作为专门分析模式；普通非相邻重复点允许，但相邻反向线段拒绝。
4. **共享采样能力，不依赖 MPR 私有方法。** `MprReslicer._trilinear_sample` 已含有限邻域权重归一化和非连续数组处理。提取成共享函数，保留原 MPR 调用行为和数值回归，不引入 SciPy 或另一套插值实现。
5. **缓存访问与 CPU 计算分离。** `VolumeManager` 会修改 LRU，不能直接从新线程并发调用。以后由现有 worker 取得、校验体数据，再给单并发 CPR 队列传只读引用；图像编辑不得原地修改共享像素。内核不持有缓存、不复制完整体数据，按块计算并调用现有取消上下文。
6. **路径版本和任务版本分开。** 路径版本标识几何编辑，任务版本同时覆盖角度、厚度、采样、当前序列/页签生命周期；GUI 只接受最新任务。调窗不增加几何版本、不重采样。
7. **测量绑定创建时的真实平面。** 横截面保存 origin、row/column basis、spacing、源序列/指纹、路径 ID/版本、弧长及算法版本。撤销或编辑路径不迁移旧测量；只有完整物理平面匹配才显示。导航到旧测量应恢复旧平面，而非仅使用当前路径的同一索引。
8. **工作区升级是完整功能的一部分。** `workspace_state` 只允许注册类型，`workspace_document.VERSION` 当前为 1 且严格校验。完成 CPR 页签持久化时升级到 v2，提供显式 v1→v2 迁移和旧工作区测试，不能只加一个 TabType。关闭页签仍保留结果，退出统一保存；缺失源文件保留记录。首批内核不修改文档版本。
9. **数值验收和 GUI 验收分开。** 合成数据证明坐标、方向、长度和采样；真实 CT/CTA/CBCT 验证可用性。没有真实数据和双平台证据时不能宣称完整首版通过。PNG 使用完整结果并按现有匿名化规则导出；派生 DICOM 留后续。

## 几何契约（算法版本 1）

- 坐标为患者 LPS，单位 mm；体素顺序沿用 `(slice, row, column)`。
- 路径为有向开放折线，2–4096 个控制点；相邻距离至少 `1e-4 mm`，总长至少 `0.1 mm`；总长至多 `10000 mm`。连续方向内积 `<= -1 + 1e-6` 拒绝。
- 沿弧长均匀采样，包括首尾。实际步长为 `length / ceil(length / requested_step)`，不得把请求步长当作最终标尺。控制线段及其转角全部参与方向运输，不能因输出较粗而跳过中间弯折。
- 初始横向方向由参数 `up_patient` 投影到首切线的法平面；近平行时选择与首切线最不平行的 LPS 正轴。局部基为切线 T、横向 U、B=T×U，使用最小旋转平行运输；角度 θ 使 Uθ=cosθ U+sinθ B，Bθ=T×Uθ。算法和初始方向需持久化。
- CPR 像素 `(row, column)` 位置为 `C(s[column]) + offset[row] Uθ[column]`。薄层采一次；厚层沿 Bθ 对称采样，最大值或有效采样均值聚合。完全无有效样本为 NaN。
- 横截面中心固定在所选中心线采样点，列方向 Uθ、行方向 Bθ、法向 T，输出真实 `MprImageGeometry`；保留路径 ID、版本、弧长、算法版本及源指纹。横截面始终为薄平面，CPR 厚层参数不污染其测量标定。
- 栅格宽度与间距均以像素中心解释。横向和横截面网格用奇数像素确保中心线落在中央像素，实际范围不小于请求范围、每轴不超过请求步长；结果携带实际范围和间距。
- 参数必须是有限数值；采样间距 `[0.05, 10] mm`、视野 `(0, 500] mm`、厚层 `[0, 100] mm`。每轴至多 4097 像素，总像素至多 4,194,304，厚层至多 1001 样本，体采样预算至多 100,000,000 次。超过限制报错，不静默降级。预览应由控制器显式提交较粗采样请求。
- 中间坐标块默认至多 16384 个点，CPR 和横截面均支持取消。使用输入体数据的引用，输出只读 float32 模态像素；非有限及越界区域为 NaN，不写背景 HU。

## 完整首版实施顺序与交付门槛

| 阶段 | 交付 | 必须通过的验收 |
| --- | --- | --- |
| A：几何内核（本次首批实施） | 路径/参数/结果模型、平行运输、公共插值、CPR/横截面、取消与上限 | 直线对照 MPR；圆弧/螺旋长度与方向；各向异性及倾斜体；管径；NaN/越界；厚层；块边界；取消；输入像素不变；原 MPR 回归 |
| B：可操作页面 | 专用控制器与 CPR 页签，两个参考切面，绘制/完成/取消/拖拽/插入/删除，多路径，CPR/断面联动，受限后台队列 | 同序列复用；源 MPR 状态不变；一次拖动一次事务；失焦取消；选点优先；迟到结果丢弃；关闭释放；调窗不采样；预览禁止定量及导出 |
| C：工作成果闭环 | 历史与测量来源、v2 工作区及 v1 迁移、关闭保留/重开恢复、PNG 导出 | 修改路径后旧测量仍定位旧平面；撤销重做与脏状态一致；丢失/变化来源可恢复；完整结果导出与匿名化；不保存体数据缓存 |
| D：首版验收 | 工具注册/自定义排序、双语文案、手册与动图、UI 与真实数据验收 | 深浅主题、高 DPI、小窗口、macOS/Windows；快速切换与大体数据；真实 CT/CTA/CBCT；无回归 |

A 是可独立审查的开发里程碑，不代表完整 CPR 功能上线。B–D 完成前不增加可见入口，不标记发布版本，也不承诺临床定量用途。
