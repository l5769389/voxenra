# 预设实时预览

用户要求将上一轮新增设置以可见预览形式呈现。在当前分支实现，保留现有保存语义。

采用选项与预览并列、窄窗口上下排列。初始显示与截图使用合成灰度模体及明确标注的虚拟信息，不读取当前患者、不改变当前视口；初始显示可切换 CT/MR 示例，演示缩放和选定窗模板。截图预览表现范围、叠加内容、匿名开关及格式/目标尺寸。报告复用实际 PDF 生成器，采用虚拟测量和参考图，展示所有页面、方向/字号/表图布局/署名。设置更新短暂合并后刷新，避免每次键入重复生成。

静态图不能说明设置差异；直接抓取患者影像会引入隐私和当前状态依赖。因此使用示例预览；实际导出仍保留已有真实报告预览。路径/打开文件位置等操作性选项不伪造视觉效果。

验收：改变设置后预览实际像素/纸张比例/页面内容更新；示例不会接触患者或修改源显示；三主题、窄宽布局、翻页、组件销毁和设置保存回归。
