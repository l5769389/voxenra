# 工具栏视图分类简化

用户已授权审核后实施此前六类方案。审核结论：可合并设置入口，但不能合并底层配置，否则 CT、MR、彩色图像及对比视图的独立布局会丢失。

主分类为 2D 阅片、MPR 重建、3D、平铺、4D、融合。2D 和 MPR 的单序列／序列对比属于细分模式；CT、MR、PET、其他灰度、彩色及 PET/CT 属于图像类型。PET/CT 三维保留在 3D 下，与融合阅片分开。

## Approaches

- 保留 26 项平铺菜单：配置明确但选择负担大。
- 合并并共用六套配置：界面简单，但破坏既有细分布局和能力差异。
- 采用用户确认的六类入口加折叠细分选项：保持原配置键，降低日常选择负担。

折叠时仍显示当前完整配置名称；展开后分开选择模式与图像类型，仅显示该视图支持的选项。切换主分类优先恢复本次编辑中该分类上次选择，首次选择尽量保留图像类型，不支持时使用该类默认值。切换不会保存或丢弃草稿；恢复默认仅影响当前具体配置。

打开编辑器时从所属窗口最近的影像页签获取当前工具配置，忽略设置、手册等辅助页签；无影像时使用 2D CT。只初始化一次，编辑中不跟随其他窗口或页签跳变。

不修改实际阅片视图入口、工具能力判断、配置存储结构或既有拖拽操作。中英葡文案及本地手册同步。校验各类配置可达、独立保存、上下文初始化、窄窗口与键盘路径。
