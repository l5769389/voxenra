# 阅片辨识与工具栏设计

用户已确认实施。保留当前 MPR 默认布局入口、现有主题、按钮文字偏好及 QA 提示策略；不发布版本。

1. 页签与阅片区区分检查日期和序列。原始序列描述不做语义缩写，仅视觉省略；完整信息可悬停读取。缺失日期、描述如实显示；同名同号需稳定区分。隐私开关覆盖新增身份信息。兼容工作区恢复及独立窗口、多来源对比。
2. 人工可读窗宽窗位统一 WW → WL，数据字段及文件格式保持不变。窗模板列表独立滚动，输入与操作区域不随模板滚动，列表边界不向外层传递滚轮。
3. 设置增加工具栏配置：左上视图按钮排序，文件/PACS与底部系统入口固定；右栏按模式/能力配置常用与更多顺序，常用最多7项。拖动与上下移动、保存/取消/恢复当前默认、预览。稳定标识持久化，新增工具进更多，无配置保留默认；展开/折叠采用同一排序来源。无需改变具体子工具排序。
4. 右侧导入入口改为导入分割，更新相关翻译与手册。
5. 最大化视图区：隐藏左右完整区域包括按钮栏，保留页签与还原按钮；再次点击恢复原宽度及折叠状态。状态仅限当前窗口，不写用户布局偏好，不更改数据、不触发脏标记，与全屏独立。设置/手册等非影像页面正常显示，返回影像继续最大化；新窗口/重启默认关闭。
6. 后续追加：窗模板列表提供星标收藏，设置中的窗模板页面同步管理。收藏持久化并优先显示，取消收藏恢复普通顺序；收藏操作不应用模板，也不改当前窗值。

选择保留默认工具组织并开放用户排序，代替强制移动布局按钮；选择视图区最大化，代替复杂的临时浮动面板。
