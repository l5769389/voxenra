# 新建工作区实现计划

用户已选择：在当前窗口开始空白工作区，先处理旧工作区未保存的更改。

目标：主页、工作区窗口和 Ctrl+N（macOS 为 ⌘N）均可新建；保留个人设置及最近工作区。

- [x] 控制器：增加 `newWorkspace()`，脏工作区提供保存、不保存、取消。保存失败、取消文件选择或保存期间再次编辑均不得清空。新建清空页签、影像索引、导入重试状态和当前文档关联；安全处理自动恢复及分离窗口。
- [x] 界面：增加两处按钮和固定快捷键，确认框沿用主题样式；正在保存、恢复或导入时禁止新建。
- [x] 验证：先写失败测试，再实现；覆盖保存分支、取消、失败、忙状态、重开旧文件、快捷键及宽窄界面。同步三种语言和本地手册。
