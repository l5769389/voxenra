# CPR Geometry Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver phase A of the reviewed CPR roadmap as a tested numerical foundation, with no visible incomplete viewer entry.

**Architecture:** Immutable value models and NumPy geometry are independent of Qt/VTK. MPR and CPR share one trilinear sampler; CPR returns a curved grid plus physically calibrated cross-sections and checks the existing cancellation context.

**Tech Stack:** Python 3.11–3.14, NumPy, existing pytest harness; no new dependency.

**Spec:** `docs/superpowers/specs/2026-10-29-cpr-design.md`

## Global Constraints

- Coordinates are patient LPS mm; volume indices are `(slice, row, column)`.
- Algorithm v1 uses piecewise linear paths and minimal-rotation parallel transport; no silent smoothing.
- No GUI, workspace format version, package version, release or shared cache ownership change in phase A.
- No whole-volume copy; output float32/NaN and cancellation between bounded chunks.
- Limits and numeric tolerances are explicit; no implicit resolution degradation.

## Review Focus

- Coarse resampling must not skip unsampled turns or make roll depend on requested sample spacing.
- Oblique and anisotropic volume coordinates must agree with a physical linear field, not only index-aligned fixtures.
- A path whose middle passes outside the volume must retain NaN holes and correct distances.
- Very long paths or dense slabs must fail before large allocations and remain cancellable during work.
- Cross-section geometry must describe the returned image and preserve its provenance independently of later caller edits.

### Task 1: Path geometry and immutable contracts

Consumers use immutable arrays and values.

Produces `CprReslicer(block_points=16384).reslice(volume, path, settings) -> CprResult` and `.cross_section(volume, centerline, index, *, width_mm, step_mm) -> CprCrossSection`.
