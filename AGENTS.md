# Repository instructions

Before preparing a version tag, packages, or GitHub Release, follow [the release checklist](docs/release-checklist.md). Apply it to the exact commit being released. Ordinary code and documentation changes do not trigger a release.

For GUI operation or automation work on 2D, MTF, and FWHM, read [the precise-operation guide](docs/automation-ui.md). Verify both the visible UI and resulting state; an accepted action alone does not establish completion.
